# 教材候補：再調査の請求と審査請求の関係

## 元になった分析

## 入口判定

再調査の請求と審査請求の関係では、まず「再調査の請求ができるか」と「再調査の請求を選んだ後どうなるか」を分ける。

再調査の請求は、法律にその旨の定めがある場合に限られる。
しかし、再調査の請求ができる場合でも、それを経ずに審査請求をすることができる。
一方、再調査の請求を先に選んだ場合は、原則としてその決定後でなければ審査請求できない。

## 制度比較

| 制度・場面 | ルール | ひっかけ |
|---|---|---|
| 再調査の請求ができる場合 | 法律に定めがある場合に限られる | 審査請求可能なら当然可能と誤解 |
| 最初の選択 | 再調査の請求を経ずに審査請求できる | 再調査前置と誤解 |
| 再調査の請求後 | 原則として決定後でなければ審査請求できない | 任意だから自由に並行可能と誤解 |
| 決定遅延等 | 決定を経ずに審査請求できる場合あり | 常に決定まで待つと誤解 |
| 審査請求に移った場合の再調査請求 | 取下げみなし | 棄却みなしと誤解 |

## 判断基準

1. 再調査の請求は、法律に定めがある場合に限られる。
2. 審査請求ができるだけでは、再調査の請求ができるとは限らない。
3. 再調査の請求は任意的手続であり、最初から審査請求を選べる。
4. 先に審査請求をした場合、再調査の請求はできない。
5. 先に再調査の請求をした場合、原則として決定後でなければ審査請求できない。
6. 決定遅延などの場合は、決定を経ずに審査請求できる場合がある。
7. その場合、再調査の請求は棄却ではなく取下げみなし。
8. 任意性、決定前置、取下げみなしを分けて覚える。
