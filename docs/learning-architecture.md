---

## 1. 教材の目的

この教材は、行政書士試験の知識を増やすだけでなく、問題文を見たときに何を疑うべきかを判断できるようにする教材である。

特に、取消訴訟では「処分性・原告適格・訴えの利益・出訴期間」の入口判断を素早く切れるようにする。

---

## 2. 学習者の流れ（基本順序）

```
トップページ
  → 処分性
  → 原告適格
  → 訴えの利益
  → 出訴期間
  → 入口判定ドリル
  → 過去問演習教材
  → 弱点復習
  → 学習ログ / 行動分析
```

---

## 3. 教材の層構造

| 層 | 名称 | 役割 |
|----|------|------|
| 第1層 | トップ導線 | 学習順序を迷わせないための入口 |
| 第2層 | 基礎演習教材 | 1論点ずつ入口感覚を作るページ |
| 第3層 | 横断判定ドリル | 複数論点のうち、どこを疑うべきかを判断するページ |
| 第4層 | 過去問演習教材 | 本番形式に近い問題処理を練習するページ |
| 第5層 | 行動分析 | 離脱・誤答・次問遷移を測る改善基盤 |

---

## 4. 基礎演習教材の役割

- 完全な解説集ではない。
- スマホで軽く読めて、論点の感覚を作ることを優先する。
- 重い説明や実戦的な選択肢処理は、参考折りたたみまたは過去問演習教材に回す。

---

## 5. 横断判定ドリルの役割

- 基礎ページを読んだ後に使う。
- 目的：場面を見たときに、処分性・原告適格・訴えの利益・出訴期間のどこをまず疑うべきかを判断できるようにする。
- 過去問本文はコピーしない。完全オリジナルの短い場面で作る。

---

## 6. 過去問演習教材の役割

- 実戦に近い処理を扱う。
- 著作権に配慮し、過去問本文・選択肢をそのままコピーしない。
- 問題の構造・論点・選択肢処理の考え方を教材化する。

---

## 7. 計測したい行動指標（GA4 / GTM / Clarity 想定）

- トップから各教材ページへの遷移
- 各ページの完走率
- ミニクイズ開始率
- ミニクイズ正答率
- 次ページ遷移率
- 入口判定ドリルの完走率
- 過去問演習への遷移率
- 折りたたみ参考欄の開閉率
- 離脱箇所
- スマホでの読み詰まり

## 9. 次に作るべきもの（優先順位）

### 第1候補：取消訴訟の入口判定ドリル
- 目的：4点セットを読んだ後に、どの入口論点を疑うべきかを判断する練習をする。
- 層：第3層（横断判定ドリル）

### 第2候補：トップページに入口判定ドリルへの導線を追加
- 条件：入口判定ドリルの内容確認後に行う。

### 第3候補：過去問演習教材の最小版
- 目的：本番に近い選択肢処理の型を作る。
- 層：第4層（過去問演習教材）

## 10. やらないこと（このドキュメントのスコープ外）

- 確認状態の変更
- UIやCSSの変更
