# 人間確認タスク — 主要条文・判例チェックリスト

取消訴訟の入口シリーズ（4ページ）に記載された条文・判例について、人間による最終確認に回す対象を管理するチェックリストである。

- `AIクロスチェック済み` の項目を人間の最終確認対象とする場合は、`docs/source-log.md` の確認状態を `人間最終確認待ち` に更新してからこのリストに記載する。
- `人間最終確認待ち` の項目について人間が一次資料を確認し、確認対象・確認URL・確認日・確認者の4点をすべて明示した場合に限り、AIエージェントへの明示的な指示で `人間最終確認済み` に更新する。

確認状態の遷移は `AI記載` → `AIクロスチェック済み` → `人間最終確認待ち` → `人間最終確認済み` の順であり、ステップのスキップは原則不可。

## 確認の手順

1. 各項目の「確認URL」欄に一次資料のURLを記入する（裁判所ウェブサイト・e-Gov法令検索など）
2. 一次資料の内容と教材記載内容を照合する
3. 「確認日」「確認者」「確認結果」「修正要否」を記入する
4. 修正が必要な場合は「メモ」欄に差異を記録し、教材を修正した上で `source-log.md` を更新する
