# 人間確認タスク — 主要条文・判例チェックリスト

取消訴訟の入口シリーズ（4ページ）に記載された条文・判例を人間が一次資料で確認するためのチェックリスト。
一次資料確認を行い、必要な教材修正を反映した後、`docs/source-log.md` の確認状態を `人間確認済み` に更新すること。

## 確認の手順

1. 各項目の「確認URL」欄に一次資料のURLを記入する（裁判所ウェブサイト・e-Gov法令検索など）
2. 一次資料の内容と教材記載内容を照合する
3. 「確認日」「確認者」「確認結果」「修正要否」を記入する
4. 修正が必要な場合は「メモ」欄に差異を記録し、教材を修正した上で `source-log.md` を更新する
