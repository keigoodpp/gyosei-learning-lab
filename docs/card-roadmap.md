# カード構成ロードマップ（参考）

この文書は、行政書士学習ラボで今後作成する教材カードの参考ロードマップです。

目的は、教材数を増やすことではなく、過去問演習前に学習者が「どの制度の問題か」を見分けやすくすることです。

ここに記載したカード数、タイトル、順序は固定仕様ではありません。実装途中のレビュー、学習効果、法的表現の安全性、既存教材との重複、トップページの情報設計に応じて、追加、削除、統合、名称変更してよいものとします。

## 基本方針

- 行政法をサイトの主軸に置く。
- 民法は制度識別で詰まりやすい論点を中心に絞る。
- トップページに全カードを並べる前提にはしない。
- 最終的には分野別一覧ページにカードを収容する。
- 教材本文追加PR、トップ導線追加PR、既存ページ内リンク追加PRを混ぜない。
- 本文に法的主張を追加する場合は、source-logとの対応を確認する。

### 運用メモ

- 階層メモは、進捗管理表ではなく導線設計用である。
- 実際の作成済み状態は、上のカード一覧表で管理する。
- パンくず導線を実装する場合は、lesson本文追加PRや低リスク後処理PRに混ぜず、導線整理専用PRで扱う。
- 行政指導のように行政法総論と行政手続法の両方に関係するカードは、必要に応じて関連リンクで補う。階層上は原則として主たる入口に置く。
- 階層は固定仕様ではなく、カード作成の進行、学習効果、重複、トップページ整理に応じて見直してよい。

### 行政法の扱い

行政法は行政書士試験の本丸として、民法より厚めに作る。

特に、行政法総論、行政手続法、行政不服審査法、行政事件訴訟法、国家賠償法、地方自治法は、それぞれ下位カードを持つ前提で整理する。

## トップページ整理の方針

今後カード数が増えた場合、トップページにすべてのカードを並べ続けない。

将来的には以下のように分ける。

| ページ | 役割 |
|--------|------|
| index.html | 分野別入口と代表カードだけを置く |
| civil-law-index.html | 民法カード一覧を収容する |
| admin-law-index.html | 行政法カード一覧を収容する |
| drill-index.html | 横断ドリルを収容する |

トップページの目的は、全教材の一覧ではなく、学習者が最初にどの分野へ入るかを選ぶ入口にすること。

## 変更可能性

このロードマップは参考であり、固定ではない。

以下の場合は、途中で変更してよい。

- 作成済み教材と内容が重複する場合
- カードを分けるより統合した方が制度識別に役立つ場合
- 行政書士試験の頻出度に照らして優先度が下がる場合
- source-log管理が過度に重くなる場合
- トップページや分野別一覧の情報設計上、別の粒度が適切になった場合
- 人間確認で読解摩擦が大きいと判断された場合

重要なのは、この表を機械的に埋めることではなく、学習者が過去問前に制度を見分ける摩擦を下げること。
