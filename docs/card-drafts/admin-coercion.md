## 1. カード目的

行政が「強くなにかをする場面」をひとまとめに覚えることで起きる混同を防ぐ。

具体的には、学習者が過去問演習前に以下の4つの場面を見分けられるようにする。

| 場面 | 代表的な手段 |
|------|-------------|
| 義務を履行させる場面 | 行政代執行・直接強制・行政上の強制徴収 |
| 緊急に実力行使する場面（義務なし） | 即時強制 |
| 過去の違反に対して制裁を科す場面 | 行政罰（行政刑罰・秩序罰） |
| 義務を前提に圧力をかける場面（間接的） | 執行罰（現行法では極限定的） |

---

## 2. 一撃定義

**行政上の強制**とは、行政が目的を実現するために法律の根拠に基づいて用いる強制的な手段の総称であり、大きく「行政強制（強制執行）」「即時強制」「行政罰」に分かれる。

> **注意**: 「行政庁は自由に強制できる」という理解は誤り。法律による行政の原理のもと、各手段ごとに**個別の法律の根拠**が必要。

---

## 3. まずイメージ

### 行政代執行が使える場面（○）

- 違法建築物の除却命令を無視した所有者に代わって、行政が業者を使って建物を取り壊す
- 不法投棄された廃棄物の撤去義務者が動かないため、行政が撤去して費用を請求する

### 行政代執行が使えない場面（×）

- 営業停止命令を無視した業者への対応（作為義務ではなく不作為義務→代執行不可）
- 税金未納者からの徴収（金銭義務→行政代執行ではなく強制徴収の手続きを使う）

### 即時強制が使われる場面（○）

- 酔っぱらった人を路上で保護する（義務を事前に課せない）
- 感染症の疑いがある人を緊急隔離する
- 火災の延焼を防ぐために隣接建物を破壊する（緊急の必要）

### 行政指導が使われる場面（任意であり強制ではない）

- 建築確認申請前に事前相談として設計変更を勧める
- 事業者に省エネ対策を求める（任意の協力を求めるにとどまる）

## 4. 試験で問われるポイント

1. **行政代執行の要件**（行政代執行法2条）
   - 代替的作為義務（他の者が代わりに行えるもの）であること
   - 義務者が履行しない・する見込みがないこと
   - 不履行を放置することが著しく公益に反すること
   - 法律（または法律に基づく命令）により課された義務であること

2. **直接強制の限定性**
   - 身体・財産に直接実力を行使するため、法律の根拠が必要
   - 現行法では、土地収用法や出入国管理及び難民認定法など限られた場面にしか規定がない

3. **即時強制の特徴**
   - 義務の事前賦課が前提ではない（義務を履行させる手段ではない）
   - 緊急または義務を課す暇がない場面で、直接身体・財産に実力行使する
   - 法律の根拠が必要

4. **行政上の強制徴収**
   - 金銭給付義務（税金・社会保険料など）を対象とする
   - 国税については国税徴収法が適用される（自力執行権）
   - 民事上の強制執行（裁判所経由）によらずに徴収できる点が特徴

5. **行政罰の2分類**
   - 行政刑罰：刑法典上の刑罰（懲役・罰金等）を科すもの。刑事訴訟手続による
   - 秩序罰（過料）：行政上の秩序維持のための制裁。非訟事件手続法または行政手続で科す

6. **法律の根拠の必要性**
   - いずれの強制手段も、法律の根拠なしに行政が独自に行使することはできない
   - 行政指導は強制力を持たないため、法律の根拠がなくても行うことはできるが、相手方の任意の協力に依存する

## 5. 似ている制度との違い

### 行政代執行 vs 直接強制

| 比較軸 | 行政代執行 | 直接強制 |
|--------|-----------|---------|
| 対象 | 代替的作為義務（他者が代替できるもの） | 代替不能な義務、または身体・財産への直接的実力行使 |
| 根拠法 | 行政代執行法が一般法として存在 | 個別法の根拠が必要（一般法なし） |
| 現行法での頻度 | 比較的よく使われる | 限定的（土地収用、出入国管理等） |
| 身体への直接介入 | なし | あり（身体拘束を含む場合あり） |

### 行政代執行 vs 即時強制

| 比較軸 | 行政代執行 | 即時強制 |
|--------|-----------|---------|
| 義務の事前賦課 | 必要（義務を課したうえで不履行の場合に発動） | 不要（義務を課す暇がない、または不可能な場合） |
| 目的 | 既存の義務を履行させる | 緊急の行政目的を直接実現する |
| 例 | 撤去命令不履行→行政が代わりに撤去 | 酔客保護・緊急隔離・延焼防止のための建物破壊 |

### 即時強制 vs 行政罰

| 比較軸 | 即時強制 | 行政罰 |
|--------|---------|--------|
| 時間軸 | 現在・未来の危険や状態に対処 | 過去の義務違反に対する制裁 |
| 目的 | 行政目的を直接実現する | 違反者に制裁を科してルールを守らせる |
| 例 | 泥酔者の路上保護 | 無届け営業への罰金 |

### 行政上の強制徴収 vs 行政代執行

| 比較軸 | 行政上の強制徴収 | 行政代執行 |
|--------|----------------|-----------|
| 義務の種類 | 金銭給付義務（税・社会保険料等） | 代替的作為義務（物を撤去する等） |
| 典型例 | 未納税の徴収 | 違法建築物の除却 |
| 根拠 | 国税徴収法等の個別法 | 行政代執行法（一般法） |

### 行政指導 vs 行政上の強制

| 比較軸 | 行政指導 | 行政上の強制 |
|--------|---------|------------|
| 強制力 | なし（相手方の任意の協力に依存） | あり（法律の根拠に基づく実力行使） |
| 相手方の対応 | 断っても原則として不利益は生じない | 不履行の場合に強制手段が発動される |
| 法的地位 | 事実行為 | 法的効果を伴う行為 |

### 行政行為の執行力 vs 実際の強制手段

- **行政行為の執行力**とは、行政行為によって命じた義務について強制執行しうる一般的な法的地位のこと。
- ただし、執行力があるからといって、即座に具体的な強制手段が使えるわけではない。
- **具体的な手段（代執行・直接強制等）は別途個別の根拠が必要**。
- 「行政行為に執行力がある＝なんでも強制できる」という理解は誤り。

### 民事上の強制執行 vs 行政上の強制

| 比較軸 | 民事上の強制執行 | 行政上の強制 |
|--------|----------------|------------|
| 主体 | 裁判所（民事執行法） | 行政庁（個別法・行政代執行法等） |
| 根拠 | 確定判決等の債務名義 | 行政処分・法律の根拠 |
| 自力執行 | 原則として行政は民事執行を使わない | 行政上の強制徴収等で自力執行が認められる場面がある |

## 6. 場面別の見分け方

```
「行政が強制する場面」と思ったら、まずこの順で確認する

Step 1: 義務を履行させようとしているか？
   → YES: 行政強制（強制執行）の可能性 → Step 2へ
   → NO（緊急・義務前提なし）: 即時強制の可能性

Step 2: 義務の種類は何か？
   → 代替的作為義務（他者が代わりにできる行為）: 行政代執行
   → 身体・不代替の義務: 直接強制（個別法の根拠が必要）
   → 金銭給付義務: 行政上の強制徴収

Step 3: 過去の違反に制裁を科す場面か？
   → YES: 行政罰（刑事罰→行政刑罰 / 過料→秩序罰）

追加確認: 強制力を持たない「お願い・勧告」の場面か？
   → YES: 行政指導（強制ではない）
```

## 7. ミニクイズ3問

### Q1

ある市は、空き家の所有者に対して、老朽化した建物の撤去を命じた。所有者がこれを無視し続けたため、市が代わりに撤去業者を手配して建物を除却し、その費用を所有者に請求した。この場面で市が用いた手段として最も適切なものはどれか。

1. 即時強制
2. 行政代執行
3. 直接強制
4. 行政罰（秩序罰）

**解説**: 代替的作為義務（撤去という行為は第三者が代わって行える）を義務者に代わって実施し、費用を徴収するのは行政代執行の典型例（行政代執行法2条）。即時強制は義務の事前賦課を前提とせず、直接強制は身体・不代替義務が対象、秩序罰は過去の違反への制裁。

### Q2

警察官が、深夜に路上で泥酔して倒れている人を、本人の同意を得ることなく保護施設に連行した。この行為の法的性質として最も適切なものはどれか。

1. 行政代執行
2. 行政上の強制徴収
3. 即時強制
4. 行政刑罰

**解説**: 泥酔者の保護は、事前に義務を課すことができない（または課す暇がない）場面で、直接身体に実力を行使するものであり、即時強制に当たる。行政代執行は義務不履行を前提とし、強制徴収は金銭義務が対象、行政刑罰は過去の違反への刑事制裁。

### Q3

行政指導について述べた次の記述のうち、正しいものはどれか。

1. 行政指導は行政行為の一種であり、相手方はこれに従う法的義務を負う
2. 行政指導に従わない場合、行政はただちに行政代執行によって目的を実現できる
3. 行政指導は強制力を持たず、相手方の任意の協力に依存する行為であり、それ自体では法的義務を発生させない
4. 行政指導を行うには、必ず個別の法律の根拠が必要である

**解説**: 行政指導は事実行為であり、相手方に法的義務を発生させない。従わなかったからといって、それだけで行政代執行等の強制手段を発動する根拠にはならない。また、行政指導そのものは法律の根拠がなくても行うことができる（行政手続法32条以下参照）。
