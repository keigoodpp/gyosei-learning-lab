## 1. カード目的

このカードの目的は、国家賠償法1条と2条を「どちらも国が払う話」として雑に混同するのをやめることにある。

「人の行為が問題なのか（1条）」「施設・物の危険や管理状態が問題なのか（2条）」「そもそも損害賠償なのか損失補償なのか」という3つの入り口の区別を、過去問演習の前に直感として持てる状態を作る。

---

## 2. 一撃定義

| 条文 | 一撃定義 |
|------|---------|
| 国家賠償法1条 | 公権力の行使に当たる公務員が職務上違法に他人に損害を与えたとき、国または公共団体が賠償する |
| 国家賠償法2条 | 道路・河川・学校施設などの公の営造物の設置または管理に瑕疵があり損害が生じたとき、国または公共団体が賠償する |

**整理ポイント：** 1条は「人（公務員）の行為」が起点。2条は「物（営造物）の状態」が起点。

## 3. まずイメージ

### 1条のイメージ（人の行為が問題）

| 場面 | 1条が問題になる例 |
|------|-----------------|
| ○ | 警察官が職務中に誤って第三者に怪我をさせた |
| ○ | 税務署員が違法な滞納処分を行い損害を与えた |
| ○ | 公立学校の教員が体罰で生徒に怪我をさせた |
| × | 道路の穴に落ちて怪我をした（→2条の問題） |
| × | 土地収用で財産を失った（→損失補償の問題） |

### 2条のイメージ（物の状態・管理が問題）

| 場面 | 2条が問題になる例 |
|------|-----------------|
| ○ | 国道の補修不良（穴・陥没）で通行人が転倒した |
| ○ | 公立プールの排水口の安全管理が不十分で事故が起きた |
| ○ | 河川の護岸整備に問題があり洪水被害が生じた |
| × | 河川工事中の作業員が誤って民家に損害を与えた（→1条の問題） |
| × | 適法な道路工事で日照が失われた（→損失補償を検討） |

## 4. 試験で問われるポイント

### 国家賠償法1条のポイント

- **入口では、まず次の要素を確認する：** ①公権力の行使に当たる公務員の行為、②職務を行うについて、③違法性、④故意または過失、⑤損害の発生、⑥行為と損害との因果関係
- **「公権力の行使」の範囲：** 権力的作用だけでなく、非権力的な行政活動も含む場合がある（要確認）
- **賠償責任の主体：** 被害者に対する賠償責任は、まず**国または公共団体**として整理する。公務員個人の直接責任の扱いは判例・資料確認が必要（source-log候補参照）。
- **求償：** 国または公共団体が賠償した後、一定の場合に公務員に対する求償が問題になる（国家賠償法1条2項・要e-Gov確認）。
- **民法709条との違い：** 民法709条は私人間の不法行為責任を考える入口。国賠1条は、公権力の行使に当たる公務員の職務上の違法行為について、国または公共団体の賠償責任を問題にする入口。

### 国家賠償法2条のポイント

- **入口では、まず次の要素を確認する：** ①公の営造物に当たるか、②設置または管理の瑕疵があるか、③損害が発生したか、④瑕疵と損害との因果関係があるか
- **「公の営造物」：** 道路・河川・公立学校・公営施設など。行政財産に限らない（要確認）
- **故意・過失について：** 2条では、故意・過失そのものは要件として前面に出ない。中心は、公の営造物の設置・管理の瑕疵と損害との因果関係である。
- **「瑕疵」の意味：** 通常有すべき安全性を欠いていること（要確認）
- **1条との使い分け：** 管理担当者の具体的行為が問題なら1条も検討。施設・物の状態が問題なら2条

### 損害賠償と損失補償の区別

- **損害賠償（国賠1条・2条）：** 違法または瑕疵ある行政活動による損害の回復
- **損失補償（憲法29条3項など）：** 適法な公権力行使による特別な財産的犠牲に対する補償
- **混同注意：** 行政が関係すれば常に国家賠償法の問題になるわけではない。適法な公権力行使による特別な犠牲が問題になる場合は、損失補償を検討する（要確認）。

## 5. 似ている制度との違い

| 比較軸 | 国賠1条 | 国賠2条 | 民法709条 | 損失補償 |
|--------|---------|---------|-----------|---------|
| 問題の起点 | 公務員の行為 | 営造物の状態 | 個人の行為 | 適法な公権力の行使 |
| 責任の主体 | 国または公共団体 | 国または公共団体 | 行為者本人 | 国または公共団体 |
| 故意・過失 | 必要 | 前面に出ない（設置・管理の瑕疵が中心） | 必要 | 不問 |
| 行為の性質 | 違法な公権力行使等 | 営造物の瑕疵 | 違法な私人の行為 | 適法な行政活動 |
| 典型例 | 違法な滞納処分 | 道路の穴による転倒 | 通常の不法行為 | 土地収用 |

## 6. 場面別の見分け方

### ステップ1：問題の起点を確認する

```
損害が出た
　↓
行政活動が関係しているか？
　├─ No → 民法の問題（国賠法の出番なし）
　└─ Yes → 次へ
　　　↓
　適法な活動か、違法・瑕疵ある活動か？
　　　├─ 適法な公権力行使による特別な犠牲 → 損失補償を検討
　　　└─ 違法または瑕疵あり → 次へ
　　　　　↓
　　　何が問題か？
　　　　　├─ 公務員の行為・判断・不作為が問題 → 国賠1条を検討
　　　　　└─ 道路・施設・設備の設置や管理状態が問題 → 国賠2条を検討
```

### ステップ2：1条か2条かの見分け

| 問いかけ | 1条 | 2条 |
|---------|-----|-----|
| 「誰かの行為が問題」と言えるか | ○ | △ |
| 「物や施設の危険な状態が問題」と言えるか | △ | ○ |
| 故意・過失を確認する必要があるか | ある | 前面に出ない（設置・管理の瑕疵の有無を確認） |
| 典型的な場面 | 職務中の公務員の違法行為 | 道路・公共施設の管理不備 |

## 7. ミニクイズ3問

### Q1

ある市の職員が、徴税業務の過程で誤った滞納処分を行い、Aさんの銀行口座を違法に差し押さえた。Aさんが被った損害について、まず根拠として検討すべき法令として最も適切なものはどれか。

1. 民法709条（不法行為責任）
2. 国家賠償法1条（公権力の行使に基づく賠償責任）
3. 国家賠償法2条（公の営造物の設置・管理の瑕疵）
4. 憲法29条3項（損失補償）

**→ 正答：インデックス1**

**解説：** 市職員が職務として行った違法な滞納処分（差押え）は、「公権力の行使に当たる公務員の職務行為」に該当する。このような場合はまず国家賠償法1条の問題として整理する。民法709条は不法行為者個人の責任を問う入口であり、公務員個人への直接請求については判例・資料での確認が必要（要確認）。2条は物や施設の状態が問題となる場面。選択肢4（損失補償）は適法な公権力行使による場面で、本問は違法行為なので該当しない。

---

### Q2

国道を管理する国土交通省の担当道路事務所が、道路上の陥没を相当期間放置していた。その陥没に自転車で乗り入れたBさんが転倒して怪我を負った。Bさんの損害賠償請求の根拠として最も適切なものはどれか。

1. 民法709条（不法行為責任）
2. 国家賠償法1条（公権力の行使に基づく賠償責任）
3. 国家賠償法2条（公の営造物の設置・管理の瑕疵）
4. 憲法29条3項（損失補償）

**→ 正答：インデックス2**

**解説：** 道路（国道）は「公の営造物」にあたる。その陥没の放置は道路の「管理の瑕疵」にあたりうる。このような物・施設の設置または管理の状態が問題となる場合は、国家賠償法2条を根拠として検討する。2条では故意・過失そのものは前面に出ず、設置・管理の瑕疵と損害との因果関係が中心となる。この点が故意・過失を要件とする1条と異なる（要確認）。

---

### Q3

国が適法な都市計画事業として道路を拡張するために、Cさんの土地を収用した。Cさんが金銭的な救済を求める場合、まず検討すべき法的根拠として最も適切なものはどれか。

1. 国家賠償法1条（公権力の行使に基づく賠償責任）
2. 国家賠償法2条（公の営造物の設置・管理の瑕疵）
3. 民法709条（不法行為責任）
4. 憲法29条3項（財産権の保障と損失補償）

**→ 正答：インデックス3**

**解説：** 土地収用は適法な公権力の行使である。適法な公権力行使による特別な財産的犠牲は「損失補償」の問題として検討する入口であり、国家賠償法（違法または瑕疵ある行政活動に対する賠償）の問題とは区別する。憲法29条3項は「私有財産は、正当な補償の下に、これを公共のために用ひることができる」と定め、損失補償の憲法上の根拠の一つとして参照されるが、詳細な成立要件や補償の範囲については資料確認が必要（要確認）。国賠1条・2条と損失補償は「行政が関係する」という点で似て見えるが、行為の適法・違法（または瑕疵の有無）が分岐点になる。
