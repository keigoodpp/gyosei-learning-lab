## 1. カード目的

行政行為について「行政庁が何かをしたら全部行政行為」と考える雑な理解を解消する。

過去問演習に入る前の段階で、学習者が次の問いに自力で答えられるようにする。

- これは行政行為の問題か。
- 行政行為ではなく、別の行政活動（行政指導・行政立法・行政契約・行政計画・事実行為・行政上の強制など）か。
- 取消訴訟で争える問題なのか（処分性の問題か）。

---

## 2. 一撃定義

**行政行為とは、行政庁が個別具体的な事件・対象について、一方的に権利義務などの法的効果を生じさせる行政活動として整理する。**

ポイントは次の 4 点。法律の根拠は、行政行為の定義そのものではなく、適法性確認の入口として別に整理する。

| ポイント | 内容 |
|---|---|
| 法律の根拠 | 法律の根拠との関係を確認する必要がある。根拠がない場合は適法性が問題になる |
| 個別具体的な事件・対象 | 一般的・抽象的なルール形成（行政立法）とは異なる |
| 一方的 | 相手方の同意は不要（行政契約とは異なる） |
| 権利義務の変化 | 単なる情報提供や事実行為とは異なる |

## 3. まずイメージ

行政の行為形式は多様である。行政行為はその一種に過ぎない。

```
行政の行為形式（概観）
├── 行政立法         … 法令・命令など。一般的・抽象的なルール
├── 行政行為         ← このカードの中心
│   ├── 許可・認可・特許・免除・確認 など
│   └── 効力：公定力・不可争力・不可変更力・執行力（詳細は別カードへ）
├── 行政指導         … 任意の協力を求める。法的強制力なし
├── 行政契約         … 双方の合意にもとづく
├── 行政計画         … 将来の行政活動の指針。処分性が問題になる場合がある
├── 事実行為         … 法的効果を直接生じさせない行為（情報提供・行政指導 など）
└── 行政上の強制     … 義務の実現手段（強制執行・即時強制 など）
```

> 行政裁量（裁量行為・羈束行為の区別）もこのカードでは入口だけ触れる。詳細は別カードへ。

## 4. 試験で問われるポイント

### 4-1. 行政行為を見分ける入口

- 行政庁による行為か
- 個別具体的な事件・対象について法的効果を生じさせる行為か
- 一方的に法的効果を生じさせるか
- 法律の根拠との関係（適法性確認）が問題になるか

### 4-2. 行政行為の効力（概観）

行政行為には特有の効力がある。このカードでは名称だけ確認し、詳細は別カードで扱う。

| 効力 | 概要 |
|---|---|
| 公定力 | 行政行為は、取り消されるまでは効力を前提に扱われる場面がある |
| 不可争力 | 一定期間の経過により、相手方が争う道が制限される場合がある |
| 不可変更力 | 一定の行為について、行政庁が後から自由に変更できないことが問題になる場合がある |
| 執行力 | 義務の強制的実現と接続する場合があるが、具体的な強制手段には根拠法令・要件・手続が別途必要 |

### 4-3. 行政裁量（入口）

法律が行政庁に判断の幅を認めている場合、裁量行為となる。裁量がある場合でも司法審査は及ぶ。ただし、裁判所は行政庁の専門的・政策的判断を直ちに置き換えるのではなく、裁量権の逸脱・濫用や判断過程の問題を確認する。詳細は行政裁量カードへ。

### 4-4. 処分性（取消訴訟との関係）

処分取消訴訟で問題になるのは、行政事件訴訟法 3 条 2 項の「処分」に当たるかどうかである。なお、取消訴訟には裁決取消訴訟（同法 3 条 3 項・要確認）もあるため、取消訴訟一般を「処分だけ」と整理しない。

- 講学上の「行政行為」と「処分性が認められる行為」は、必ずしも完全に一致しない。
- 行政計画では処分性が争点になる場合がある（要確認）。
- 行政指導は通常、任意の協力を求める行政活動として行政行為とは区別される。処分性との関係については個別の事案による（要確認）。
- このカードでは「完全に同じではない」という入口だけ確認する。処分性の詳細は別カードへ。

## 5. 似ている制度との違い

| 行為形式 | 行政行為との違い |
|---|---|
| **行政指導** | 相手方の任意の協力を求める行政活動として、行政行為とは区別する。法的強制力なし。法的効果を直接生じさせない。行政手続法上の規律・任意性・不利益取扱い禁止などは要確認。 |
| **行政立法** | 一般的・抽象的なルール形成であり、個別具体的な事件・対象について直接法的効果を生じさせる行政行為とは区別する。 |
| **行政契約** | 双方の合意にもとづく。一方的な権利義務の変動ではない。 |
| **行政計画** | 将来の行政活動の指針。個別具体的な法的効果を直接生じさせるとは限らない。処分性が争われる場合がある（要確認）。 |
| **事実行為** | 法的効果を直接生じさせない行為。行政指導も事実行為の一種として位置づけられる場合がある。 |
| **行政上の強制** | 行政行為などによって課された義務を現実に履行させる手段や、緊急場面での即時強制などとして整理する。行政罰は過去の違反に対する制裁であり、義務履行を直接実現する強制執行とは区別する。行政行為とは別の段階の問題。詳細は行政上の強制カードへ。 |

## 6. 場面別の見分け方

以下のチャートを参考に、行政活動の種類を見分ける。

```
行政庁が何かをした
      │
      ▼
  一般的・抽象的なルール形成か？
  Yes → 行政立法（法規命令・行政規則）
  No  ↓
      │
      ▼
  双方の合意にもとづくか？
  Yes → 行政契約
  No  ↓
      │
      ▼
  任意の協力を求めているだけか？（法的強制力なし）
  Yes → 行政指導（事実行為）
  No  ↓
      │
      ▼
  将来の行政の方向性を示す指針か？
  Yes → 行政計画（処分性は別途検討が必要）
  No  ↓
      │
      ▼
  すでに課した義務を実力で実現しているか、または直接実力行使か？
  Yes → 行政上の強制（強制執行・即時強制）
  No  ↓
      │
      ▼
  個別具体的な事件・対象について、一方的に権利義務などの法的効果を生じさせているか？
  Yes → 行政行為（許可・認可・特許・下命・禁止・確認 等）
```

> 取消訴訟で争えるかは「処分性」の問題として別に確認する。

## 7. ミニクイズ 3 問

### Q1. 行政指導の特徴

次のうち、行政指導についての説明として最も適切なものはどれか。

1. 行政庁が法律の根拠にもとづき、相手方に一方的に義務を課す行為である
2. 相手方の任意の協力を求める行政活動であり、法的強制力を持たない
3. 双方の合意にもとづいて権利義務を発生させる行為である
4. 一般的・抽象的なルールを制定する行為であり、特定の相手方はいない

**正答インデックス：1**（0 始まり）

**解説：**
行政指導は、相手方の任意の協力を求める行政活動である。法的強制力を持たず、相手方が従わなくても直接的な法的制裁はない（行政手続法上に関連規定あり・要確認）。選択肢 0 は行政行為（下命）、選択肢 2 は行政契約、選択肢 3 は行政立法の説明に近い。

---

### Q2. 行政立法と行政行為の区別

次のうち、行政行為の説明として最も適切なものはどれか。

1. 将来の行政活動の方向性を示す指針であり、個別具体的な事件・対象について直接法的効果を生じさせるとは限らない
2. 一般的・抽象的なルールを定めるものであり、不特定多数に適用される
3. 個別具体的な事件・対象について、一方的に権利義務などの法的効果を発生・変更・消滅させる行為である
4. 行政庁と相手方が合意して法律関係を形成する行為である

**正答インデックス：2**（0 始まり）

**解説：**
行政行為の特徴として、個別具体的な事件・対象・一方的・法的効果の変動を押さえる。法律の根拠は適法性確認の入口として確認する。選択肢 0 は行政計画、選択肢 1 は行政立法（法規命令等）、選択肢 3 は行政契約の説明に近い。

---

### Q3. 処分性と取消訴訟

取消訴訟に関する次の説明のうち、最も適切なものはどれか。

1. 行政庁のあらゆる行為が取消訴訟の対象となる
2. 処分取消訴訟で争う場合には、行政事件訴訟法に定める「処分」に該当するかが問題になり、講学上の行政行為と完全に一致するわけではない
3. 行政指導は任意の協力を求める行為であるから、取消訴訟の対象となることはない
4. 処分性の判断は、法律に「行政処分」と明示されているかどうかだけで決まる

**正答インデックス：1**（0 始まり）

**解説：**
処分取消訴訟で問題になる「処分」（行政事件訴訟法 3 条 2 項・要確認）は、講学上の行政行為と完全に一致するわけではない。行政計画が処分性の対象となるかが争われた判例も存在する（具体的な判例名は要確認）。行政指導は通常、任意の協力を求める行政活動として処分性を持たないものとして区別するが、個別の事案については要確認。なお、取消訴訟には裁決取消訴訟（行政事件訴訟法 3 条 3 項・要確認）もあるため、取消訴訟一般を「処分だけ」と整理しないことに注意する。選択肢 0・2・3 はいずれも過度に断定的であり不正確。
