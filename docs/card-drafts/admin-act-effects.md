## 1. カード目的

行政行為の効力について、公定力・不可争力・不可変更力・執行力を混同しないための入口を整理する。

特に以下の混同を減らす：
- 公定力と不可争力を同じものとして覚えてしまう
- 不可争力と不可変更力を混同する
- 執行力と行政上の強制を雑に同一視する
- 「違法な行政行為は当然に無効」と誤解する
- 「取消訴訟で争えるかどうか」と「行政庁が自分で変更できるかどうか」を区別できない

---

## 2. 一撃定義

行政行為の効力は、公定力・不可争力・不可変更力・執行力の4つに分けて整理する。それぞれ「誰が」「どの段階で」「何ができるか」が異なる。

---

## 3. まずイメージ

| 効力 | 意味のコア | 誰への制約か | どこで問われやすいか |
|------|-----------|------------|-----------------|
| 公定力 | 取り消されるまでは有効なものとして通用する | 国民・裁判所 | 違法行為の効力・取消訴訟の必要性 |
| 不可争力 | 一定の期間が過ぎると、国民の側から取消しを求めて争えなくなる | 国民 | 出訴期間・審査請求期間 |
| 不可変更力 | 行政庁が自ら変更・取消しをできなくなる場面 | 行政庁 | 不服申立て裁決後の拘束 |
| 執行力 | 義務を履行しない相手方に対して行政が強制的に実現できる効力 | 義務者（国民） | 行政上の強制執行・代執行 |

---

## 4. 試験で問われるポイント

### 公定力
- 行政行為が違法であっても、権限ある機関が取り消すまでは有効なものとして通用する効力として整理する
- 「違法だから当然に無効」とは原則として整理しない（重大かつ明白な瑕疵がある場合の無効は別に確認する）
- 公定力があるから取消訴訟という争訟手続が必要になる、という接続を押さえる

### 不可争力
- 一定期間（出訴期間・審査請求期間）が経過すると、国民の側から取消しを求めて争う手続が制限される
- 「国民の側から争えなくなる」という点が核心。行政庁側の問題ではない
- 不可争力が生じても、行政行為が適法になるわけではない

### 不可変更力
- 行政庁が自らした行政行為を職権で取消し・変更できなくなる場面として整理する
- すべての行政行為に当然に生じるわけではなく、不服申立てに対する裁決など一定の行為に認められる場合がある（要確認）
- 「行政庁側が変更できなくなる」という点が核心

### 執行力
- 義務を課す行政行為について、履行しない相手方に対して行政が強制的に義務内容を実現できる効力
- 執行力があるから直ちに強制できるわけではなく、行政上の強制執行の根拠・手続が別途必要になる場合がある
- 民事上の強制執行とは仕組みが異なる点に注意する

---

## 5. 似ている制度との違い

### 公定力 vs 不可争力
- 公定力：違法でも取消し前は有効として通用するという行政行為の属性
- 不可争力：国民の側から争う手続が期間経過により制限されるという制度的効果
- 公定力は「有効として扱われる根拠」、不可争力は「争えなくなる時的制限」として別に整理する

### 不可争力 vs 不可変更力
- 不可争力：国民の側から争えなくなる
- 不可変更力：行政庁の側が変更・取消しをできなくなる
- 制約を受ける主体が違う

### 執行力 vs 行政上の強制
- 執行力は行政行為の効力の一種
- 行政上の強制執行（代執行・直接強制・執行罰・強制徴収）は執行力の実現手段として別に整理する
- 執行力があることと、具体的に強制できるかどうかは別の問題として区別する

### 公定力 vs 無効
- 重大かつ明白な瑕疵がある行政行為は、公定力が生じず当然無効として扱われる場合がある（要確認）
- 違法な行政行為のすべてが無効になるわけではない
- 「違法 → 取消し得るが有効」と「重大明白な瑕疵 → 無効」を区別する

## 6. 場面別の見分け方

### 場面1
Aに対する行政行為が違法である疑いがあるが、まだ取消されていない。
→ 公定力の問題として整理する。違法であっても取消しを受けるまでは有効なものとして通用するのが基本。ただし重大かつ明白な瑕疵がある場合の無効は別に確認する。

### 場面2
行政行為に対して取消訴訟を提起しようとしたが、出訴期間が経過していた。
→ 不可争力の問題として整理する。国民の側から取消しを求めて争う手続が制限される。不可争力が生じても行政行為が適法になるわけではない。

### 場面3
不服申立てに対する裁決が出た後、審査庁が同じ事項について別の判断をしようとした。
→ 不可変更力が問題になり得る場面として確認する（要確認）。行政庁の側から変更できなくなる場面として整理する。

### 場面4
行政行為によって課された義務をAが履行しない。行政が強制的に実現しようとしている。
→ 執行力および行政上の強制執行の問題として整理する。どの強制手段が使えるかは、根拠法令・手続の確認が別途必要になる。

## 7. ミニクイズ3問

### 問1
行政行為の効力の入口として最も適切な理解はどれか。

1. 公定力とは、国民の側から争う手続が一定期間後に制限される効力である
2. 行政行為が違法であれば、当然に取消しを待たずに無効として扱われる
3. 公定力とは、行政行為が取り消されるまでは有効なものとして通用するという効力である
4. 不可争力とは、行政庁が自ら変更・取消しをできなくなる効力である

### 問2
不可争力と不可変更力の区別として最も適切なものはどれか。

1. 不可争力は国民の側から争う手続が制限される効力、不可変更力は行政庁の側から変更できなくなる場面として区別する
2. 不可争力と不可変更力はどちらも行政庁に対する制約として同じ意味に扱う
3. 不可変更力が生じると、国民の側からも行政庁の側からも取消しができなくなる
4. 不可争力は行政庁の職権取消しを禁止する

### 問3
執行力に関して危ない理解はどれか。

1. 執行力は行政行為の効力の一種として整理する
2. 執行力があれば直ちに行政上の強制執行が可能であり、根拠法令や手続の確認は不要である
3. 執行力と行政上の強制執行（代執行等）は区別して整理する
4. 民事上の強制執行と行政上の強制執行は仕組みが異なる点に注意する

## 8. 正答インデックス（0始まり）

- 問1: 2
- 問2: 0
- 問3: 1

### 解説メモ

**問1**
選択肢2は「行政行為の公定力の核心」。選択肢0（国民側の争い制限）は不可争力の説明。選択肢1（違法なら当然無効）は公定力の原則に反する誤解。選択肢3（行政庁の変更制限）は不可変更力の説明。

**問2**
選択肢0が正しい区別。不可争力は「国民側が争えなくなる」、不可変更力は「行政庁側が変更できなくなる」として主体が違う。選択肢1（同じ意味）・選択肢2（両者に効果）・選択肢3（行政庁の職権取消し禁止が不可争力）はいずれも混同。

**問3**
選択肢1が危ない理解。執行力があっても、行政上の強制執行を実行するには根拠法令・手続が別途必要になる場合がある。執行力の存在と具体的な強制の可否は別に整理する。

## 10. 危険表現チェック

以下の語・表現が原稿内に出てくる場合の注意点。

| 語・表現 | チェック観点 |
|---------|------------|
| 「有効」 | 「誰との関係で有効か」「取消しを受けるまでは」という条件付きを明示しているか |
| 「無効」 | 「重大かつ明白な瑕疵がある場合」に限定しているか。違法なら当然無効と読めないか |
| 「取り消せる」 | 主体（国民か行政庁か）・手続（取消訴訟か職権取消しか）を明示しているか |
| 「争えない」 | 「国民の側から」「期間経過後は」という限定を外していないか |
| 「変更できない」 | 「行政庁の側から」「不可変更力が認められる行為について」という限定を外していないか |
| 「強制できる」 | 「根拠法令・手続が別途必要な場合がある」という留保を外していないか |
| 「効力がある」 | どの効力か（公定力か執行力か）を明示しているか |
| 「当然に」 | 「当然に無効」「当然に争えない」など、原則と例外を混同させていないか |
