# 判例・条文 確認ログ

教材ページに記載した判例・条文の一次資料確認記録。
教材を追加・修正したときは必ずこのファイルに追記すること。

## 確認状態の定義

| 状態 | 意味 |
|------|------|
| `AI記載` | AIが作成したが、他AIまたはレビュアーによる照合が未完了 |
| `AIクロスチェック済み` | Claude Code以外のAIレビュー（Codex Review・ChatGPTレビュー等）を経て、明確な指摘への対応が完了している状態 |
| `人間最終確認待ち` | AIクロスチェック済みだが、人間による最終承認前の状態 |
| `人間最終確認済み` | ユーザーが確認対象・確認URL・確認日・確認者を明示し、最終確認済みであると明確に指示した状態 |

> 注: 旧表記 `人間確認済み` は移行期の既存エントリのみ存続する。新規エントリには `人間最終確認済み` を使用すること。
