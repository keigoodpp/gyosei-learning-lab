# 判例・条文 確認ログ

教材ページに記載した判例・条文の一次資料確認記録。
教材を追加・修正したときは必ずこのファイルに追記すること。

## 確認状態の定義

| 状態 | 意味 |
|------|------|
| `AI記載` | AIが学習データをもとに記載。日付・掲載誌・URLは未検証。人間による確認が必要 |
| `人間確認済み` | 人間が一次資料（裁判所ウェブサイト等）で内容・URL を直接確認した |
| `未確認` | 記載はあるが確認作業が完了していない（追記直後の一時的な状態） |

## 追記ルール

新しい教材を追加したとき、または既存教材の判例表記を修正したときは：

1. テーブルに行を追加し、**確認状態は必ず `未確認` または `AI記載` から始める**
2. 「確認URL」には裁判所ウェブサイト等の直接リンクを記載する。確認できていない場合は `要確認` と書く
3. 「確認者」には確認した人の名前またはロール（例: `AI`, `@username`）を記載する
4. 人間が一次資料を確認したら、確認者名・URLを更新し、状態を `人間確認済み` に変更する
5. 要点メモを追記する（定義・変更理由・掲載誌）
