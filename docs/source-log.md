# 判例・条文 確認ログ

教材ページに記載した判例・条文の一次資料確認記録。
教材を追加・修正したときは必ずこのファイルに追記すること。

## 確認状態の定義

| 状態 | 意味 |
|------|------|
| `AI記載` | AIが作成したが、他AIまたはレビュアーによる照合が未完了 |
| `AIクロスチェック済み` | Claude Code以外のAIレビュー（Codex Review・ChatGPTレビュー等）を経て、明確な指摘への対応が完了している状態 |
| `人間最終確認待ち` | AIクロスチェック済みだが、人間による最終承認前の状態 |
| `人間最終確認済み` | ユーザーが確認対象・確認URL・確認日・確認者を明示し、最終確認済みであると明確に指示した状態 |

> 注: 旧表記 `人間確認済み` は移行期の既存エントリのみ存続する。新規エントリには `人間最終確認済み` を使用すること。

### 判例の要点メモ

**最高裁昭和39年10月29日判決（東京ごみ焼却場事件）**

### 判例・条文の要点メモ

**行政事件訴訟法第9条第1項（括弧書き）**
- 括弧書き部分: 「当該処分若しくは裁決の効果が期間の経過その他の理由によりなくなった後においてもなお処分若しくは裁決の取消しによって回復すべき法律上の利益を有する者を含む」
- 処分の効果が消滅した後も、なお取消しによって回復すべき法律上の利益がある場合は、取消訴訟を続ける利益が認められることを示す規定
- 2026-05-26 Keiichiro Yoshida がe-Gov法令検索で確認済み

**最高裁昭和55年11月25日判決（運転免許停止処分事件）**
- 運転免許の停止処分について、停止期間満了後の訴えの利益が争われた事件
- 判示の要旨（AIクロスチェック済み）: 免許効力停止期間を経過し、かつ処分の日から無違反・無処分で1年を経過したときは、当該処分の取消しによって回復すべき法律上の利益を有しないとして訴えの利益を否定した
- 留意点: この判決の結論（主文）は訴えの利益なし（却下）である。停止期間満了後の1年間は前歴（行政記録）が残り将来の処分に影響するため訴えの利益が存続する趣旨が判決理由に含まれるが、1年無違反・無処分経過後は前歴が消えるため訴えの利益も消滅するとした構造。整合レビューにて教材本文・クイズ解説に1年ルール・前歴消去の構造の注記を追加済み。ただし「停止期間満了後も前歴が残る間は訴えの利益が存続する」という基本的な記述・クイズの正答（選択肢②）は維持している。判決の結論（却下）との厳密な整合・正確な判示文言は人間最終確認時に照合すること
- 民集34巻6号781頁（判決日・掲載情報・判示の骨子は courts.go.jp id=37358 等でAIクロスチェック済み。正確な判示文言・判決全文の人間最終確認は未実施）

**最高裁昭和59年10月26日判決（建築確認工事完了事件）**
- 建築確認の取消訴訟で建築工事が完了した後の訴えの利益が争われた事件
- 工事完了後は確認を取り消しても建物は存在し続け、回復される法律上の利益がないとして、原則として訴えの利益が消滅するとした
- 民集38巻10号1169頁（判決日・掲載情報・工事完了後の訴えの利益消滅という骨子は courts.go.jp id=52704 等でAIクロスチェック済み。正確な判示文言・判決全文の人間最終確認は未実施）

## 追記ルール

新しい教材を追加したとき、または既存教材の判例表記を修正したときは：

1. テーブルに行を追加し、**確認状態は必ず `AI記載` から始める**
2. 「確認URL」には裁判所ウェブサイト等の直接リンクを記載する。確認できていない場合は `要確認` と書く
3. 「確認者」には確認した人の名前またはロール（例: `AI`, `@username`）を記載する
4. 確認状態の更新は以下の順序で行う（ステップのスキップは原則不可）
   - AIクロスチェック（Codex Review・ChatGPTレビュー等）を経て指摘への対応が完了したら `AIクロスチェック済み` に更新する
   - 人間の最終確認対象としてキューに入れる場合は `人間最終確認待ち` に更新する
   - 人間が一次資料を確認し、確認対象・確認URL・確認日・確認者の4点が明示された場合に限り `人間最終確認済み` に更新する
5. 要点メモを追記する（定義・変更理由・掲載誌）
