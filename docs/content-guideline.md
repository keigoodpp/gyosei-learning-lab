# 法令・判例教材の書き方ルール

`lessons/` 以下の教材ページを作成・レビューする際の基準。

---

## 1. 教材の型（2種類）

教材ページは以下のいずれかの型を選んで構成する。

### 1-A. 標準説明教材型

初学者向けに定義・背景・試験ポイントを丁寧に説明するページ。

すべての教材は以下の順序で構成する。順序を変えてはならない。

| # | セクション | 目的 | 分量の目安 |
|---|-----------|------|-----------|
| 1 | **まず結論** | 論点の核心を1〜2文で述べる | 50字以内 |
| 2 | **初心者向け説明** | 定義・背景を平易な言葉で解説 | 150〜300字 |
| 3 | **具体例** | ○/×の対比で理解を定着させる | 各側3〜5例 |
| 4 | **試験で問われるポイント** | 頻出論点を箇条書きで列挙 | 3〜6項目 |
| 5 | **ミニクイズ** | 択一式3問で自己確認 | 各問1問1解説 |

### 1-B. 基礎演習教材型

過去問演習前のウォームアップを目的とし、スマホで軽く読んで感覚を作るページ。
判例カードや短い復習を中心に構成する。

推奨する構成順序:

| # | セクション | 目的 | 分量の目安 |
|---|-----------|------|-----------|
| 1 | **一撃定義** | 論点の核心を1文で示す | 60字以内 |
| 2 | **まずイメージ** | ○/×の対比で直感を作る | 各側2〜3例 |
| 3 | **よくある勘違い** | 典型的な誤解を3項目で潰す | 各項1文 |
| 4 | **判例を場面で覚える** | 場面・説明・結論の3層カード | 2〜4件 |
| 5 | **1分復習** | 覚えるフレーズ＋要点リスト | フレーズ1〜2文 |
| 6 | **ミニクイズ** | 択一式3問で自己確認 | 各問1問1解説 |
| 7 | **参考（折りたたみ）** | 詳細な説明・条文・試験ポイント | 折りたたみ内 |

**基礎演習教材型の運用ルール:**
- 重い説明・条文引用・試験ポイント詳細は参考（折りたたみ）に移してよい
- ミニクイズまでの前半を短く保ち、スマホで読み通せることを優先する
- 判例カードは既存の判例のみ使用し、新しい判例を追加する場合は source-log への記録が必要
- 以下は型を問わず維持する:
  - 条文番号・判例表記の正確性
  - 判例表記は裁判所・年月日・判決/決定の種別を省略しない
  - クイズの正答・解説・JS構造を壊さない
  - 確認状態を勝手に変更しない

## 2. 法令の引用ルール

### 条文の記載形式
```
行政手続法第2条3号
行政書士法2条の2
民法第5条第1項
```
- 法令名は正式名称を使う（「行手法」「行書法」などの略称は本文中で使用不可）
- 条・項・号の順で記載する
- 条文を引用するときは「」で囲み、出典を明示する

### 判例の記載形式
```
最高裁昭和39年10月29日判決
最高裁大法廷平成20年9月10日判決
最高裁平成17年7月15日判決
```
- 裁判所・日付・種別（判決/決定）を必ず記載する
- 通称がある場合は括弧書きで添える（例: 東京ごみ焼却場事件）
- 判例変更がある場合は「判例変更」と明記し、変更前・変更後の両方を示す

## 3. 正確性の確保

### やること
- 条文番号は e-Gov 法令検索で必ず確認してから記載する
- 判例は最高裁判所裁判例集（裁判所ウェブサイト）を一次情報とする
- 「処分性あり/なし」など二値の結論は判例の帰結に忠実に書く

### やってはならないこと
- 条文・判例を記憶だけを根拠に記載する（必ず一次資料で確認）
- 学説上争いがある論点を「確定した結論」として断定的に書く
- 争いがある点は「学説上争いがある」または「有力説によれば〜」と明記する

---

## 4. 対象読者の設定

- **前提知識**: 法律の初学者（法学部以外を含む）
- **文章レベル**: 中学生が読んでも意味がわかる平易さを目指す
- **専門用語**: 初出時に必ず簡単な言い換えを添える

```
例（悪い）: 「処分性が認められる要件として直接性が求められる。」

例（良い）: 「処分性が認められるには、行政の行為が国民の権利義務を
            『直接』変えるものでなければならない（直接性の要件）。」
```

## 5. クイズの作り方

### 問題文
- 択一式（2〜4択）を使う
- 「正しいものはどれか」「誤っているものはどれか」を明確にする
- 引っかけは許容するが、不公正なひっかけ（常識で判断できない枝）は不可

### 選択肢
- 全選択肢が同程度の長さになるよう揃える
- 正解肢は毎回ランダムな位置に配置する（実装上は `answer` インデックスで管理）

### 解説
- 正解・不正解ともに「なぜそうなるか」を根拠（条文・判例）とともに書く
- 解説は100字以内を目安とする

## 6. ファイル命名規則

| 項目 | ルール |
|------|--------|
| ファイル名 | `lessons/<slug>.html`（英小文字・ハイフン区切り） |
| slug の決め方 | 論点名のローマ字（例: `shobunsei`, `genkoktekikaku`, `moshitate`） |
| 文字コード | UTF-8 |
| 改行コード | LF |
