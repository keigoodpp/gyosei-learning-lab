行政裁量の全体地図

「裁量がある＝何でも適法」という誤解を解くための基礎確認

一撃定義
POINT

行政裁量とは、法令が行政庁に認めた判断余地のことをいう。

裁量があっても「何をしても適法」にはならない。裁量権の逸脱または濫用があれば、取消訴訟において違法として問題になりうる。

まずイメージ
  • 裁量がある場面（裁量行為）
    法令の文言が「できる」「適当と認めるとき」など行政庁に選択の余地を残している場面。公務員の懲戒処分の種類・程度の選択など
  • 裁量がない、または狭い場面（覊束行為）
    法令が要件と効果を比較的明確に定め、行政庁の判断余地が小さい場面。「○○の場合は許可しなければならない」と定めているときなど
  • 裁量があっても違法になりうる場合
    裁量の外側を超えた判断（逸脱）、裁量の内側でも目的違反・比例原則違反・平等原則違反（濫用）、判断過程に看過しがたい過誤・欠落がある場合
よくある勘違い
  • 裁量がある＝何をしても適法、ではない → 裁量権の逸脱・濫用は違法になりうる
  • 裁量の範囲内なら目的違反でも適法、ではない → 目的違反は裁量権の濫用として違法が問題になりうる
  • 裁判所は行政庁の裁量を一切審査できない、ではない → 裁量権の逸脱・濫用について審査できる
  • 考慮不尽と他事考慮は同じ、ではない → 考慮不尽は考慮すべき事情を十分考慮しないこと、他事考慮は考慮すべきでない事情を考慮すること
  • 裁量の逸脱と濫用は同義、ではない → 逸脱は裁量の外側への踏み出し、濫用は内側でも目的・原則に反する行使
  • 覊束行為なら常に合法、ではない → 要件の認定や手続にも問題がないかを確認する
場面で覚える
場面1
法令が「公益上必要があると認めるとき」などの幅のある文言を置き、行政庁が制度趣旨・処分の性質・専門性を踏まえて許可・不許可を判断している。
→ 裁量行為になりうる場面（ただし、許可だから当然に裁量行為とは限らない。根拠法令の要件・効果が明確なら覊束的に扱われることもある）
場面2
行政庁が処分をするかどうかを判断する際、考慮すべき重要な事情を見落としていた。
→ 考慮不尽（裁量の逸脱・濫用として違法が問題になりうる）
場面3
行政庁が処分の量定に際し、本来考慮してはいけない事情を判断の根拠にした。
→ 他事考慮（裁量の逸脱・濫用として違法が問題になりうる）
場面4
法令が「○○の場合は許可しなければならない」と定めており、行政庁に選択の余地がない。
→ 覊束行為（裁量がない場面。要件の認定が正しいか・手続違反がないかを確認する）
場面5
「行政庁に裁量があるから、裁判所はその処分の当否を一切審査できない」とされた。
→ 誤り（裁量がある場合でも司法審査は及ぶ。裁量権の逸脱・濫用があれば違法として問題になりうる）
1分復習
裁量があることと、何でも適法であることは別の話。
  • 法令が判断余地を認めているか → 裁量行為か覊束行為かを確認
  • 裁量の外側を超えているか → 裁量権の逸脱
  • 裁量の内側でも目的・原則に反するか → 裁量権の濫用
  • 考慮すべき事情を十分考慮したか → 考慮不尽の問題
  • 考慮すべきでない事情を考慮したか → 他事考慮の問題
  • 司法審査は及ぶ → ただし行政庁の判断を丸ごと置き換えるわけではない
ミニクイズ
問1
行政庁が裁量を有する処分において、考慮すべき事情を十分に考慮しなかった。この場合、違法が問題になりうるか？
問2
行政庁が裁量判断において、本来考慮してはいけない事情を判断の根拠にした。これは何と呼ばれるか？
問3
行政庁に裁量がある場合、裁判所はその処分を一切審査できないか？
参考：発展確認・関連ページ
発展確認：行政裁量で問われるポイント
覊束行為と裁量行為の区別
  • 法令の文言は重要な入口だが、文言だけで機械的に決まるわけではない
    「しなければならない」「できる」「適当と認めるとき」などの文言は参考になるが、制度趣旨・処分の性質・専門性・判例の整理も合わせて確認する
裁量権の逸脱と濫用
  • 逸脱：裁量の外側への踏み出し
    行政庁が法令や授権の範囲を超えた判断をすること。取消訴訟において違法として問題になりうる
  • 濫用：裁量の内側でも違法になりうる
    裁量の範囲内であっても、目的に反したり、比例原則・平等原則に反する形で行使した場合は濫用として違法が問題になりうる。逸脱と濫用は別の切り口だが、行政事件訴訟法第30条は両者をともに違法の根拠として並べている
考慮不尽と他事考慮
  • 考慮不尽：考慮すべき事情を十分に考慮しないこと
    裁量判断において考慮に入れるべき事情を見落とした場合に、裁量の逸脱・濫用として違法が問題になりうる
  • 他事考慮：考慮すべきでない事情を考慮すること
    裁量判断において本来考慮してはいけない事情を判断に取り込んだ場合に、裁量の逸脱・濫用として違法が問題になりうる。考慮不尽とは別の概念
比例原則・平等原則・目的違反
  • 比例原則：目的と手段のバランスが問われる
    目的に比べて過度に重い手段を選んだ場合、裁量権の濫用として違法が問題になりうる
  • 平等原則：同種の事案を合理的理由なく異なって扱うことが問われる
    合理的な理由のない差別的取扱いがあった場合、裁量権の濫用として違法が問題になりうる。事情の違いがある場合に異なる取扱いをすることが直ちに違法とは限らない
  • 目的違反：法令が予定した目的とは異なる目的での権限行使
    権限を与えられた目的とは異なる目的で行使した場合、裁量権の濫用として違法が問題になりうる
司法審査との関係
  • 裁量がある場合でも司法審査は及ぶ
    裁判所は行政庁の専門的・政策的判断を直ちに置き換えるのではなく、裁量権の範囲を超えたか（逸脱）、濫用があったか、判断過程に看過しがたい過誤・欠落があるかを確認する。審査の密度は事案による
