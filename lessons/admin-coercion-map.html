行政上の強制の全体地図

「行政が強く動く場面」をすべて同じ制度として処理しないための基礎確認

一撃定義
POINT

行政上の強制とは、行政目的を実現するため、法律の根拠に基づいて義務履行を確保したり、緊急の必要に応じて実力を及ぼしたりする制度群をいう。

制度ごとに目的・対象・根拠・手続が異なる。行政罰は義務履行確保ではなく過去の義務違反等への制裁であり、区別して扱う。行政指導は相手方の任意の協力を求める行政活動であり、直接の強制手段とは異なる。

まずイメージ
  • 行政代執行
    代替的作為義務（他の者が代わって行うことができる作為義務）が課され、義務者が履行しない場合に、行政が代わって実現する場面。法律の根拠・要件の充足が必要
  • 行政上の強制徴収
    税などの金銭給付義務を履行しない義務者から、法律の根拠に基づき徴収する場面。行政代執行とは対象となる義務の種類が異なる
  • 即時強制
    事前に義務を課して履行を待つ余裕がない場面で、法律の根拠に基づいて身体・財産に実力を及ぼす場面。義務の事前賦課を前提としない点で行政代執行と異なる
  • 行政罰
    過去の義務違反等に対して制裁を科す場面。義務履行を直接実現する強制執行とは区別する
  • 行政指導
    相手方の任意の協力を求める行政活動。法的義務を直接発生させず、直接の強制手段ではない
よくある勘違い
  • 義務違反があれば全部行政代執行できる、ではない → 対象は代替的作為義務に限られ、要件の充足も必要
  • 税の滞納は行政代執行で処理する、ではない → 金銭給付義務は行政上の強制徴収の問題であり、行政代執行の対象ではない
  • 緊急なら何でも即時強制できる、ではない → 即時強制にも法律の根拠が必要
  • 行政罰は義務を履行させる制度、ではない → 行政罰は過去の義務違反等への制裁であり、義務履行を直接実現する手段ではない
  • 行政指導に従わないと強制手段を使える、ではない → 行政指導は任意の協力を求める活動であり、従わなかったことだけを理由に強制手段を発動する根拠にはならない
  • 直接強制と行政代執行は同じ、ではない → 直接強制は身体・財産に直接実力を加える制度。行政代執行は代替的作為義務を行政が代わって実現する制度
  • 執行罰と行政罰は同じ、ではない → 執行罰は義務履行を促す間接的手段。行政罰は過去の違反等への制裁。目的が異なる
場面で覚える
場面1
撤去などの代替的作為義務が課されたが、義務者が履行しない。
→ 行政代執行が問題になりうる（ただし、代替的作為義務・法律上の根拠・補充性・公益上の支障などの要件の充足を確認する必要がある）
場面2
税などの金銭給付義務を履行しない。
→ 行政代執行ではなく、行政上の強制徴収が問題になる（対象となる義務の種類が作為義務ではなく金銭給付義務であるため）
場面3
事前に義務を課して履行を待つ余裕がない緊急の場面で、行政が身体・財産に実力を及ぼした。
→ 即時強制が問題になりうる（法律の根拠が必要。義務の事前賦課を前提としない点で行政代執行と異なる）
場面4
過去の無許可営業や届出義務違反に対して制裁を科す。
→ 行政罰が問題になる（過去の義務違反等への制裁。義務履行を直接実現する行政上の強制執行とは区別する）
場面5
行政庁が事業者に改善を求めているが、相手方が任意に応じるかどうかに委ねている。
→ 行政指導が問題になる（任意の協力を求める活動。直接の強制手段ではない）
1分復習
「行政が強く動く場面」を見たら、制度ごとの目的・対象・根拠を確認する。
  • 義務履行を実現しようとしているか → 行政上の強制執行の問題（代執行・直接強制・強制徴収）
  • 代替的作為義務か・金銭給付義務か → 代替的作為義務なら行政代執行、金銭給付義務なら行政上の強制徴収
  • 事前に義務を課す余裕がない緊急場面か → 即時強制の問題（法律の根拠が必要）
  • 過去の違反等への制裁か → 行政罰の問題（義務履行確保の強制執行とは区別）
  • 任意の協力を求めているか → 行政指導（強制手段ではない）
  • いずれの手段も法律の根拠が必要 → 法律による行政の原理のもとで発動する
ミニクイズ
問1
行政代執行が問題になりやすいのはどれか。
問2
即時強制の説明として近いものはどれか。
問3
行政罰と行政上の強制執行の違いとして正しいものはどれか。
参考：発展確認・関連ページ
発展確認：各制度のポイント
行政代執行の要件
  • 代替的作為義務であること
    他の者が代わって行うことができる作為義務が対象。不代替的義務（作為義務のうち他者が代替できないもの）や不作為義務は対象外
  • 法律（または法律に基づく命令）により課された義務であること
    行政代執行の根拠となる義務は、法律上の根拠をもつものに限られる（要確認）
  • 補充性
    他の手段によって義務の履行を確保することが困難な場合であること（行政代執行法2条参照。条文の正確な文言は要e-Gov確認）
  • 公益上の支障
    その不履行を放置することが著しく公益に反すること（行政代執行法2条参照。条文の正確な文言は要e-Gov確認）
直接強制の限定性
  • 身体・財産に直接実力を加える制度
    行政代執行とは異なり、義務者本人の身体や財産に直接働きかける手段であるため、認められる場面は限定的とされる
  • 個別の法律上の根拠が必要
    行政代執行法のような一般法がなく、個別の法律に根拠がある場合に限り問題になりうる（根拠法令は要確認）
執行罰の位置づけ
  • 義務履行を促す間接的手段
    義務を履行するまでの間、一定の金銭的負担を繰り返し課すことで心理的に履行を促す制度。直接の実力行使ではない
  • 現行法上の位置づけは限定的
    現行法での根拠は非常に限られており（要確認）、行政刑罰・秩序罰（行政罰）や行政上の強制執行の他の手段とは区別する
行政罰の2分類
  • 行政刑罰
    行政上の義務違反に対して刑罰（懲役・罰金等）を科すもの。刑事訴訟手続による（要確認）
  • 秩序罰（行政上の過料）
    行政上の秩序維持のために過料を科すもの。行政刑罰とは制裁の種類・手続が異なる（要確認）
即時強制と法律の根拠
  • 事前の義務賦課を前提としない
    義務を課して履行を待つ余裕がない場面、または義務を事前に課すことができない場面で問題になる。行政代執行とは根本的に構造が異なる
  • 法律の根拠が必要
    「緊急だから」というだけで発動できるわけではなく、法律の根拠に基づいて問題になる（根拠法令は事案ごとに要確認）
