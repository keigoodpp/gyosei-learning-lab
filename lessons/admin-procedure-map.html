行政法

行政手続法の全体地図

過去問で何を聞かれているかを見抜くための基礎確認

一撃定義
POINT

行政手続法は、行政が処分や行政指導を行うときに、どのような手続を踏むべきかを整理する法律である。

過去問では、申請に対する処分か、不利益処分か、行政指導か、届出か、命令等の制定かをまず見分ける。

まずイメージ
  • 申請に対する処分
    許可・認可など、私人からの申請に対して行政庁が応答する場面
  • 不利益処分
    許可取消し・営業停止など、相手方に不利益を与える処分をする場面
  • 行政指導
    命令ではなく、行政が相手方に協力を求める場面
  • 届出
    一定事項を行政に知らせることで、法令上の効果が発生する場面
  • 意見公募手続
    命令等を定める前に、広く意見を募集する場面
  • 審査基準
    申請に対する処分で、許可するかどうかを判断する基準
  • 処分基準
    不利益処分をするかどうか、またはどの程度にするかの基準
  • 理由提示
    処分の理由を相手方に示す場面
試験で問われるポイント
申請に対する処分
  • 審査基準・標準処理期間・申請拒否処分の理由提示が問題になりやすい
    審査基準は、行政上特別の支障がある場合を除き公にしておく必要があり、申請を拒否する際の理由提示が問われる
不利益処分
  • 処分基準・聴聞・弁明の機会付与・理由提示が問題になりやすい
    不利益処分では、まず聴聞が必要な法定類型かを見る。聴聞類型でなければ弁明の機会付与を検討する。ただし、行政手続法上、意見陳述手続自体が不要となる例外がある
行政指導
  • 任意性・書面交付・許認可等の権限との関係が問題になりやすい
    行政指導は任意だが、相手方が求めた場合の書面交付や、許認可権限を背景にした事実上の強制が問題になりうる
届出
  • 形式上の要件を満たして到達したときの扱いが問題になりやすい
    届出は、形式上の要件が充足していれば到達の時点で手続上の効果が生じる
意見公募手続
  • 命令等を定める前の手続として問われやすい
    命令等制定機関が命令等を制定・改廃しようとするときに、広く意見を求める手続
場面で覚える
場面1
事業者が営業許可を申請した。
→ 申請に対する処分（申請を受けた行政庁が、許可するかどうかを判断する場面）
場面2
行政庁が営業許可を取り消そうとしている。
→ 不利益処分（相手方に不利益を与える処分として、処分基準・聴聞・理由提示が問われる）
場面3
行政庁が業者に改善を求めているが、命令ではない。
→ 行政指導（任意の協力要請。書面交付や事実上の強制が問われる）
場面4
一定事項を行政庁に提出した。
→ 届出（形式上の要件を満たして到達した時点で手続上の効果が生じる）
場面5
命令等を制定する前に意見を募集する。
→ 意見公募手続（命令等の制定・改廃前に広く意見を求める手続）
場面6
許可するかどうかの判断基準が問題になる。
→ 審査基準（申請に対する処分で適用する基準。行政上特別の支障がある場合を除き公にしておく必要がある）
場面7
不利益処分をするかどうかの基準が問題になる。
→ 処分基準（不利益処分の判断・程度を定める基準。審査基準と区別する）
場面8
なぜ処分したのかを示す必要があるか問題になる。
→ 理由提示（申請拒否処分・不利益処分のどちらでも問われる。透明性と防御のために重要）
よくある勘違い
  • 申請に対する処分と不利益処分を混同しない → 申請から始まるか、行政が一方的に課すかで区別する
  • 審査基準は申請に対する処分、処分基準は不利益処分で見る → 使う場面が違う
  • 行政指導は命令ではないが、任意性が崩れると問題になる → 名称ではなく実態で判断する
  • 届出は行政庁の許可とは違う → 届出は知らせるだけで、許可判断を待つものではない
  • 理由提示は処分の透明性と防御のために重要 → 申請拒否・不利益処分の両方で問われる
  • 聴聞と弁明の機会付与は、処分の重さの感覚ではなく行政手続法上の法定類型で見る → まず聴聞の法定類型か確認し、それ以外なら弁明の機会付与を検討する（ただし意見陳述手続自体が不要となる例外もある）
1分復習
申請・不利益・指導・届出・意見公募のどの場面かを最初に見分ける。
  • 申請から始まるなら申請に対する処分
  • 行政が不利益を与えるなら不利益処分
  • 協力要請なら行政指導
  • 知らせるだけなら届出
  • 命令等を作る前なら意見公募手続
  • 許可判断の基準なら審査基準
  • 不利益処分の基準なら処分基準
  • なぜその処分かを示すなら理由提示
ミニクイズ
問1
事業者が営業許可を申請し、行政庁が許可するかどうかを判断している。この場面でまず見るべきものはどれか。
問2
行政庁が、既に与えた営業許可を取り消そうとしている。この場面でまず見るべきものはどれか。
問3
行政庁が事業者に改善を求めているが、法的義務として命じたわけではない。この場面でまず見るべきものはどれか。
