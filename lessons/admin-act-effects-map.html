行政法

行政行為の効力の全体地図

公定力・不可争力・不可変更力・執行力の「誰が」「どの段階で」「何ができるか」を混同しないための基礎確認

一撃定義
POINT

行政行為の効力は、公定力・不可争力・不可変更力・執行力の4つに分けて整理する。それぞれ「誰が」「どの段階で」「何ができるか」が異なる。

違法な行政行為が当然に無効になるわけではなく、重大かつ明白な瑕疵がある場合の無効は別に確認する。公定力があるから常に適法という意味ではない。

まずイメージ

4つの効力は、制約を受ける主体と段階がそれぞれ違う。

効力 意味のコア 誰への制約か
公定力 取り消されるまでは有効なものとして通用する 国民・裁判所
不可争力 一定期間が過ぎると、国民の側から取消しを求めて争えなくなる 国民
不可変更力 行政庁が自ら変更・取消しをできなくなる場面 行政庁
執行力 義務を履行しない相手方に対して行政が強制的に実現できる効力 義務者（国民）
よくある勘違い
  • 違法な行政行為は当然に無効、ではない → 違法であっても、権限ある機関が取り消すまでは有効なものとして通用するのが基本。重大かつ明白な瑕疵がある場合の無効は別に確認する
  • 公定力があるから常に有効（適法）、ではない → 公定力は「取消し前の通用力」であり、行政行為が適法であることを保障するものではない
  • 不可争力が生じると行政行為は適法になる、ではない → 不可争力は争う手続の時的制限であり、行政行為の適法・違法を変えるものではない
  • 不可争力と不可変更力は同じ、ではない → 不可争力は「国民の側から争えなくなる」、不可変更力は「行政庁の側が変更できなくなる」。制約を受ける主体が違う
  • 不可変更力はすべての行政行為に当然に生じる、ではない → 不服申立てに対する裁決など一定の行為について認められる場合があり、すべての行政行為に一律に生じるとは整理しない
  • 執行力があれば行政は直ちに強制できる、ではない → 執行力は行政行為の効力の一種に過ぎず、具体的な強制手段（代執行等）を実行するには根拠法令・要件・手続が別途必要になる場合がある
  • 行政上の強制執行は執行力そのもの、ではない → 行政上の強制執行（代執行・直接強制・執行罰・強制徴収）は執行力の実現手段として別に整理する
場面で覚える
場面1
Aに対する行政行為が違法である疑いがあるが、まだ取り消されていない。
→ 公定力の問題として整理する。違法であっても取消しを受けるまでは有効なものとして通用するのが基本。ただし重大かつ明白な瑕疵がある場合の無効は別に確認する。公定力があるから取消訴訟という争訟手続が必要になる、という接続を押さえる
場面2
行政行為に対して取消訴訟を提起しようとしたが、出訴期間が経過していた。
→ 不可争力の問題として整理する。国民の側から取消しを求めて争う手続が制限される（行政事件訴訟法14条・行政不服審査法18条）。不可争力が生じても行政行為が適法になるわけではない
場面3
不服申立てに対する裁決が出た後、審査庁が同じ事項について別の判断をしようとした。
→ 不可変更力が問題になり得る場面として確認する。行政庁の側から変更できなくなる場面として整理する（不変更力の認められる行為・範囲は別途確認が必要）
場面4
行政行為によって課された義務をAが履行しない。行政が強制的に実現しようとしている。
→ 執行力および行政上の強制執行の問題として整理する。執行力があっても、どの強制手段が使えるかは根拠法令・要件・手続の確認が別途必要になる（詳細は行政上の強制カードへ）
1分復習
「行政行為の効力が問われる場面」を見たら、4つのどれが問題かと、誰への制約かを確認する。
  • 取消し前の有効扱いが問題か → 公定力（国民・裁判所への制約。違法でも取消前は通用）
  • 争う手続の時的制限が問題か → 不可争力（国民への制約。適法・違法とは無関係）
  • 行政庁が後から変更できるかが問題か → 不可変更力（行政庁への制約。すべての行為に生じるとは限らない）
  • 義務の強制的実現が問題か → 執行力（義務者への制約）＋行政上の強制執行（根拠法令・手続が別途必要）
  • 違法な行政行為の扱い → 原則は公定力により取消し前は通用。重大かつ明白な瑕疵がある場合は無効として別に確認
  • 不可争力と不可変更力の区別 → 主体の違い。国民側か行政庁側かを先に確認する

参考：発展確認・関連ページ
発展確認：無効と取消しの区別

行政行為の瑕疵は、原則として「取消し得るが有効」として扱われる。無効になるのは重大かつ明白な瑕疵がある場合に限る（要確認）。

  • 取消し得る行政行為
    違法があっても、権限ある機関が取り消すまでは有効なものとして通用する（公定力の帰結）。取消訴訟・審査請求で争う必要がある
  • 無効な行政行為
    重大かつ明白な瑕疵がある場合には公定力が生じず、当然無効として扱われる場合がある（要確認）。取消訴訟を待たずとも無効確認を求められる場面がある
発展確認：行政上の強制との接続

執行力は行政行為の効力の一種であり、行政上の強制執行はその実現手段として別に整理する。

  • 行政代執行
    代替的作為義務について、義務者に代わって行政が実施し費用を徴収する（行政代執行法）
  • 直接強制
    義務者の身体・財産に直接実力を加える。根拠法令が必要（詳細は行政上の強制カードへ）
  • 強制徴収
    金銭給付義務の不履行について、国税徴収法等の手続で強制的に徴収する
  • 執行罰
    義務を履行しない者に過料を科して間接的に強制する手段（詳細は行政上の強制カードへ）
