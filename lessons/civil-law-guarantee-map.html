民法

保証の全体地図

過去問演習前に保証で問われる場面をざっくり分類する

一撃定義
POINT

保証は、主債務者が主債務を履行しない場合に、保証人が保証債務として履行する場面の総称である。主債務と保証債務は別の債務として整理する。

過去問では、まず通常保証か連帯保証か、催告の抗弁権か検索の抗弁権かを見分ける。保証は人的担保として物的担保とは区別する。

まずイメージ
  • 主債務
    保証の前提となる、主債務者が債権者に対して負う本来の債務
  • 保証債務
    主債務者が履行しない場合に、保証人が債権者に対して負う債務
  • 通常保証
    保証人が催告の抗弁権・検索の抗弁権を持つ保証
  • 連帯保証
    催告の抗弁権・検索の抗弁権を持たない保証
  • 催告の抗弁権
    通常保証人が、まず主債務者に催告するよう主張する方向の抗弁（通常保証のみ問題になる）
  • 検索の抗弁権
    通常保証人が、主債務者の財産に先に強制執行するよう主張する方向の抗弁（通常保証のみ問題になる）
試験で問われるポイント
保証は人的担保として整理する
  • 主債務を前提に保証人が債務を負う場面が保証
    物的担保（抵当権・質権など）は物による担保、保証は人による担保として区別する
催告の抗弁権（通常保証）
  • 通常保証人が、まず主債務者に催告するよう主張する方向の抗弁
    債権者が保証人に履行を求めてきた場合に、まず主債務者への催告を求める方向として整理する
検索の抗弁権（通常保証）
  • 通常保証人が、主債務者の財産に先に強制執行するよう主張する方向の抗弁
    主債務者に弁済の資力があり強制執行が容易であることを証明して、主債務者財産への先執行を求める方向として整理する
連帯保証と通常保証の違い
  • 連帯保証人は催告の抗弁権・検索の抗弁権を持たない
    通常保証との最大の違いとして整理する。連帯保証人は主債務者と連帯して保証債務を負う
通常保証と連帯保証を同じにしない
  • 催告の抗弁権・検索の抗弁権の有無で区別する
    通常保証では両抗弁権が問題になるが、連帯保証ではこれらの抗弁権が認められない点に注意する
保証と物的担保の違い
  • 保証は人による担保、物的担保は物による担保として区別する
    抵当権・質権などの物的担保は、財産そのものを担保に供する方向として整理する
場面で覚える
場面1
AはBから借金をし、CがAの保証人になった。BがAに返済を求めても履行がない場合に、BはCに対して保証債務の履行を求めることができる。
→ 保証（主債務と保証債務の関係）
場面2
BがCに保証債務の履行を求めてきた。CはAが主債務者であるため、まずAに催告してほしいと主張する方向で考えている。Cは通常保証人である。
→ 催告の抗弁権（通常保証）
場面3
AはBから借金をし、CがAの通常保証人になっている。AはBに対して返済する資力を持っており、Aの財産への強制執行も容易な状態にある。CはBに対して、まずAの財産から強制執行してほしいと主張する方向で考えている。
→ 検索の抗弁権（通常保証）
場面4
AはBから借金をし、CがAの連帯保証人になっている。BがCに履行を求めてきた。CはAの連帯保証人であるため、通常保証人と同じ抗弁を当然には主張できない。
→ 連帯保証（催告・検索の抗弁権なし）
場面5
Aは不動産を担保に供してBから借金をした。Cは保証人にはなっていない。担保は物（不動産）が対象であり、人（Cの債務）が前提ではない。
→ 物的担保（保証ではない）
よくある勘違い
  • 保証人は主債務者そのものではない → 保証人と主債務者は別の人であり、主債務と保証債務も別の債務として整理する
  • 通常保証と連帯保証を同じにしない → 催告の抗弁権・検索の抗弁権の有無が通常保証と連帯保証の主な違いになる
  • 「保証人が債務を負う」だけでは説明として不十分 → 通常保証か連帯保証かによって、問題になる場面が異なる
  • 催告の抗弁権と検索の抗弁権を混ぜない → 催告の抗弁権はまず主債務者への催告を求める方向、検索の抗弁権はまず主債務者の財産への執行を求める方向として区別する
  • 保証と物的担保を混ぜない → 保証は人（保証人）が債務を負う人的担保、物的担保は財産そのものを担保に供する方向として区別する
1分復習
通常保証か連帯保証か、催告の抗弁権か検索の抗弁権かをまず見分ける。
  • 人（保証人）による担保なら保証（人的担保）
  • 主債務者が履行しない場合の保証人の債務なら保証債務
  • まず主債務者への催告を求める方向の抗弁なら催告の抗弁権（通常保証）
  • まず主債務者の財産への執行を求める方向の抗弁なら検索の抗弁権（通常保証）
  • 催告の抗弁権・検索の抗弁権がない保証なら連帯保証
ミニクイズ
問1
AがBから借金をし、CがAの通常保証人になっている。BがCに保証債務の履行を求めてきた。CはBに対して、まずAに催告するよう主張したい。この場面でまず見るべきものはどれか。
問2
AがBから借金をし、CがAの通常保証人になっている。AはBに対して返済する資力を持っており、強制執行も容易な状態にある。CはBに対して、まずAの財産から強制執行するよう主張したい。この場面でまず見るべきものはどれか。
問3
AがBから借金をし、CがAの連帯保証人になっている。連帯保証と通常保証の違いが問題になっている。連帯保証について正しい説明はどれか。
