行政法

行政不服審査法の全体地図

過去問で何を聞かれているかを見抜くための基礎確認

一撃定義
POINT

行政不服審査法は、行政庁の処分や不作為に不服がある場合に、行政内部で争うための手続を整理する法律である。

過去問では、処分に対する不服か、不作為に対する不服か、審査請求か、再調査の請求か、再審査請求かをまず見分ける。

まずイメージ
  • 審査請求
    行政庁の処分や不作為に不服がある場合に、行政内部で見直しを求める基本ルート
  • 処分についての審査請求
    行政庁の処分に不服がある場合の審査請求
  • 不作為についての審査請求
    法令に基づく申請に対して、相当期間が経過しても行政庁が処分をしない場合の審査請求
  • 再調査の請求
    法律に定めがある場合に、処分庁にもう一度見直しを求める手続
  • 再審査請求
    法律に定めがある場合に、審査請求の裁決後、さらに別の行政庁に不服を申し立てる手続
  • 審理員
    審査請求の審理を公正に進めるために関与する者
  • 行政不服審査会
    一定の場合に、審査庁が裁決前に諮問する第三者機関
  • 裁決
    審査請求に対する最終判断
  • 執行停止
    処分の効力や執行などを一時的に止める制度
試験で問われるポイント
審査請求
  • 処分・不作為に対する不服申立ての基本ルートとして問われやすい
    原則として審査請求が不服申立ての中心となる
処分についての審査請求
  • 処分を知った日、処分があった日など、期間制限と絡めて問われやすい
    審査請求には請求できる期間の制限があることに注意する
不作為についての審査請求
  • 法令に基づく申請に対して相当期間が経過しても処分がない場面で問われやすい
    不作為とは、法令に基づく申請に対して相当期間が経過しても行政庁が処分をしない状態
再調査の請求
  • 常に使える制度ではなく、法律に定めがある場合に限られる点が問われやすい
    審査請求とは別の手続であり、法律の根拠が必要
再審査請求
  • 審査請求の裁決後に当然できるわけではなく、法律に定めがある場合に限られる点が問われやすい
    裁決があればどの場合でも再審査請求できるわけではない
審理員・行政不服審査会
  • 審理員は行政内部の審理手続で関与し、行政不服審査会は裁決前の諮問が問題になる
    審理員は審査庁から独立した裁判所ではない。行政不服審査会は一定の場合に諮問先となる第三者機関
執行停止
  • 審査請求をしても、当然に処分の効力や執行が止まるわけではない点が問われやすい
    執行停止は要件を満たす場合に別途検討する制度
場面で覚える
場面1
営業停止処分に不服がある。
→ 処分についての審査請求（行政庁の処分に不服がある場合の基本ルート）
場面2
申請したのに相当期間が経過しても行政庁が処分をしない。
→ 不作為についての審査請求（相当期間が経過しても行政庁が処分をしない場面で検討する）
場面3
処分庁にもう一度見直してほしい。
→ 再調査の請求（ただし法律に定めがある場合に限られる）
場面4
審査請求の裁決後、さらに行政内部で争いたい。
→ 再審査請求（ただし法律に定めがある場合に限られる）
場面5
審査請求の審理を進める。
→ 審理員（審査庁が指名し、審理手続を主宰する）
場面6
裁決前に第三者機関の意見を聞く。
→ 行政不服審査会への諮問（一定の場合に審査庁が諮問する）
場面7
審査請求に対する最終判断が出る。
→ 裁決（審査庁が行う最終判断。判決とは区別する）
場面8
処分の効力を一時的に止めたい。
→ 執行停止（審査請求だけで当然に止まるわけではなく、別途検討が必要）
よくある勘違い
  • 審査請求は裁判ではなく、行政内部で争う手続 → 裁判所ではなく行政庁が審理・裁決する
  • 審査請求をしても、処分の効力は当然には止まらない → 執行停止は要件を満たす場合に別途検討する
  • 再調査の請求はいつでも使えるわけではない → 法律に定めがある場合に限られる
  • 再審査請求も裁決後であれば当然にできるわけではない → 法律に定めがある場合に限られる
  • 不作為は、法令に基づく申請に対して相当期間が経過しても行政庁が処分をしない場面で見る → 処分があった場合とは区別する
  • 裁決と判決を混同しない → 裁決は行政不服審査、判決は裁判所による判断
1分復習
処分か不作為か、どのルートかをまず見分ける。
  • 処分に不服があるなら処分についての審査請求
  • 申請に対して処分がないなら不作為についての審査請求
  • 処分庁に見直しなら再調査の請求（法律の定めが必要）
  • 裁決後さらに行政内部で争うなら再審査請求（法律の定めが必要）
  • 審理を進めるなら審理員
  • 裁決前の第三者チェックなら行政不服審査会
  • 審査請求への最終判断なら裁決
  • 効力を止めたいなら執行停止（審査請求だけで当然に止まるわけではない）
ミニクイズ
問1
行政庁から営業停止処分を受けた事業者が、その処分に不服がある。この場面でまず見るべきものはどれか。
問2
事業者が許可申請をしたが、相当期間が経っても行政庁が処分をしない。この場面でまず見るべきものはどれか。
問3
審査請求をしただけで、処分の効力は当然に止まるか。
