行政法

行政指導の全体地図

「お願い・助言・指導」と、処分・ルール・強制を混同しないための基礎確認

一撃定義
POINT

行政指導は、行政機関がその任務または所掌事務の範囲内で、一定の行政目的を実現するため、相手方の任意協力を求める活動として整理する。

相手方を直接拘束する行政行為や、一般的なルールを作る行政立法とは段階が違う。もっとも、形式名が「指導」なら処分性が必ず否定される、とは即断しない。

まずイメージ
  • 行政指導として疑う場面
    行政機関が助言・指導・勧告などの形で、相手方に改善や協力を求めている。入口では「相手方の任意協力が前提か」を見る
  • 行政行為として疑う場面
    許可・不許可、免許取消し、営業停止など、個別具体的な相手に一方的な法的効果を生じさせる場面
  • 行政立法として疑う場面
    行政機関が一般的・抽象的なルールや内部基準を定めている場面。個別の相手に協力を求める行政指導とは見方が違う
  • 届出・行政契約との違い
    届出は法令上の提出行為、行政契約は合意に基づく法律関係の形成。名前だけでなく、主体・相手方・効果を確認する
  • 事実行為との関係
    行政指導は、法的拘束力を直接生じさせない事実行為の一種として位置づけられることがある。ただし、情報提供・相談対応・実作業など他の事実行為とは、行政手続法上の規律を受ける任意協力の働きかけとして区別する
よくある勘違い
  • 行政指導＝従う義務がある、ではない → 任意協力を前提に整理する
  • 行政指導＝行政行為、ではない → 直接の法的効果を生じさせる処分とは区別する
  • 行政指導＝行政立法、ではない → 一般的・抽象的ルール形成とは区別する
  • 行政指導＝行政手続法上の処分、ではない → 行政手続法でいう処分は申請に対する処分・不利益処分などとして別に整理する
  • 行政指導なら処分性なしで終わり、ではない → 形式名だけで取消訴訟の対象性を完全に否定しない
  • 行政指導に応じないだけで不利益を受けて当然、ではない → 不服従を理由に不利益な取扱いをしてはならない、という方向で押さえる
制度境界を場面で覚える
場面1：改善を促す連絡
行政機関が事業者に対し、「この点を改善してほしい」と説明し、任意の対応を求めている。
→ まず行政指導を疑う。相手方の協力が前提であり、直ちに行政行為や行政上の強制と同じ処理にしない
場面2：許可を出さない決定
申請に対し、行政庁が「許可しない」と決定し、その結果として相手方の法的地位が変わる。
→ 行政行為・行政手続法上の処分を疑う。行政指導ではなく、一方的な法的効果があるかを見る
場面3：一般的な基準を定める
行政機関が、多数の場面に共通して使う一般的・抽象的な基準を作っている。
→ 行政立法・行政規則などを疑う。個別の相手への協力要請とは分けて考える
場面4：従わないことを理由に扱いを悪くする
相手方が行政指導に応じなかったことだけを理由に、行政がその後の扱いを不利にしようとしている。
→ 不利益取扱い禁止の方向を疑う。行政指導は任意協力が前提であることから出発する
場面5：「指導」という名前の文書
文書名は「指導」だが、相手方の権利義務に直接強い効果を生じさせるようにも見える。
→ 形式名だけで結論を出さない。処分性は、実際の内容・効果・法令上の位置づけを別に確認する
1分復習

行政指導は「任意協力ベース」。ただし、名前だけで処分性を切らない。

  • 行政行為との違い
    行政行為は個別具体的な相手に一方的な法的効果を生じさせる。行政指導は協力を促す活動として整理する
  • 行政立法との違い
    行政立法は一般的・抽象的なルール形成。行政指導は特定の相手や場面への働きかけとして見る
  • 行政手続法上の処分との違い
    行政手続法上の処分は、申請に対する処分・不利益処分などの手続規律と結びつけて整理する
  • 方式の入口
    行政指導では、相手方に趣旨・内容・責任者が明確になるように示されているかを確認する
  • 発展論点
    行政指導の中止等の求めは、行政手続法の下位カードで詳しく扱う
ミニクイズ
問1
行政指導と行政行為の区別として最も適切なものはどれか。
問2
行政指導に従わなかった相手方の扱いとして、本文の整理に最も合うものはどれか。
問3
「指導」という形式名と処分性の関係として最も安全な説明はどれか。

発展確認：行政指導の入口チェック
  • 主体
    行政機関が、行政目的の実現のために行っている働きかけかを見る
  • 相手方
    誰に対して協力を求めているのかを確認する。一般向けのルール形成なら行政立法側も疑う
  • 効果
    相手方の任意協力を前提にしているのか、一方的に法的効果を発生させているのかを分ける
  • 方式
    行政指導の趣旨・内容・責任者が相手方に分かる形になっているかを入口で確認する
発展確認：他制度との切り分け
  • 届出
    法令が予定する書類提出・通知の場面として見る。行政が協力を求める行政指導とは、手続上の位置づけが違う
  • 行政契約
    行政と相手方が合意で関係を作る場面。行政指導のような一方からの働きかけと区別する
  • 事実行為との関係
    行政指導は法的拘束力を直接生じさせない事実行為の一種として位置づけられることがある。ただし、情報提供・相談対応・実作業など他の事実行為とは、行政手続法上の規律を受ける任意協力の働きかけとして区別する
  • 行政上の強制
    法律の根拠に基づいて義務履行を確保する制度。任意協力を前提とする行政指導とは入口で分ける
  • 処分性
    取消訴訟で争えるかは、行政指導というラベルだけで決めず、権利義務への直接の影響などを別に確認する
