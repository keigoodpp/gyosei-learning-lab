行政指導の全体地図

「これは行政指導か、それとも処分・行政行為・行政立法か」を見分けるための基礎確認

一撃定義
POINT

行政指導とは、行政機関がその任務または所掌事務の範囲内において、一定の行政目的を実現するため、相手方の任意の協力を求める行為として整理する。

行政指導は法的拘束力を前提にしない。一方的に権利義務を変動させる行政行為や、一般的・抽象的なルールを定める行政立法とは区別する。行政手続法上の処分にも当たらないのが基本だが、名称だけで処分性を完全に否定しない。

まずイメージ

行政の活動形式は多様である。名称だけで制度を決めつけず、性質・効果・根拠を確認する。

  • 行政指導 ← このカードの中心
    相手方の任意の協力を求める行政活動。法的拘束力を前提にしない。一方的に権利義務を変動させる行政行為とは区別する
  • 行政行為
    行政庁が個別具体的な事件・対象について、一方的に権利義務などの法的効果を生じさせる行政活動。相手方の同意を要しない点で行政指導（任意の協力を前提とする）とは区別する（詳細は行政行為カードへ）
  • 行政立法
    行政機関が一般的・抽象的なルールを定める行政活動。個別の相手方に協力を求める行政指導とは段階が異なる（詳細は行政立法カードへ）
  • 行政手続法上の処分
    行政庁の処分（申請に対する処分・不利益処分）。行政指導は原則として処分には当たらないが、名称だけで処分性を完全に否定しない（詳細は行政手続法カードへ）
  • 届出
    一定事項を行政に知らせる手続。形式上の要件を満たして到達すれば届出義務が履行されたものとして扱われる場面。行政指導と混同しない（詳細は行政手続法カードへ）
  • 行政契約
    行政主体が相手方との合意に基づいて法律関係を形成する場面。一方的な法的効果を前提としない点で行政行為とは区別するが、任意の協力を求める行政指導とも異なる
  • 事実行為
    法的効果を直接生じさせない行政活動の総称。行政指導も事実行為として位置づけられることがあるが、行政上の強制（代執行・直接強制等）とは区別する
  • 処分性
    取消訴訟で争える処分（行政事件訴訟法上）かどうかの問題。行政指導という名称がついていても、個別の事案に応じて処分性を確認する（詳細は処分性カードへ）
よくある勘違い
  • 行政指導には従う必要がある（法的拘束力がある）、ではない → 行政指導は相手方の任意の協力を前提とし、法的拘束力を直接生じさせない
  • 行政指導は国民を法的に拘束する、ではない → 行政指導は任意の協力を求める行政活動として整理する。従わなかったことのみを理由とする不利益な取扱いは許されない方向で整理する
  • 行政指導は常に処分である、ではない → 行政指導は原則として行政手続法上の処分には当たらないが、名称だけで処分性を完全に否定しない
  • 行政指導に従わなければ当然に不利益を受ける、ではない → 行政指導に従わなかったことのみを理由として不利益な取扱いをすることは、許されない方向で整理する
  • 行政指導と行政行為は同じ、ではない → 行政指導は任意の協力を前提とし、行政行為のように一方的に法的効果を生じさせるものとは区別する
  • 行政指導と行政立法は同じ、ではない → 行政立法は一般的・抽象的なルール形成であり、個別の相手方に協力を求める行政指導とは性質・段階が異なる
  • 行政指導という名称なら取消訴訟で争えない、とは即断しない → 処分性は名称だけで決まらない。事案に応じて確認する
  • 行政指導の中止等の求めはこのカードで詳しく扱う、ではない → 中止等の求めは別カードまたは行政手続法の下位カードで扱う
場面で覚える
場面1
行政機関が特定の相手方に対して、任意の協力を求める。
→ 行政指導が問題になりうる。法的拘束力を前提にせず、相手方は任意に協力するかどうかを判断できる
場面2
行政庁が個別具体的な相手方に対して、一方的に権利義務に影響を与える判断をする。
→ 行政行為が問題になりうる。相手方の同意を要しない一方的な法的効果の場面であり、任意の協力を前提とする行政指導とは区別する
場面3
行政指導に従わなかった相手方に対して、行政が何らかの取扱いをしようとする。
→ 行政指導に従わなかったことのみを理由として不利益な取扱いをすることは、許されない方向で整理する。行政指導と強制手段（行政行為・行政上の強制）を混同しない
場面4
行政指導をする際に、相手方からその内容を書面で示すよう求めがあった。
→ 行政指導の方式が問題になりうる。行政指導の趣旨・内容・責任者を明確にする場面として整理する（行政手続法上の規定参照。条文の正確な内容は要確認）
場面5
行政機関が広く一般に向けたルールを定める。
→ 行政立法が問題になりうる。一般的・抽象的なルール形成の場面であり、個別の相手方に協力を求める行政指導とは区別する
場面6
「行政指導」と名付けられた行為を取消訴訟で争えるか問題になる。
→ 名称だけで処分性を完全に否定せず、事案に応じて確認する（詳細は処分性カードへ）
1分復習
「行政が相手方に何かを求めている場面」を見たら、制度の見分け方を確認する。
  • 任意の協力を求めているか → 行政指導が問題になりうる（一方的な法的効果を生じさせる行政行為とは区別する）
  • 一方的に権利義務を変動させているか → 行政行為の問題（任意の協力を前提とする行政指導とは区別する）
  • 一般的・抽象的なルール形成か → 行政立法の問題（個別の相手方への行政指導とは段階が違う）
  • 行政指導に従わなかったことのみを理由に不利益な取扱いをしていないか → 許されない方向で整理する
  • 行政指導の趣旨・内容・責任者が明確になっているか → 方式の場面として確認する
  • 行政指導という名称だけで処分性を完全に否定していないか → 名称だけで決めず、事案に応じて確認する
  • 中止等の求めの詳細はこのカードで扱わない → 別カードまたは行政手続法の下位カードへ

参考：発展確認・関連ページ
発展確認：行政指導の意義と任意性
  • 行政指導の意義
    行政機関がその任務または所掌事務の範囲内において、一定の行政目的を実現するため、相手方の任意の協力を求める行為として整理する（行政手続法32条以下参照。条文の正確な文言は要確認）
  • 任意の協力を前提とする
    行政指導は、相手方が任意に協力するかどうかを判断できる場面として整理する。法的拘束力を前提とした一方的な法的効果を生じさせる行政行為とは性質が異なる
発展確認：不利益取扱いの禁止方向
  • 従わなかったことのみを理由とする不利益取扱い
    行政指導に従わなかったことのみを理由として、相手方に不利益な取扱いをすることは許されない方向で整理する（行政手続法32条2項参照。条文の正確な文言・適用範囲は要確認）
  • 事実上の強制との関係
    任意の形式をとっていても、従わないと事実上不利益が生じる構造になっているかどうかは、別途確認が必要な場面がありうる。形式が任意であることだけで制度を完結させない
発展確認：行政指導の方式
  • 趣旨・内容・責任者の明確化
    行政指導をする際は、その趣旨・内容・責任者を明確にする場面として整理する（行政手続法35条参照。条文の正確な文言は要確認）
  • 書面による明示
    相手方から書面での明示を求められた場合の対応が問題になりうる場面として整理する（行政手続法35条参照。条文の正確な文言・例外については要確認）
  • 行政指導の中止等の求め
    このカードでは扱わない。別カードまたは行政手続法の下位カードで確認すること
発展確認：行政指導と処分性
  • 行政指導は常に処分ではないこと
    行政指導は原則として行政手続法上の処分には当たらないとして整理する。法的拘束力を前提にしない行政活動として位置づける
  • 名称だけで処分性を完全に否定しない
    行政指導という名称がついていても、事案の性質・効果・相手方への影響から処分性が問題になりうる場合がある。形式名だけで完全に否定しない（詳細は処分性カードへ）
