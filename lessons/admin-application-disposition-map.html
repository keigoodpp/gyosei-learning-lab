申請に対する処分の全体地図

過去問前に「私人の申請への応答」かどうかを見分ける入口確認

リード

申請に対する処分は、私人が行政庁に許認可などを求め、行政庁がそれに応答する場面で問題になります。

ただし、行政庁が相手に不利益を与える場面だからといって、すべて不利益処分になるわけではありません。

まずは「私人から申請が出ているか」「行政庁がその申請に応答しているか」「届出や行政指導と混ざっていないか」を分けて見ます。

一撃定義
POINT

申請に対する処分とは、私人からの申請に対して、行政庁が許可・不許可などの応答をする場面として整理する。

試験では、不利益処分、届出、行政指導、処分性、審査基準、標準処理期間、理由提示との区別が入口になります。

まず見る軸
  • 申請があるか
    私人が行政庁に許可、認可、免許などを求めているなら、申請に対する処分を疑う。行政庁が一方的に義務を課す場面なら、不利益処分を疑う。
  • 行政庁は何に応答しているか
    申請に対して許可、不許可、認可、拒否などをするなら申請に対する処分として見る。行政庁が任意の協力を求めているだけなら行政指導を疑う。
  • 届出と混ざっていないか
    申請は、行政庁の応答を求める入口になる。届出は、一定事項を行政庁に知らせることで手続上の効果が問題になる場面として整理する。申請と届出を同じものとして扱わない。
  • どの手続が問題か
    申請に対する処分では、審査基準、標準処理期間、拒否処分の理由提示などが入口になる。ただし、具体的な手続は行政手続法と個別法を確認する。
制度の切り分け
  • 不利益処分との違い
    申請に対する処分は、私人が出した申請に行政庁が応答する場面。不利益処分は、行政庁が相手方に義務を課し、または権利利益を制限する場面。不許可や拒否だからといって、直ちに不利益処分とは整理しない。
  • 届出との違い
    申請は、行政庁に許認可などの応答を求めるもの。届出は、一定の事項を行政庁に知らせるものとして整理する。行政庁に書類を出すという見た目だけで同じにしない。
  • 行政指導との違い
    行政指導は、行政庁が相手方に任意の協力を求める働きかけ。申請に対する処分は、申請への法的な応答として問題になる。行政庁と私人がやり取りしているというだけで同じにしない。
  • 審査基準との関係
    審査基準は、申請に対する処分をする際に、行政庁が判断の基準を示す場面で問題になる。審査基準があるからといって、申請者が必ず許可されるわけではない。
  • 標準処理期間との関係
    標準処理期間は、申請処理に通常要する期間の目安として問題になる。期間を過ぎたからといって、当然に許可されたことになるとは整理しない。
  • 理由提示との関係
    申請を拒否する処分では、なぜ拒否するのかを示す理由提示が問題になる。ただし、理由提示の不備がどのような効果を持つかは、個別に確認する。
  • 処分性との関係
    行政手続法上の処分として問題になることと、取消訴訟で争える処分性は関連するが、常に同じ問いとして処理しない。取消訴訟で争えるかは、処分性として別に確認する。
よくある勘違い
  • 申請が出ているから必ず許可される、ではない → 行政庁は申請に応答するが、許可・不許可などの判断は根拠法令と個別事情を確認する。
  • 不許可や拒否なら常に不利益処分、ではない → 私人の申請への応答として拒否される場面は、まず申請に対する処分として整理する。
  • 行政庁に書類を出せば全部届出、ではない → 許認可などの応答を求めているのか、一定事項を知らせる手続なのかを分ける。
  • 行政庁から働きかけがあれば申請に対する処分、ではない → 任意の協力を求める働きかけなら行政指導を疑う。
  • 行政手続法上の処分と取消訴訟の処分性は常に同じ、ではない → 取消訴訟で争えるかは、処分性として別に確認する。

発展確認：入口チェック
  • 申請の有無
    私人が許認可などを求める申請をしているかを見る。行政庁が一方的に命じる場面なら、不利益処分や行政行為側も疑う。
  • 応答の中身
    許可・不許可・認可・拒否など、申請への応答として位置づけられるかを確認する。
  • 書類提出の意味
    書類提出の見た目だけで申請・届出を決めず、行政庁の応答を求めるものか、一定事項を知らせるものかを分ける。
  • 争い方
    行政手続法上の整理と、取消訴訟で争える処分性は関連するが、同じ問いとして決めつけない。
