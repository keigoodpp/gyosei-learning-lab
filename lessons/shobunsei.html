行政法

処分性とは何か

一撃定義
POINT

処分性とは、行政庁の行為を取消訴訟で争えるかを決める入口チェック。外部への直接的な法的効果があって初めて処分と認められる。処分性がなければ裁判所の扉は開かない。

初心者向け説明

行政（国や自治体）が何かをしても、何でも裁判で争えるわけではありません。取消訴訟という行政訴訟を使うには、まず「訴えの対象が処分かどうか」を確認する必要があります。これが処分性の問題です。

最高裁判所は次のように定義しています。

「公権力の主体たる国または公共団体が行う行為のうち、その行為によって、直接国民の権利義務を形成しまたはその範囲を確定することが法律上認められているもの」
最高裁昭和39年10月29日判決（東京ごみ焼却場事件）

要するに、「公権力が、直接・法律に基づいて、国民の権利義務を変える行為」だけが処分です。

試験での見抜き方

問題文を読むとき、ここを確認する。

  • 行政庁（国・自治体等）の行為か
    単なる私人・私企業の行為は原則対象外。ただし法律に基づき公権力の行使を担う場合は主体名ではなく法的効果で見る
  • 外部（国民）に向けた行為か
    内部の通達・指示は国民を直接拘束しない
  • 権利義務・法的地位に直接影響するか
    将来的・間接的な影響は直接性の要件を満たさない
  • まだ準備行為・計画段階にとどまっていないか
    後続の処分を経て初めて具体的効果が生じる場合は弱い
  • 形式名（勧告・指導・計画）ではなく実質の効果を見ているか
    名称に惑わされず、現実の法的圧力で判断する
本番での判断手順

迷ったとき、この順で切る。

  1. 行政庁（国・自治体等）の行為か
  2. 外部（国民）に出ているか（通達・内部指示は除く）
  3. 権利義務・法的地位に直接効果があるか
  4. 準備行為・内部行為で止まっていないか
  5. 名称ではなく実質的な法的効果で判断しているか
具体例
処分性あり（取消訴訟○）
  • 建築確認（建築基準法に基づく確認）
  • 飲食店の営業許可・不許可
  • 税の賦課決定
  • 土地区画整理事業計画の決定
    ※最高裁大法廷平成20年9月10日判決で判例変更
  • 病院開設中止勧告
    ※事実上の強制力があるため処分性あり（最高裁平成17年7月15日判決）
処分性なし（取消訴訟×）
  • 行政指導（従うかどうかは任意）
  • 通達（行政内部の命令に過ぎない）
  • 用途地域の指定（一般的・抽象的で直接性なし）
よくあるひっかけ
  • 「行政が関わっている」だけで処分と見る → 外部への直接の法的効果がなければ処分性なし
  • 「将来影響しそう」だけで処分と見る → 将来的・間接的な影響は直接性を満たさない
  • 「勧告だから処分ではない」と短絡する → 実質的な強制力があれば処分性が問題になる
  • 「事業計画だから常に処分ではない」と決めつける → 後続手続と連動して権利関係に直接影響すれば処分性あり
  • 判例の名前と結論だけを丸暗記する → 判断軸（外部への直接効果）を押さえないと応用で詰まる
試験で問われるポイント
  • 行政指導は原則として処分性なし
    「従うか否かは相手方の任意」が根拠
  • 通達は処分性なし
    行政内部の規律であり国民を直接拘束しない
  • 土地区画整理事業計画の決定は処分性あり
    最高裁大法廷平成20年9月10日判決（判例変更）
  • 病院開設中止勧告は処分性あり
    最高裁平成17年7月15日判決（事実上の強制力が決め手）
  • 用途地域の指定は処分性なし
    不特定多数に対する一般的規制で直接性が欠ける
判例を場面で覚える
東京ごみ焼却場事件（最高裁昭和39年10月29日）
住民の近くに迷惑施設ができそうで不安。しかし争うには行政の行為が「直接」自分の権利義務を変えているかが問われる。この事件で処分性の定義が確立された。
→ 処分性のリーディングケース。定義の基礎として押さえる
土地区画整理事業計画決定に関する最高裁大法廷判決（平成20年9月10日）
「計画」という名前でも、区域内の建築行為等が制限されるなど、後続の手続と連動して権利関係に具体的な影響が及ぶ。
→ 事業計画の決定も処分性あり（判例変更）。「計画＝処分なし」は危険
病院開設中止勧告事件（最高裁平成17年7月15日）
形式は「勧告」で法的義務を直接課すものではない。しかし従わないと保険医療機関の指定に現実的な圧力がかかる。
→ 事実上の強制力を重視して処分性あり。「勧告＝処分なし」は危険
1分復習
名前を見るな、効果を見ろ。
争える入口は、外部への直接効果で決まる。
  • 処分性＝取消訴訟で争える行政行為かを判断する入口
  • 形式名ではなく、外部への直接の法的効果で見る
  • 準備行為・内部行為は直接性が弱く処分性が認められにくい
  • 「勧告」でも実質的強制力があれば処分性が問題になる
  • 「計画」でも後続手続と連動した直接影響があれば処分性あり
