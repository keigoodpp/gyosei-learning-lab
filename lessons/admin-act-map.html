行政法

行政行為の全体地図

「行政庁が何かをしたら全部行政行為」という雑な理解を解消するための基礎確認

一撃定義
POINT

行政行為とは、行政庁が個別具体的な事件・対象について、一方的に権利義務などの法的効果を生じさせる行政活動として整理する。

法律の根拠は、行政行為の定義そのものではなく、適法性確認の入口として別に整理する。取消訴訟で争えるかどうかは、行政事件訴訟法上の処分性として別に確認する。

まずイメージ

行政の行為形式は多様である。行政行為はその一種に過ぎない。

  • 行政立法
    一般的・抽象的なルール形成。法令・命令など。個別具体的な事件・対象への直接の法的効果とは区別する
  • 行政行為 ← このカードの中心
    個別具体的な事件・対象について、一方的に権利義務などの法的効果を生じさせる行政活動。許可・認可・特許・下命・禁止・確認など
  • 行政指導
    相手方の任意の協力を求める行政活動。法的強制力を前提にしない。法的効果を直接生じさせない点で行政行為と区別する
  • 行政契約
    行政主体と相手方の合意に基づいて法律関係を形成する場面。一方的な行政行為とは区別する
  • 行政計画
    将来の行政活動の指針として作られることが多い。個別具体的な法的効果を直接生じさせるか、処分性が認められるかは別途確認する
  • 事実行為
    法的効果を直接生じさせない行政活動。情報提供・案内・行政指導など。行政行為と混同しない
  • 行政上の強制
    義務履行を確保したり、緊急の場面で実力を及ぼしたりする段階の問題。行政行為とは段階が異なる（詳細は行政上の強制カードへ）
よくある勘違い
  • 行政庁が何かをしたら全部行政行為、ではない → 行政行為は個別具体的な事件・対象について一方的に法的効果を生じさせる場面に限られる
  • 行政行為なら必ず取消訴訟で争える、ではない → 取消訴訟で争えるかは処分性の問題として別に確認する
  • 行政指導は強く見えても、行政行為とは限らない → 行政指導は任意の協力を求める行政活動であり、法的強制力を前提にしない
  • 行政立法は行政行為の一種、ではない → 行政立法は一般的・抽象的なルール形成であり、個別具体的な法的効果を生じさせる行政行為とは区別する
  • 行政契約は一方的な行政行為の一形態、ではない → 行政契約は行政主体と相手方の合意に基づくものであり、一方的な行政行為とは区別する
  • 行政上の強制は行政行為と同じ段階の問題、ではない → 行政上の強制は義務履行確保や緊急場面での実力行使の問題であり、権利義務の法的効果を発生させる段階とは区別する
  • 法律の根拠がなければ行政行為ではない、ではない → 法律の根拠は行政行為の定義ではなく適法性確認の入口。根拠がない場合は適法性が問題になる
場面で覚える
場面1
行政庁が、特定の申請者に対して許可・不許可を決める。
→ 行政行為が問題になりうる（個別具体的な事件・対象について、一方的に法的効果を生じさせる場面として整理する。ただし、許可だから当然に裁量行為とは限らない。行政裁量は別カードで確認する）
場面2
行政庁が、広く一般に適用されるルールを定める。
→ 行政立法が問題になりうる。一般的・抽象的なルール形成であり、個別具体的な事件・対象について直接法的効果を生じさせる行政行為とは区別する
場面3
行政庁が、事業者に改善を求めているが、相手方が任意に応じるかどうかに委ねている。
→ 行政指導が問題になりうる。相手方の任意の協力を求める行政活動であり、法的強制力を前提にしない点で行政行為とは区別する
場面4
行政主体と相手方が合意して法律関係を作る。
→ 行政契約が問題になりうる。双方の合意に基づく場面であり、一方的に法的効果を生じさせる行政行為とは区別する
場面5
行政庁が既に課された義務を実力で実現しようとしている。
→ 行政上の強制が問題になりうる（義務履行確保の段階の問題。行政行為によって法的効果を発生させる段階とは区別する。詳細は行政上の強制カードへ）
場面6
行政の行為を取消訴訟で争えるかが問題になる。
→ 行政事件訴訟法上の処分性を確認する。講学上の行政行為と処分性を完全に同一視しない。行政計画が処分性の問題になることもある（詳細は処分性カードへ）
1分復習
「行政庁が何かをした場面」を見たら、行為形式の見分け方を確認する。
  • 一般的・抽象的なルール形成か → 行政立法の問題（行政行為とは区別する）
  • 双方の合意に基づくか → 行政契約の問題（一方的な行政行為とは区別する）
  • 任意の協力を求めているだけか → 行政指導の問題（法的強制力なし。行政行為とは区別する）
  • 義務履行確保や緊急の実力行使か → 行政上の強制の問題（行政行為とは段階が違う）
  • 個別具体的な事件・対象について、一方的に法的効果を生じさせているか → 行政行為が問題になりうる
  • 取消訴訟で争えるかは処分性として別に確認する → 講学上の行政行為と処分性を完全に同一視しない
  • 法律の根拠は適法性確認の入口 → 根拠がない場合は適法性が問題になる

発展確認：行政行為の効力（名称の確認）

行政行為には特有の効力があるとされる。このカードでは名称だけ確認し、詳細は行政行為の効力カードで扱う。

  • 公定力
    行政行為は、取り消されるまでは効力を前提に扱われる場面がある。詳細は別カードへ
  • 不可争力
    一定期間の経過により、相手方が争う道が制限される場合がある。詳細は別カードへ
  • 不可変更力
    一定の行為について、行政庁が後から自由に変更できないことが問題になる場合がある。詳細は別カードへ
  • 執行力
    義務の強制的実現と接続する場合があるが、具体的な強制手段には根拠法令・要件・手続が別途必要。行政上の強制カードで確認する
発展確認：行政裁量（入口のみ）
  • 覊束行為と裁量行為
    法律の要件・効果が一義的に定まる覊束行為と、行政庁に判断の幅がある裁量行為の区別が問題になる場面がある。詳細は行政裁量カードへ
  • 司法審査との関係
    裁量がある場合でも司法審査は及ぶ。裁量権の逸脱・濫用があれば取消事由になる。詳細は行政裁量カードへ
