民法

契約の全体地図

過去問演習前に契約で問われる場面をざっくり分類する

一撃定義
POINT

契約は、当事者の意思表示の合致によって成立し、当事者間に権利義務を発生させる法律行為として整理する。申込みと承諾の意思表示が合致した時点で契約が成立し、双方に給付義務が生じる場面として位置づける。

契約の問題は、まず「契約が成立しているかどうか」を見る。その上で、「契約成立後に義務が履行されているか」が問題なら債務不履行の場面として区別する。契約関係のない相手に損害を与えた場面は不法行為として区別する。

売買など物の取引が登場しても、代金支払請求や引渡請求は特定の相手への給付の請求として債権側の問題として整理する。所有権移転や登記が問題の中心なら物権変動側の問題として区別する。

まずイメージ
  • 契約
    当事者の意思表示の合致によって成立し、当事者間に権利義務を発生させる法律行為。申込みと承諾の合致が問題になる場面から整理する
  • 申込み
    相手方に対して契約を締結することを求める意思表示。相手の承諾があれば契約が成立する
  • 承諾
    申込みに対して同意する意思表示。申込みと承諾が合致した時点で契約が成立する
  • 意思表示の合致
    申込みと承諾の内容が対応して合致した状態。契約成立の要件として問題になる
  • 契約当事者
    契約によって権利義務を負う者。売買なら売主と買主、賃貸借なら賃貸人と賃借人などが問題になる
  • 給付
    契約によって発生した債務の内容として行うべき行為。代金の支払い・物の引渡し・サービスの提供などが給付として問題になる
  • 債権
    契約によって発生した、相手に給付を求める権利。売買なら代金支払請求権・引渡請求権などが問題になる
  • 債務
    契約によって発生した、相手への給付義務。売買なら代金支払義務・引渡義務などが問題になる
  • 履行
    債務者が債務の内容に従って給付を実現すること。履行があれば債務が消滅する
  • 債務不履行
    債務者が契約などによって発生した債務の内容に従った給付をしない場面の総称。契約成立後の問題として契約成立の問題とは区別して整理する
  • 不法行為
    故意または過失によって他人の権利または法律上保護される利益を侵害し、損害を発生させた場合に損害賠償義務が発生する場面。既存の契約関係とは別の根拠による問題として整理する
  • 解除
    契約成立後に、法定または約定の事由に基づいて契約関係を解消する場面。原則として遡及効が問題になるが、賃貸借など継続的契約では将来に向かって効力を生じる例外があるため、常に遡及的に消滅するとは整理しない。債務不履行が契約解除の事由として問題になる場面がある
  • 取消し
    意思表示の瑕疵（詐欺・強迫・錯誤など）を理由に、有効に成立した契約の効力を遡及的に消滅させる場面。解除とは異なり、意思表示の段階の問題として整理する
  • 物権変動
    契約の履行として所有権が移転する場面など、物に対する権利の変動が問題になる場面。売買代金請求や引渡請求とは問題の焦点が異なる
試験で問われるポイント
契約では、誰と誰が何に合意したかを先に見る
  • 契約の問題は、まず申込みと承諾の意思表示が合致しているかを確認する方向で整理する
    どの当事者間でどのような給付義務が発生したかを先に押さえる
契約成立の問題と、契約成立後の債務不履行の問題を分ける
  • 契約が有効に成立しているかどうかが問題の中心なら、契約成立の問題として整理する
    契約は成立しているが義務が履行されないことが問題なら、債務不履行として区別して整理する
契約責任と不法行為責任を混同しない
  • 契約責任は、既存の契約によって発生した債務の不履行を根拠とする場面に位置づく
    不法行為責任は、故意または過失による他人の権利・利益の侵害を根拠とする場面として区別して整理する。両者が同一の事実から競合する場面もある
売買契約で物が出ても、代金支払請求や引渡請求は債権側の問題として見る
  • 物の取引が問題文に登場しても、特定の相手への代金支払請求や引渡請求が問題の中心なら債権側として整理する
    所有権の帰属や登記の対抗関係が問題の中心なら物権変動側として区別して整理する
解除と取消しを混同しない
  • 解除は、契約成立後に法定または約定の事由に基づいて契約関係を解消する場面として整理する。原則として遡及効が問題になるが、賃貸借など継続的契約では将来に向かって効力を生じる例外がある
    取消しは、意思表示の段階の瑕疵（詐欺・強迫・錯誤など）を理由に契約の効力を遡及的に消滅させる場面として区別して整理する
無効と取消しを混同しない
  • 無効は、法律行為が最初から効力を持たない場面として整理する
    取消しは、いったん有効に成立した法律行為の効力を、取消権者の意思表示によって遡及的に消滅させる場面として区別して整理する
場面で覚える
場面1
AがBに対して商品の購入を申し込み、BがAの申込みに承諾した。AとBの意思表示が合致し、AにはBへの代金支払義務が、BにはAへの商品引渡義務が発生した場面である。
→ 契約成立（意思表示の合致による権利義務の発生）
場面2
AはBとの売買契約に基づいて、BがAに対して代金支払義務を負っている。AはBに対して代金の支払いを求める立場にある。この場面では、特定の相手Bへの給付の請求関係が問題になる。
→ 債権（売買代金請求権）
場面3
AはBとの売買契約に基づいて、BがAに対して商品引渡義務を負っている。AはBに対して商品の引渡しを求める立場にある。この場面では、特定の相手Bへの給付の請求関係が問題になる。
→ 債権（引渡請求権）
場面4
AとBの間で売買契約が成立した。しかしBは履行期が到来しても代金を支払わなかった。契約は成立しているが、Bが義務を履行しない場面である。
→ 債務不履行（契約成立後の義務不履行の場面）
場面5
AとBの間に契約関係はなかった。Aの過失により、Bの財物が損傷した。既存の契約とは別の根拠で、Bに損害賠償の問題が生じている場面である。
→ 不法行為（契約関係によらない損害賠償の場面）
場面6
AはBに土地を売った。売買代金の支払いと引渡しの問題が終わった後、AからBへの所有権移転の登記が問題になった。この場面では物に対する権利の変動が中心の問題になる。
→ 物権変動・対抗要件（物に対する権利の変動が問題の中心）
場面7
Aは詐欺を受けてBとの売買契約を締結した。Aは詐欺を理由として意思表示を取り消す立場にある。この場面では、意思表示の段階の瑕疵が問題の中心になる。
→ 取消し（意思表示の瑕疵を理由とする場面）
場面8
AとBの間で売買契約が成立した。Bが履行期に履行しないため、AはBの債務不履行を理由として契約関係を解消しようとしている場面である。
→ 解除（契約成立後の法定事由に基づく契約の効力消滅の場面）
よくある勘違い
  • 契約は単なる口頭の約束ではなく、法律上の権利義務を発生させる法律行為として見る → 意思表示の合致によって当事者間に給付義務が発生する点を先に押さえる
  • 契約が成立したからすぐに債務不履行、とは整理しない → 債務不履行は、契約などによって発生した義務が履行されない場面として、契約成立の問題とは区別して整理する
  • 契約関係がないから常に不法行為、とは整理しない → 不法行為は、故意または過失による権利・利益の侵害を根拠とする場面として、契約の有無とは別に問題になる場合がある
  • 物が出てくる契約でも、代金支払請求や引渡請求が問題の中心なら債権側の問題として見る → 所有権の帰属や登記の対抗関係が問題の中心になって初めて物権変動側の問題として区別する
  • 解除と取消しを同じ制度として扱わない → 解除は契約成立後の事由に基づく場面、取消しは意思表示の段階の瑕疵に基づく場面として区別して整理する
  • 無効と取消しを同じ制度として扱わない → 無効は法律行為が最初から効力を持たない場面、取消しは取消権者の意思表示によって遡及的に効力が消滅する場面として区別して整理する
1分復習
契約は意思表示の合致で成立する法律行為。問題文では「契約成立」か「義務不履行」かを先に切り分ける。
  • 契約では、誰と誰が何に合意したかを先に確認する
  • 契約成立の問題と、契約成立後の債務不履行の問題を分ける
  • 契約責任と不法行為責任を分ける
  • 物が出ても、代金支払請求や引渡請求が中心なら債権側の問題として見る
  • 解除と取消しを分ける。無効と取消しを分ける
ミニクイズ
問1
次のうち、契約成立の場面として整理されるのはどれか。
問2
次のうち、契約成立後の債務不履行の場面として整理されるのはどれか。
問3
契約・物権変動・不法行為・取消しの区別について正しい説明はどれか。
