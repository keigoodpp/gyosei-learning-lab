民法

使用者責任の全体地図

使用者責任・被用者自身の不法行為責任・共同不法行為・監督義務者責任を見分ける入口

一撃定義
POINT

使用者責任は、ある事業のために他人を使用する者（使用者）が、被用者がその事業の執行について第三者に加えた損害について、一定の場合に損害賠償責任を負う制度として整理する。

使用者と被用者の関係があること、被用者が第三者に損害を与えたこと、被用者の行為が「事業の執行について」といえることが入口の確認事項になる。被用者自身の不法行為責任とは別の問題として整理する。共同不法行為・監督義務者責任とも別制度として区別する。

まずイメージ
  • 使用者責任
    ある事業のために他人を使用する者が、被用者がその事業の執行について第三者に損害を加えた場合に損害賠償責任が問題になる場面
  • 使用者
    ある事業のために他人を使用する者。被用者を選任し指揮命令する立場にある者として整理する
  • 被用者
    使用者に使用されて事業に従事する者。使用者責任では、実際に損害を生じさせた行為の主体として整理する
  • 事業の執行について
    被用者の行為が使用者の事業の執行に関するものといえるかどうかを見る場面。使用者責任が問題になるかどうかの入口として確認する
  • 第三者
    使用者・被用者の関係の外にあり、被用者の行為によって損害を受けた者。使用者責任における被害者として整理する
  • 損害
    被用者の行為によって第三者に生じた財産的・非財産的な不利益。使用者責任の場面では第三者に生じた損害が問題になる
  • 被用者自身の不法行為責任
    被用者が直接の加害行為を行った場合に、被用者自身が負い得る不法行為責任。使用者の損害賠償責任とは別に整理する
  • 使用者の損害賠償責任
    被用者がその事業の執行について第三者に損害を加えた場合に、使用者が被害者に対して負い得る損害賠償責任。被用者自身の不法行為責任とは別に整理する
  • 選任監督上の注意
    使用者側の免責と関わる場面として整理する。使用者が被用者の選任および監督について相当の注意をしたと認められる場合に問題になる。入口では責任発生の問題と区別して別枠で整理する
  • 免責
    使用者責任の場面で、一定の要件を満たした場合に使用者の損害賠償責任が認められない方向で問題になる場面。選任監督上の注意と関わる。入口では抗弁側の論点として整理する
  • 求償
    使用者が被害者に損害賠償をした後に、被用者に対して一定の範囲で支出の負担を求める場面。被害者への責任発生とは別の段階の問題として整理する
  • 共同不法行為
    複数の加害者の行為が関わって一つの損害が生じた場合に、各加害者が連帯して損害賠償責任を負う場面。使用者と被用者の関係を基礎とする使用者責任とは別の制度として区別して整理する
  • 監督義務者責任
    責任能力がない者が損害を与えた場合に、その者の監督義務者が問われ得る損害賠償責任。使用者責任とは発生根拠が異なる別の制度として区別して整理する
  • 責任能力
    自己の行為の責任を弁識する能力。責任能力が正面から問題になる場面ではまず監督義務者責任の問題として確認する。ただし、責任能力が問題になる者が被用者として使用者の事業の執行について第三者に損害を加えた事案では、使用者責任との関係も別途確認する
試験で問われるポイント
使用者責任では、誰が使用者で誰が被用者かを先に見る
  • 使用者と被用者の関係があるかを先に確認する
    使用者・被用者の関係がない場面では、使用者責任の問題として整理しない
被用者が第三者に損害を与えた場面かを見る
  • 被用者の行為によって第三者に損害が生じているかを確認する
    被用者の行為が起点になっており、その結果として第三者に損害が生じている場面かを先に見る
被用者の行為が「事業の執行について」といえるかを見る
  • 被用者の行為と使用者の事業の関連性を確認する
    使用者の事業の執行に関するものといえるかどうかが問題になる。使用者の事業と無関係な私的行為の場面では、この要件の充足が問われる
被用者自身の不法行為責任と、使用者の責任を分けて整理する
  • 被用者が不法行為の直接の主体であるとしても、使用者の責任は別の問題として整理する
    使用者が責任を負う場面を確認しても、被用者自身の不法行為責任が当然に消えるとは整理しない
使用者責任は、複数の加害者が関わる共同不法行為とは別に整理する
  • 使用者責任は使用者・被用者関係を基礎とする場面として整理する
    複数の行為者の行為が重なって損害が生じた場面は共同不法行為の問題として整理し、使用者責任と混同しない
責任能力が正面から問題になる場面では、まず監督義務者責任を確認する
  • 責任能力が正面から問題になる場面ではまず監督義務者責任の問題として確認する
    ただし、責任能力が問題になる者が被用者として使用者の事業の執行について第三者に損害を加えた事案では、使用者責任との関係も別途確認する。両者を混同しない
選任監督上の注意・免責は、入口では「抗弁側の論点」として整理する
  • 使用者の責任が問題になる入口を確認したうえで、抗弁側の論点として整理する
    使用者が被用者の選任および監督について相当の注意をしたかどうかは、責任発生の入口確認とは別の段階で問題になる
使用者が被害者に賠償した後の求償は、被害者への責任とは別に整理する
  • 求償は使用者が賠償をした後の被用者との内部的な問題として整理する
    被害者への損害賠償責任が問題になる段階と、使用者から被用者への求償が問題になる段階を混同しない
場面で覚える
場面1
X会社の従業員AがX会社の業務を執行する中で、過失により第三者Bの財物に損害を与えた。AにはAの不法行為責任が問われ得る。別にX会社の損害賠償責任が問題になる場面である。
→ 使用者責任（被用者の行為と事業の執行との関係が問題になる場面）
場面2
店舗の従業員Aが接客中に過失により客Bの所持品を壊した。AにはAの不法行為責任が問われ得る。別にAを使用する店舗（使用者）の損害賠償責任が問題になる場面である。
→ 使用者責任（接客業務の執行中の行為として事業の執行性が問題になる場面）
場面3
配達業者の従業員Aが配達業務として移動中に、過失により通行人Bにけがをさせた。AにはAの不法行為責任が問われ得る。別にAを使用する配達業者（使用者）の損害賠償責任が問題になる場面である。
→ 使用者責任（配達業務の執行中の行為として事業の執行性が問題になる場面）
場面4
X会社の従業員Aが、X会社の業務とは無関係に、私的な用事で移動中に第三者Bに損害を与えた。この場面では「事業の執行について」といえるかどうかが問題になる。
→ 「事業の執行について」の要件が問題になる場面（私的行為と業務の関係性を確認する）
場面5
AとBが別々に加害行為をし、その結果が重なって第三者Cに一つの損害が生じた。複数の加害者の行為が損害に関わっている場面であり、各加害者の責任が連帯して問題になる。
→ 共同不法行為（使用者責任の問題ではなく、複数加害者の連帯責任として整理する場面）
場面6
責任能力の有無が問題となる者Aが行為によりBに損害を与えた。Aの行為についての監督義務者の責任が問われている場面である。責任能力が正面から問題になるこの場面ではまず監督義務者責任を確認する。なお、Aが被用者として使用者の事業の執行について第三者に損害を加えた事案であれば、使用者責任との関係も別途確認する。
→ 監督義務者責任が問題になる場面（Aが被用者として事業執行中の損害であれば使用者責任との関係も別途確認する）
場面7
X会社の従業員AがX会社の業務執行中に第三者Bに損害を与えた。BはAに損害賠償を求めることが問題になる場面である。AはAの不法行為責任として整理し、X会社の使用者責任とは別に確認する。
→ 被用者自身の不法行為責任（使用者の責任が問題になる場面とは別に確認する場面）
場面8
X会社が被害者Bに損害賠償をした後、X会社がAに対して一定の範囲で支出の負担を求めることが問題になる場面である。被害者への損害賠償責任が問題になる段階とは別に整理する。
→ 求償（被害者への責任発生とは別段階の内部的な問題として整理する場面）
よくある勘違い
  • 店や会社が登場したら必ず使用者責任として整理するわけではない → 使用者と被用者の関係があること、被用者の行為が「事業の執行について」といえることを先に確認する
  • 被用者が行為をした場面ならば常に使用者責任として整理するわけではない → 被用者の行為が「事業の執行について」の場面かどうかを確認する
  • 「事業の執行について」といえるかどうかが入口の問題になる → 使用者の事業と無関係な私的行為の場面では、この要件の充足が問われる
  • 使用者の損害賠償責任が問題になる場面でも、被用者自身の不法行為責任が当然に消えるとは整理しない → 被用者の不法行為責任と使用者の損害賠償責任は別の問題として整理する
  • 使用者責任と共同不法行為を同じ制度として扱わない → 使用者責任は使用者・被用者関係を基礎とする場面、共同不法行為は複数の加害者の行為が重なって損害が生じる場面として区別して整理する
  • 使用者責任と監督義務者責任を同じ制度として扱わない → 使用者責任は使用者・被用者関係を基礎とする場面、監督義務者責任は責任能力が問題になる者の監督義務者の責任として区別して整理する。ただし、責任能力が問題になる者が被用者として事業の執行について損害を加えた事案では、両者の関係を別途確認する
  • 使用者が被害者に賠償した後の求償は、被害者への責任発生の問題とは別に整理する → 求償は使用者と被用者の内部的な問題として、被害者への損害賠償責任が問題になる段階とは区別して整理する
  • 入口では、まず「誰が使用者で誰が被用者か」「その行為が使用者の事業に関係するか」を先に確認する → 選任監督上の注意・免責・求償は責任発生の入口確認とは後の段階で問題になる
1分復習
使用者・被用者・第三者の三者関係で見る。「事業の執行について」が入口になる。被用者の不法行為責任と使用者の責任を分ける。
  • 使用者責任は、使用者・被用者・第三者の三者関係で見る
  • 被用者が第三者に損害を与えた場面かを先に確認する
  • 「事業の執行について」が入口の確認事項になる
  • 被用者自身の不法行為責任と使用者の損害賠償責任を別の問題として整理する
  • 共同不法行為とは別制度として区別して整理する。責任能力が正面から問題になる場面ではまず監督義務者責任を確認し、被用者として事業執行中の損害であれば使用者責任との関係も別途確認する
  • 選任監督上の注意・免責・求償は責任発生の入口とは別の段階で整理する
