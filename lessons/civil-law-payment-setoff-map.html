相殺・弁済の全体地図

過去問演習前に弁済と相殺の場面をざっくり分類する

一撃定義
POINT

弁済は、債務者（または弁済する資格を持つ者）が、債務の内容に従った給付を行うことによって債務を消滅させる場面の総称である。誰が弁済するのか、誰が受け取るのかを先に整理する。

相殺は、互いに同種の給付を目的とする債権を対立して持ち合う当事者の一方が、一定の要件のもとで意思表示によって双方の債権を対当額で消滅させる場面の総称である。弁済とは異なり、実際に給付を行わずに債権を消滅させる点を先に押さえる。

弁済と相殺は、どちらも債権が消滅する場面に位置づけられるが、消滅の仕組みが異なる。弁済は給付による消滅であり、相殺は意思表示による対当消滅である。

まずイメージ
  • 弁済
    債務の内容に従った給付によって債務が消滅する場面の総称。誰が弁済するのか、誰が受け取るのかを整理する出発点になる
  • 弁済者
    債務の本旨に従った給付を行う者。通常は債務者自身が弁済者となるが、第三者が弁済者となる場面も問題になる
  • 受領権者
    弁済を受け取る権限を持つ者。債権者またはその代理人などが該当する。受領権限のない者への弁済が有効かどうかが問題になる場面がある
  • 相殺
    互いに同種の給付を目的とする対立する債権を、一方の当事者の意思表示によって対当額で消滅させる場面の総称。給付なしに債権が消える点が弁済と異なる
  • 自働債権
    相殺を主張する側（相殺者）が持つ債権。相殺の意思表示によってこの債権を行使することになる
  • 受働債権
    相殺を主張する相手方が持つ債権。相殺の意思表示によって消滅の対象となる側の債権
  • 相殺適状
    相殺が認められるかを判断するために確認する状態。双方の債権が同種の給付を目的とし、対立して存在することに加え、相殺を主張する側が用いる自働債権の弁済期到来を落とさず確認する。受働債権の弁済期や期限の利益の扱いは別に問題になる
  • 相殺禁止
    相殺が認められない場面。悪意による不法行為に基づく損害賠償債権を受働債権とする場合のように、法律が相殺を禁止する場面がある
試験で問われるポイント
弁済では、誰が弁済するのか・誰が受け取るのかを先に見る
  • 弁済者が誰であるかを先に確認する
    債務者自身が弁済者である場面と、第三者が弁済者になる場面を分けて整理する
  • 受領権者が誰であるかを先に確認する
    受領権限のない者への弁済が有効とされる場合・されない場合の区別が問題になる場面がある
弁済は、債務の内容に従った給付によって債務が消える場面
  • 債務の本旨に従った給付が弁済の要素になる
    給付の内容・時期・場所・方法などが債務の内容に従っているかが問題になる場面がある
相殺では、自働債権と受働債権を分ける
  • 相殺を主張する側の債権が自働債権、相手方の債権が受働債権になる
    どちらが自働債権でどちらが受働債権かを混同しないことが出発点になる
相殺では、対立する同種債権があるかを先に見る
  • 双方の債権が同種の給付を目的とし、対立して存在することが相殺の前提になる
    同種ではない給付を目的とする場合、相殺の問題にならない点を先に押さえる
相殺適状では、同種性・対立性・弁済期・相殺禁止の有無が問題になる
  • 相殺適状として問題になる要素を雑に飛ばさない
    相殺を主張する側が用いる自働債権について、弁済期が到来しているかを落とさず確認する。受働債権の弁済期や期限の利益の扱いは別に問題になるため、「お互い債権があれば常に相殺できる」とは整理しない
  • 相殺禁止の場面が問題になる場合がある
    悪意による不法行為に基づく損害賠償債権を受働債権とする相殺のように、相殺が禁止される場面を無視しない
弁済と相殺を同じ「支払い」として混ぜない
  • 弁済は給付による消滅、相殺は意思表示による対当消滅として区別する
    どちらも債権が消滅する場面だが、消滅の仕組みが異なる。問題文で弁済の問題か相殺の問題かを先に見分ける
場面で覚える
場面1
AはBに対して金銭債務を負っている。AがBの求める金額をBに交付し、Bがこれを受け取ることで債務が消滅した。AがBに対する債務の内容に従って給付を行った場面である。
→ 弁済（給付による債務消滅）
場面2
AはBに対して金銭債務を負っている。AとBの間で合意がなく、Bの知人CがAの代わりにBへ金銭を給付した。AとCの間で問題となる弁済者の資格の問題が生じる場面である。
→ 第三者弁済（弁済者が誰かを先に確認する場面）
場面3
AはBに対して金銭を支払った。しかしBには受領権限がなく、実際の債権者は別の人Cであった。この場面では、受領権者でない者への弁済が問題になる。
→ 受領権限のない者への弁済（受領権者かどうかが問題になる場面）
場面4
AはBに対して100万円の金銭債権を持っている。BもAに対して100万円の金銭債権を持っている。AがBに対して相殺の意思表示をすると、双方の債権が対当額で消滅する場面が生じる。
→ 相殺（AがBへの自働債権でBのAへの受働債権を対当消滅させる場面）
場面5
AはBに対して100万円の金銭債権（自働債権）を持っている。BはAに対して80万円の金銭債権（受働債権）を持っている。Aが相殺の意思表示をすることで、80万円の範囲で双方の債権が消滅し、Aには残り20万円の債権が残る。
→ 相殺（対当額での消滅。自働債権と受働債権の額が異なる場面）
場面6
AはBに対して金銭債権を持っている。BはAに対して、建物の引渡しを目的とする債権を持っている。AがBへの金銭債権を自働債権として相殺を主張しようとした。しかし双方の給付の種類が異なる場面である。
→ 同種の給付を目的としない場面（相殺適状の要件が問題になる場面）
場面7
AはBから悪意による不法行為を受け、損害賠償債権をBに対して持っている。BはAに対して別の金銭債権を持っていた。BがAへの金銭債権を自働債権として、AのBへの損害賠償債権（受働債権）を相殺で消滅させようとした場面である。
→ 相殺禁止の問題（悪意による不法行為に基づく損害賠償債権を受働債権とする相殺が問題になる場面）
よくある勘違い
  • 弁済は単なる「支払い」ではない → 債務の内容に従った給付によって債務が消滅する場面として整理する。給付の内容・方法・相手方が問題になることがある
  • 誰に対して給付を行っても弁済になるわけではない → 受領権者でない者への弁済が問題になる場面では、弁済の有効性や効果が争われることがある
  • 相殺は一方的に何でも差し引ける制度ではない → 相殺適状の要件（同種性・対立性・弁済期・相殺禁止の有無など）を確認する方向で整理する
  • 自働債権と受働債権を混ぜない → 相殺を主張する側が自働債権を持ち、相手方の債権が受働債権になる。どちらがどちらかを先に確認する
  • 相殺適状を「お互い債権があれば相殺できる」とだけ済ませない → 同種の給付を目的とするか、弁済期が到来しているかなど、要件の要素を雑に飛ばさない
  • 相殺禁止の場面を無視しない → 受働債権の種類によっては相殺が禁止される場面がある。悪意による不法行為に基づく損害賠償債権を受働債権とする相殺のように、相殺禁止が問題になる場面を整理する
  • 弁済と相殺を同じ制度として扱わない → 弁済は給付による消滅、相殺は意思表示による対当消滅として区別して整理する
1分復習
弁済は給付による債務消滅。相殺は意思表示による対立債権の対当消滅。仕組みが違う。
  • 弁済の場面では、弁済者と受領権者を先に確認する
  • 弁済は債務の内容に従った給付によって債務が消滅する場面
  • 相殺の場面では、自働債権（相殺者側）と受働債権（相手方側）を分ける
  • 相殺の場面では、対立する同種債権があるかを先に見る
  • 相殺適状と相殺禁止を雑に飛ばさない
  • 弁済と相殺はどちらも債権が消滅する場面だが、消滅の仕組みが異なる

問1

問3
