国家賠償法・損失補償の全体地図

過去問で何を聞かれているかを見抜くための基礎確認

一撃定義
POINT

国家賠償法は、違法な公権力の行使などによって損害が生じた場合に、国や公共団体が賠償責任を負う場面を整理する法律である。

損失補償は、適法な公権力の行使によって特定の人に特別の犠牲が生じた場合に、その損失を補う考え方である。

過去問では、まず違法な行為による損害賠償なのか、適法な行為による補償なのかを見分ける。

まずイメージ
  • 国家賠償法1条
    公務員が職務を行うについて、故意または過失によって違法に他人へ損害を与えた場面
  • 国家賠償法2条
    道路・河川などの公の営造物の設置または管理に瑕疵があり、他人に損害が生じた場面
  • 公権力の行使
    行政処分のような権力的作用に限らず、公的な行政活動を広く含み得る。ただし、私経済作用や、営造物の設置管理として2条で見る場面とは区別する
  • 職務を行うについて
    公務員の行為が職務と関係しているかを見る場面
  • 違法性
    公務員の行為が法的に許される範囲を外れているかを見る場面
  • 故意・過失
    公務員にわざとまたは注意義務違反があるかを見る場面
  • 営造物の設置管理の瑕疵
    道路・河川・施設などが通常備えるべき安全性を欠いているかを見る場面
  • 損失補償
    適法な公権力行使によって、特定の人に特別の犠牲が生じた場合に補償を考える場面
試験で問われるポイント
国家賠償法1条
  • 公務員、職務関連性、公権力の行使、違法性、故意・過失、損害の発生を分けて見る
    公権力の行使は行政処分のような権力的作用に限らず、公的な行政活動を広く含み得る。私経済作用や2条の営造物管理は区別する
  • 被害者に対する賠償責任の主体はまず国または公共団体として整理する
    公務員個人の直接責任については本文では断定しない（要確認）。求償は被害者への賠償とは別段階の問題として整理する
国家賠償法2条
  • 公の営造物、設置または管理の瑕疵、損害との因果関係を見る
    故意・過失そのものを前面の要件として見るのではなく、設置または管理の瑕疵と損害との因果関係を中心に確認する
1条と2条の違い
  • 1条は人の違法な職務行為、2条は物や施設の設置管理の瑕疵として整理する
    公務員の行為が問題か、施設・設備の状態が問題かを最初に見分ける
損失補償
  • 違法ではなく適法な行政活動によって特別の犠牲が生じた場面で見る
    補償が問題になるのは、適法な行為による特定人への集中した負担の場面
国家賠償と損失補償の違い
  • 違法なら国家賠償、適法だが特別の犠牲なら損失補償を検討する
    まず行政活動が違法か適法かを確認してから、どちらの問題かを判断する
場面で覚える
場面1
警察官が違法な職務行為で損害を与えた。
→ 国家賠償法1条（公務員の違法な職務行為による賠償責任）
場面2
行政職員の職務に関係する行為で損害が生じた。
→ 職務を行うについて（行為が職務と関係しているかを確認する）
場面3
市道に大きな穴が放置され、通行人がけがをした。
→ 国家賠償法2条（公の営造物の設置管理の瑕疵）
場面4
公共施設の管理不備で事故が起きた。
→ 営造物の設置管理の瑕疵（施設が通常備えるべき安全性を欠いているかを見る）
場面5
道路工事のため適法に土地利用を制限された。
→ 損失補償を検討（適法な公権力行使による特別の犠牲の場面）
場面6
違法な処分で損害が生じた。
→ 国家賠償を検討（違法行為による損害賠償の場面）
場面7
適法な規制だが特定人に重い負担が集中した。
→ 損失補償を検討（特別の犠牲に対する補償が問題になる場面）
場面8
施設そのものではなく公務員の判断が問題になっている。
→ 1条か2条かを分ける（人の行為か物の瑕疵かで適用条文が変わる）
よくある勘違い
  • 損害があれば必ず国家賠償になるわけではない → まず行政活動が違法か適法かを確認する
  • 国家賠償法1条と2条を混同しない → 1条は人の違法な職務行為、2条は物や施設の設置管理の瑕疵
  • 2条では故意・過失そのものは前面の要件ではない → 設置または管理の瑕疵と損害との因果関係を中心に見る（公務員個人の過失とは別の問題として整理する）
  • 損失補償は違法行為の責任ではない → 適法行為による特別の犠牲を補う考え方
  • 損失補償は誰にでも認められるわけではない → 特定の人に特別の犠牲が生じた場合に問題となる
  • 違法なら国家賠償、適法なら損失補償と単純に見えるが、まず事案の構造を確認する
1分復習
違法か適法か、人の行為か施設の瑕疵かをまず見分ける。
  • 公務員の違法な職務行為なら国家賠償法1条
  • 道路・河川・施設などの管理不備なら国家賠償法2条
  • 違法な行政活動で損害なら国家賠償
  • 適法な行政活動で特別の犠牲なら損失補償
  • 人の行為か、施設の瑕疵かを分ける
  • 違法性と故意・過失を分けて見る
  • 損害と因果関係も確認する
ミニクイズ
問1
市の職員が、徴税業務の過程で違法な滞納処分を行い、事業者の財産に損害が生じた。この場面でまず見るべきものはどれか。
問2
国道に陥没箇所が相当期間補修されないまま放置されており、通行中の自転車がはまって転倒した。この場面でまず見るべきものはどれか。
問3
適法な公共事業により、特定の土地所有者に特別な負担が生じた。この場面でまず見るべきものはどれか。
