地方自治法の全体地図

過去問で何を聞かれているかを見抜くための基礎確認

一撃定義
POINT

地方自治法は、都道府県・市町村などの地方公共団体の仕組み、議会と長の関係、住民の権利、事務の種類、国等の関与などを整理する法律である。

過去問では、まず組織の問題か、住民参加の問題か、事務の種類の問題か、国等の関与の問題かを見分ける。

まずイメージ
  • 普通地方公共団体
    都道府県と市町村。地方自治法の基本単位
  • 議会
    条例制定、予算議決、決算認定などを通じて地方公共団体の意思決定に関わる機関
  • 長
    知事・市町村長。地方公共団体を代表し、事務を管理執行する機関
  • 条例
    地方公共団体が議会の議決により定める法規
  • 規則
    長などがその権限に基づいて定めるルール
  • 直接請求
    住民が一定数の署名を集めて、条例制定改廃、議会解散、議員や長の解職などを求める制度
  • 住民監査請求
    住民が財務会計上の違法・不当な行為などについて監査委員に監査を求める制度
  • 住民訴訟
    住民監査請求を経たうえで、財務会計上の違法な行為などについて裁判所で争う制度
  • 自治事務
    地方公共団体が処理する事務のうち、法定受託事務以外のもの
  • 法定受託事務
    国などが本来果たすべき役割に関わる事務を、法律に基づいて地方公共団体が処理するもの
  • 国等の関与
    国や都道府県が地方公共団体に対して助言、勧告、是正要求などを行う場面
試験で問われるポイント
議会と長
  • どちらの権限か、議決が必要か、長が執行する場面かを見分ける
    条例制定や予算議決は議会、事務の管理執行は長として整理する
条例と規則
  • 議会が定める条例か、長などが定める規則かを区別する
    制定主体の違いが問われやすい
直接請求
  • 何を請求する制度か、署名数や請求先の違いが問われやすい
    条例制定改廃、議会解散、議員や長の解職など、目的によって制度が分かれる
住民監査請求・住民訴訟
  • 財務会計上の違法・不当な行為が入口になる点と、住民訴訟には住民監査請求の前置が必要な点が問われやすい
    住民訴訟をいきなり提起することはできない
自治事務と法定受託事務
  • 事務の種類によって国等の関与のあり方が変わる点に注意する
    法定受託事務は国の関与が強く、自治事務は地方の自主性が強い場面が多い
国等の関与
  • 地方自治の尊重と国の関与の限界が問題になりやすい
    助言・勧告・是正要求など、関与の形式の違いも確認する
場面で覚える
場面1
県や市町村そのものの種類が問われている。
→ 普通地方公共団体（都道府県と市町村が基本単位）
場面2
議会が条例を制定する。
→ 条例・議会（議会の議決により定める法規）
場面3
市長が事務を管理・執行する。
→ 長の権限（地方公共団体を代表し事務を管理執行する）
場面4
住民が一定数の署名を集めて条例の制定を求める。
→ 直接請求（住民が署名で制度を動かす場面）
場面5
住民が違法な公金支出を問題にして監査委員に監査を求める。
→ 住民監査請求（財務会計上の違法・不当な行為が入口）
場面6
住民監査請求を経た後に裁判所で財務会計上の違法を争う。
→ 住民訴訟（住民監査請求の前置が必要）
場面7
地方公共団体が通常処理する事務の種類を確認する。
→ 自治事務（法定受託事務以外の地方が主体的に処理する事務）
場面8
国が地方公共団体に是正を求める。
→ 国等の関与（助言・勧告・是正要求などの形式で行われる）
よくある勘違い
  • 条例と規則を混同しない → 条例は議会が定め、規則は長などが定める
  • 議会の権限と長の権限を混同しない → 議決は議会、管理執行は長として分ける
  • 直接請求は何を求めるかによって制度が分かれる → 条例制定改廃、議会解散、解職請求などを区別する
  • 住民訴訟はいきなり提起できない → 住民監査請求の前置が必要
  • 住民監査請求・住民訴訟は財務会計上の行為が中心 → 一般的な政策決定の違法とは区別する
  • 自治事務と法定受託事務は国等の関与の場面で重要になる → 事務の種類によって関与のあり方が変わる
1分復習
組織か、住民参加か、事務の種類か、国等の関与かをまず見分ける。
  • 都道府県・市町村なら普通地方公共団体
  • 条例なら議会、規則なら長など
  • 事務の管理執行なら長
  • 署名で制度を動かすなら直接請求
  • 財務会計上の違法・不当を監査に出すなら住民監査請求
  • 監査請求後に裁判所で争うなら住民訴訟
  • 地方が主体的に処理する事務なら自治事務
  • 国の役割に関わる委任的な事務なら法定受託事務
  • 国から地方への助言・勧告・是正要求なら国等の関与
ミニクイズ
問1
市の住民が、一定数の署名を集めて条例の制定を求めようとしている。この場面でまず見るべきものはどれか。
問2
住民が、市の違法な公金支出を問題にして監査委員に監査を求めようとしている。この場面でまず見るべきものはどれか。
問3
住民が、住民監査請求を経た後に、財務会計上の違法な行為について裁判所で争おうとしている。この場面でまず見るべきものはどれか。

地方自治法は地方公共団体の組織、住民参加、事務、国等の関与を整理する。行政手続法・行政不服審査法・行政事件訴訟法は行政活動への手続・不服申立て・訴訟を整理する。国家賠償法・損失補償は行政活動によって損害や損失が生じた場合の金銭的救済を整理する。
