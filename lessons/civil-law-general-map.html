民法総則の全体地図

過去問演習前に民法総則で問われる場面をざっくり分類する

一撃定義
POINT

民法総則は、民法全体に共通して使われる基本ルールを整理する分野である。

過去問では、まず意思表示の問題か、代理の問題か、時効の問題か、能力の問題かを見分ける。

まずイメージ
  • 人
    権利義務の主体になる自然人
  • 法人
    法律上、権利義務の主体になれる団体
  • 権利能力
    権利義務の主体となることができる地位
  • 意思能力
    自分の行為の結果を判断できる能力
  • 行為能力
    単独で有効に法律行為をする能力
  • 制限行為能力者
    未成年者、成年被後見人、被保佐人、被補助人のこと
  • 意思表示
    契約などの法律効果を発生させる意思の表示
  • 心裡留保
    真意ではないことを自分では分かっている意思表示
  • 虚偽表示
    相手方と通じて、真意でない意思表示をする場面
  • 錯誤
    重要な勘違いがある意思表示
  • 詐欺・強迫
    だまされたり脅されたりして意思表示をした場面
  • 代理
    本人のために代理人が法律行為をする場面
  • 無権代理
    代理権がない者が代理人として法律行為をした場面
  • 表見代理
    代理権があるように見える事情があり、相手方保護が問題になる場面
  • 時効
    一定期間の経過によって権利の取得や消滅が問題になる場面
  • 取得時効
    一定期間の占有などにより権利取得が問題になる場面
  • 消滅時効
    一定期間権利を行使しないことで権利消滅が問題になる場面
  • 時効の援用
    時効の効果を主張する場面
試験で問われるポイント
能力
  • その人が単独で有効な法律行為をできるかを見る
    権利能力・意思能力・行為能力の三つを区別して整理する
制限行為能力者
  • 本人保護と取引安全のバランスを見る
    未成年者・成年被後見人・被保佐人・被補助人の保護のしくみを整理する
意思表示
  • 表示された意思と真意・動機・外部事情のズレを見る
    心裡留保・虚偽表示・錯誤・詐欺・強迫のどれに当たるかをまず分類する
心裡留保・虚偽表示・錯誤
  • どのタイプの意思表示の問題かをまず分類する
    心裡留保は自分が真意でないと知っている場面、虚偽表示は相手方との通謀がある場面、錯誤は重要な勘違いがある場面として見分ける
詐欺・強迫
  • 誰がだましたか、誰に対して取り消しを主張できるかを見る
    第三者によるだましと取消しの主張範囲が問われる場面がある
代理
  • 代理権、顕名、代理行為、効果帰属を整理する
    本人のために代理人が誰に対して意思表示したかを整理する
無権代理・表見代理
  • 本人保護と相手方保護のどちらが問題かを見る
    無権代理は代理権がない場合、表見代理は代理権があるように見える事情がある場合に検討する
時効
  • 取得時効か消滅時効か、援用が必要かを見る
    期間経過だけでなく援用の問題も整理する
場面で覚える
場面1
未成年者が単独で契約した。
→ 制限行為能力者
場面2
真意ではないと分かって意思表示した。
→ 心裡留保
場面3
相手と通じて嘘の売買をした。
→ 虚偽表示
場面4
重要な勘違いをして契約した。
→ 錯誤
場面5
だまされて契約した。
→ 詐欺
場面6
代理人が本人のために契約した。
→ 代理
場面7
代理権がないのに代理人として契約した。
→ 無権代理
場面8
長期間の経過で権利取得・消滅が問題になった。
→ 時効
よくある勘違い
  • 意思能力と行為能力を混同しない → 意思能力は自分の行為の結果を判断できるかの問題、行為能力は単独で有効に法律行為ができるかの問題
  • 制限行為能力者制度は、本人保護が中心だが取引安全も問題になる → 保護の程度は類型によって異なる
  • 心裡留保、虚偽表示、錯誤、詐欺、強迫を同じものとして扱わない → 意思と表示のズレの原因と相手方の関与の有無が異なる
  • 代理では、誰のために、誰が、誰に対して意思表示したかを整理する → 顕名がない場合の取扱いにも注意する
  • 無権代理と表見代理を混同しない → 無権代理は代理権のない場合の問題、表見代理は外観への信頼保護の問題
  • 時効は、期間経過だけでなく援用も問題になる → 援用権者の範囲も確認する
1分復習
意思表示・代理・時効・能力のどの問題かをまず見分ける。
  • 人・法人なら権利主体
  • 判断能力なら意思能力
  • 単独で法律行為できるかなら行為能力
  • 未成年者などなら制限行為能力者
  • 意思と表示のズレなら意思表示
  • 真意でない表示なら心裡留保
  • 通謀なら虚偽表示
  • 勘違いなら錯誤
  • だまし・脅しなら詐欺・強迫
  • 本人のために別人が行為するなら代理
  • 代理権がなければ無権代理
  • 代理権があるように見えれば表見代理
  • 期間経過なら時効
ミニクイズ
問1
AはBに対し、本当は売るつもりがないのに、冗談のつもりで自分の時計を売ると言った。この場面でまず見るべきものはどれか。
問2
AはBの代理人と名乗って契約したが、実際には代理権を与えられていなかった。この場面でまず見るべきものはどれか。
問3
Aが長期間にわたり土地を占有しており、一定期間の経過による権利取得が問題になっている。この場面でまず見るべきものはどれか。
