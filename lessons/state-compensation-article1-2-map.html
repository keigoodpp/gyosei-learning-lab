国家賠償法1条と2条の全体地図

過去問前に「人の職務行為」か「公の営造物の瑕疵」かを見分ける入口整理

国家賠償法では、まず「人の行為の問題か」「物・施設の状態の問題か」を分けます。

公務員の職務行為による違法な加害なら1条を疑います。

道路、河川、学校、公園などの公の営造物の設置・管理に問題があるなら2条を疑います。

どちらも国または公共団体の責任が問題になりますが、見る入口は同じではありません。

一撃定義
POINT

国家賠償法1条は、公務員が公権力の行使として職務を行う場面で、違法に他人へ損害を与えた場合を入口にします。

国家賠償法2条は、道路・河川その他の公の営造物の設置または管理に瑕疵があり、それによって損害が生じた場合を入口にします。

試験では、1条は「人の違法な職務行為」、2条は「公の営造物の瑕疵」と見分けます。

まず見る軸
  • 人の行為か、物・施設の状態か
    公務員の判断、命令、処分、取締り、職務上の行為が問題なら1条を疑う。道路、河川、学校、公園、公共施設などの状態や管理が問題なら2条を疑う
  • 1条では何を見るか
    公務員か、公権力の行使か、職務行為か、違法性があるか、故意・過失があるか、損害と因果関係があるかを見る
  • 2条では何を見るか
    公の営造物か、設置・管理に瑕疵があるか、その瑕疵と損害に因果関係があるかを見る。2条では、公務員個人の過失を入口にしない
  • 損失補償や民法不法行為と混ざっていないか
    国家賠償は、違法な公権力行使や営造物の瑕疵による損害賠償として問題になる。損失補償は、適法な公権力行使により特別の犠牲が生じる場面で問題になる。民法不法行為との比較は重要だが、国家賠償法の要件を先に見る
よくある勘違い
  • 国または公共団体が相手なら同じ、ではない → 1条か2条か、または損失補償など別制度かを分ける
  • 公務員が出てくれば直ちに1条、ではない → 問題の中心が職務行為なのか、営造物の状態や管理なのかを見る
  • 公共施設が出てくれば直ちに2条、ではない → 施設の設置・管理の瑕疵が問題になっているかを確認する
  • 2条は公務員個人の過失責任、ではない → 公の営造物の設置・管理の瑕疵を入口にする
  • 国家賠償と損失補償は同じ、ではない → 違法な行為・瑕疵による賠償か、適法な公権力行使による特別の犠牲の補償かを分ける
制度の切り分け
1条と2条の違い
1条は公務員の職務行為による違法な加害。2条は公の営造物の設置・管理の瑕疵。
→ 国または公共団体が相手になる点だけで同じにしない
1条の入口
公務員が職務上、公権力の行使として行った行為が問題になる。その行為が違法か、故意・過失があるか、損害と因果関係があるかを確認する。
→ 公務員が出てくるだけで直ちに1条とはしない
2条の入口
道路、河川、学校、公園などの公の営造物の状態や管理が問題になる。設置・管理の瑕疵があったか、その瑕疵と損害がつながるかを見る。
→ 2条を公務員の過失責任として整理しない
国家賠償と損失補償
国家賠償は、違法な行為や瑕疵により損害が生じた場面で問題になる。損失補償は、適法な公権力行使により特別の犠牲が生じた場面で問題になる。
→ 「国がお金を払う」だけで同じ制度にしない
民法不法行為との関係
国家賠償も損害賠償の問題なので、故意・過失、損害、因果関係など民法不法行為と似た語が出る。
→ 国家賠償法の条文上の要件を飛ばして、民法だけで処理しない
行政処分・処分性との関係
ある行政処分が違法かどうかと、その結果として国家賠償責任が生じるかは、同じ問いではない。
→ 取消訴訟で争えるか、国家賠償を請求できるかは別に確認する
1分復習

国家賠償法1条と2条は、まず入口を分ける。

公務員の職務行為による違法な加害なら1条。

公の営造物の設置・管理の瑕疵なら2条。

  • 国や公共団体が相手だから同じ、とは考えない
  • 2条では、公務員個人の過失ではなく、公の営造物の設置・管理の瑕疵を入口にする
  • 損失補償、民法不法行為、取消訴訟とも混ぜない
