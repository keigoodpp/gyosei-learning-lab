情報公開法の開示・不開示入口

一撃定義
POINT

行政機関情報公開法の開示請求では、まず行政文書か、何人も請求できるか、不開示情報か、部分開示できるかを分ける。個人名を見ても、すぐ5条1号に飛びつかず、事業情報かどうかを先に確認する。

まずイメージ
開示請求の入口
対象は行政機関が保有する行政文書。請求できる人は、原則として「何人も」。特別な理由や利害関係を足さない。
→ 入口資格と、実際に開示されるかは別問題
不開示情報の入口
個人識別情報など、5条の不開示情報に当たるかを見る。ただし、事業を営む個人の当該事業に関する情報は5条1号から除かれる。
→ 個人名だけで即5条1号にしない
部分開示の入口
一部に不開示情報があっても、容易に区分して除け、有意な情報が残るなら、残部開示を検討する。
→ 全部開示・全部不開示の二択にしない
よくある勘違い
  • 「請求者には特別な利害関係が必要」と思う → 3条は「何人も」。利害関係は入口資格の一般要件ではない
  • 「個人名が出たら常に5条1号」と思う → まず、事業を営む個人の当該事業に関する情報かを確認する
  • 「事業を営む個人の事業情報も5条1号」と思う → 5条1号の個人識別情報からは除かれ、法人等・事業情報側で考える
  • 「一部に不開示情報があれば文書全体を必ず不開示」と思う → 部分開示の可否を別に見る
  • 「部分開示は常に義務」と思う → 容易に区分して除けるか、有意な情報が残るかを確認する
場面で覚える
行政文書かどうか
職員が職務上作成・取得し、組織的に用いられ、行政機関が保有している文書等かを見る。
→ 「正式決裁済みだけ」と狭めない
何人も請求できるという入口
開示請求権者は広く捉える。国民・住民・国内居住者に限るという限定を勝手に加えない。
→ 請求できることと、開示されることを混ぜない
個人識別情報
氏名などで特定個人を識別できる情報は、5条1号の不開示情報に当たり得る。
→ 秘密にしたい情報かだけで判断しない
事業を営む個人の当該事業に関する情報の除外
個人が営む事業の取引・営業などに関する情報は、個人名が含まれていても5条1号の入口から除かれる。
→ 法人等・事業情報側で検討する
部分開示
不開示情報部分を除いた残りを開示できるかを検討する。行政機関に要約文書を新しく作らせる制度ではない。
→ 「黒塗り等で除いた残部」と「新規作成」を分ける
1分復習
個人名に飛びつくな。
事業情報か、部分開示できるかを先に分ける。
  • 行政文書かどうかが、開示請求対象の入口
  • 開示請求は、原則として「何人も」できる
  • 個人識別情報を見る前に、事業を営む個人の当該事業に関する情報かを確認する
  • 一部に不開示情報があっても、部分開示の可否を別に検討する
  • 部分開示は残部開示であり、新しい概要文書の作成ではない
