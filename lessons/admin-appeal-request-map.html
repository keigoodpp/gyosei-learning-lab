行政法

審査請求の全体地図

行政不服審査法クラスタで審査請求を他制度と混同しないための入口確認

冒頭結論
POINT

審査請求は、行政庁の処分や法令に基づく申請への不作為について、裁判所ではなく行政側の審査庁に見直しを求める手続である。

結論は判決ではなく裁決として整理する。取消訴訟、再調査の請求、再審査請求、執行停止とは入口を分けて読む。

入口判定
  • 行政庁の処分に不服があるか
    営業停止命令、許可取消し、不許可など、行政庁の処分を争う場面なら、処分についての審査請求を疑う。
  • 法令に基づく申請をしたのに行政庁が動かない不作為か
    単なる問い合わせへの返事待ちや、法令上の申請ではない要望への未回答まで広げない。
  • 裁判所ではなく行政側の審査庁に申し立てる場面か
    審査請求は、処分庁への単なる要望や行政指導への反発ではなく、法律の定めに従って審査庁が審理し裁決する入口として見る。
  • 審査請求だけで執行停止まで当然に求めていないか
    審査請求をしただけで当然に処分の効力や執行が止まるとは整理しない。執行停止は別制度として確認する。
  • 再調査の請求や再審査請求と混ぜていないか
    審査請求を中心に読み、再調査の請求や再審査請求は個別法上の定めや段階の違いが問題になる別入口として留保する。
比較表

行政事件訴訟 裁判所 処分の取消しなど 判決など 審査請求

執行停止 審査庁など 効力・執行などを一時的に止めるか 停止の判断 審査請求本体
ミニ事例
例1：処分についての審査請求
営業停止命令を受けた事業者が、行政側の審査庁に見直しを求める。
→ 行政庁の処分に不服があるので、処分についての審査請求として読む。
例2：不作為についての審査請求
許可申請をしたのに、行政庁が相当期間何も判断しない。
→ 法令に基づく申請への不作為についての審査請求を疑う。
例3：行政事件訴訟
営業停止命令を争うために裁判所へ取消訴訟を提起する。
→ 裁判所で争う行政事件訴訟であり、審査請求とは入口が違う。
試験ポイント
  • キーワードを見る
    「不服」「裁決」「審査庁」「審理員」「処分」「不作為」「期間」「執行停止」という語に注目する。
  • 語だけで判断しない
    誰に、何を、どの手続で争うかを確認する。裁判所なら行政事件訴訟、行政側の審査庁なら審査請求を疑う。
  • 審査庁と処分庁を分ける
    審査請求は単に処分庁へ文句を言う制度ではない。上級行政庁の有無などで審査庁が変わり得るため、必ず処分庁が判断すると断定しない。
  • 審理員は入口だけ押さえる
    原則として審理員が審理手続を整理する場面があるが、例外や詳細は別論点として深入りしない。
  • 裁決の大枠を見る
    却下は入口要件で門前払い、棄却は理由なし、認容は請求人側の主張を認める方向、という入口整理にとどめる。
  • 期間制限を意識する
    処分についての審査請求には、原則として処分があったことを知った日の翌日から起算して三月、処分の日の翌日から起算して一年という期間制限がある。ただし、正当な理由などの例外があり得るため、例外なく不可とは断定しない。
ひっかけ注意
  • 審査請求は裁判ではない。結論は判決ではなく裁決。
  • 審査請求をしただけで当然に処分の効力が止まるわけではない。
  • 申請者本人への不許可を不利益処分に戻さない。申請に対する処分としての不服対象になり得るが、不利益処分そのものとは別入口で整理する。
  • 不作為は、法令に基づく申請に対する不作為として読む。単なる返事待ちに広げない。
  • 再調査の請求、再審査請求、取消訴訟、執行停止と混ぜない。
  • 審査請求期間を例外なしに断定しない。
  • 審査請求を必ず経なければ取消訴訟を提起できない、と不服申立前置を一般化しすぎない。
