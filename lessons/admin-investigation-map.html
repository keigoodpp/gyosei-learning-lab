行政法

行政調査の全体地図

行政調査・行政指導・行政行為・行政上の強制・行政罰・刑事捜査を混同しないための入口整理

行政調査は、行政が行政目的を実現するために、事実・資料・状況を把握する活動です。

ただし、調査という言葉だけで、相手方が拒めるか、法律上の権限があるか、実力行使できるか、罰則があるか、取消訴訟で争えるかは決まりません。

まずは「任意協力なのか」「法律上の質問検査・立入検査なのか」「行政上の強制や即時強制と混ざっていないか」を分けて見ます。

一撃定義
POINT

行政調査とは、行政目的のために、行政機関が事実・資料・状況を把握する活動です。

試験では、任意調査、質問検査・立入検査、行政指導、行政上の強制、即時強制、行政罰、刑事捜査との区別が入口になります。

まず見る軸
  • 何をしているか
    相手に行動を促しているのか、事実や資料を集めているのかを分ける。行動を促すなら行政指導、情報収集なら行政調査を疑う
  • 相手方の協力は任意か
    任意の聞き取りや資料提出依頼なら、相手方の任意協力を前提に考える。法律上の質問検査・立入検査なら、根拠法令・対象・要件・手続を確認する
  • 拒否したらどうなるか
    拒否したら直ちに行政が物理的に調査を実現できる、とは限らない。個別法で罰則や不利益な効果が定められている場合でも、それは調査そのものの実力行使とは分けて考える
  • 行政上の強制や即時強制と混ざっていないか
    行政上の強制は義務の履行確保や急迫状態への対応として問題になる。行政調査はまず情報収集活動として捉え、強制手段そのものと同一視しない
よくある勘違い
  • 行政調査＝行政指導、ではない → 事実・資料・状況を把握しているのか、行動を促しているのかを分ける
  • 行政調査＝行政行為、ではない → 調査は通常、判断の前提となる情報収集として問題になる
  • 任意調査＝質問検査・立入検査、ではない → 個別法上の根拠・対象・要件・手続の有無を確認する
  • 調査権限がある＝当然に物理的実力行使までできる、ではない → 調査拒否への制裁や不利益効果とは分ける
  • 行政調査なら処分性の検討不要、ではない → 取消訴訟で争えるかは処分性として別に確認する
  • 行政調査＝刑事捜査、ではない → 目的や手続の違いを見つつ、刑事手続との関係も即断しない
制度の切り分け
行政指導との違い
行政指導は相手方に一定の行動を促す任意協力の働きかけ。行政調査は事実・資料・状況を把握する活動。
→ どちらも相手方と接触するが、目的が違う
行政行為との違い
行政行為は、個別具体的な相手に法的効果を発生させる行政活動として整理する。行政調査は、通常はその前提となる情報収集として問題になる。
→ 調査に関する行為が取消訴訟で争えるかは、処分性として別に確認する
任意調査と質問検査・立入検査
任意調査は相手方の協力を前提にする。質問検査・立入検査は、個別法上の根拠に基づいて、質問・検査・立入りなどが問題になる。
→ 法律上の調査権限があることと、当然に物理的実力行使までできることは同じではない
行政上の強制との違い
行政上の強制は、義務の履行確保や急迫状態への対応として問題になる。行政調査は情報収集活動なので、行政上の強制そのものとして整理しない。
→ 調査拒否への制裁や不利益効果がある場合でも、調査そのものの強制とは分ける
行政罰との違い
行政罰は義務違反に対する制裁として問題になる。調査拒否に罰則がある場合でも、罰則の問題と調査活動そのものは分けて考える。
→ 制裁の有無だけで、調査そのものを物理的に実現できるとは考えない
刑事捜査との違い
行政調査は行政目的のための情報収集。刑事捜査は犯罪の嫌疑を前提に刑事責任追及へ向かう手続。
→ 行政調査だから刑事手続の規律が無関係になる、とも、刑事捜査と同じになる、とも即断しない
1分復習
  • 行政調査は「情報を集める活動」
  • まず、行動を促す行政指導と分ける
  • 次に、任意調査か、個別法に基づく質問検査・立入検査かを見る
  • 最後に、行政上の強制・即時強制・行政罰・刑事捜査と混ぜない
