民法

不法行為の全体地図

過去問演習前に不法行為で問われる場面をざっくり分類する

一撃定義
POINT

不法行為は、故意または過失によって他人の権利または法律上保護される利益を侵害し、損害を生じさせた場合に、加害者が被害者に対して損害賠償責任を負う場面として整理する。

契約上の義務の不履行（債務不履行）とは発生根拠が異なる。「損害が発生したから不法行為」とは整理しない。契約関係がある場面でも不法行為が問題になる場合がある。

まずイメージ
  • 不法行為
    故意または過失によって他人の権利または法律上保護される利益を侵害し、損害を生じさせた場合に損害賠償責任が問題になる場面。契約によらない損害賠償の発生根拠として位置づける
  • 故意
    結果の発生を認識しながら行為すること。故意と過失は区別される概念であり、同じ意味として扱わない
  • 過失
    注意を尽くせば結果を回避できたにもかかわらず、注意を怠って結果を発生させること
  • 権利侵害
    他人が有する権利が侵害された状態。かつては権利侵害が不法行為の成立に厳格に問われた
  • 法律上保護される利益
    権利として明確に認められてはいないが、法的な保護に値する利益。権利侵害と並んで不法行為の侵害対象として整理する
  • 損害
    不法行為によって生じた財産的・非財産的な不利益。損害賠償の範囲として問題になる
  • 因果関係
    加害行為と損害との間に原因と結果の関係があること。不法行為の成立には加害行為と損害の因果関係が問題になる
  • 損害賠償
    不法行為または債務不履行によって生じた損害を補填するための金銭的な給付。財産的損害と非財産的損害（精神的損害）の双方が問題になる場面がある
  • 使用者責任
    被用者が事業の執行について第三者に損害を与えた場合に、使用者も損害賠償責任を負う場面。被用者自身の不法行為責任とは別に整理する
  • 共同不法行為
    複数の加害者の行為が関わって一つの損害が生じた場合に、各加害者が連帯して損害賠償責任を負う場面
  • 責任能力
    自己の行為の責任を弁識する能力。責任能力がない者が損害を与えた場合は監督義務者の責任が別に問題になる
  • 契約責任
    契約によって発生した債務の不履行を根拠とする損害賠償責任。不法行為責任とは発生根拠が異なる
  • 債務不履行
    契約などによって発生した債務の内容に従った給付をしない場面の総称。不法行為とは区別して整理する
試験で問われるポイント
不法行為では、誰が誰の権利または法律上保護される利益を侵害したかを先に見る
  • 加害者が誰か、被害者が誰かを先に整理する
    権利または法律上保護される利益のどれが侵害されたかを確認してから、損害賠償責任の問題に進む
故意または過失が問題になる
  • 故意と過失は区別される概念として整理する
    故意は結果の発生を認識しながら行為すること、過失は注意を怠って結果を発生させることとして区別する
損害の発生と、加害行為との因果関係を見る
  • 損害が発生していることと、その損害と加害行為の間の因果関係を確認する方向で整理する
    損害が発生しているだけでは不法行為として整理しない。加害行為との因果関係が問題になる
契約上の債務不履行とは根拠を分ける
  • 契約上の義務の不履行による損害賠償は、まず債務不履行側の問題として整理する
    契約関係がある場面であっても、不法行為責任が競合して問題になる場合を一律に否定しない
使用者責任は、被用者の行為と事業執行性を区別して整理する
  • 使用者が責任を負う場面として整理する際は、被用者の不法行為と事業の執行との関係を確認する方向で整理する
    被用者自身の不法行為責任と、使用者が負う責任は別の問題として整理する
共同不法行為は、複数の加害者が関わる損害賠償責任として整理する
  • 複数の行為者の行為が重なって損害が生じた場面として整理する
    使用者責任と混同しない。共同不法行為は各加害者の連帯責任の問題として整理する
責任能力は、責任を負う主体の問題として整理する
  • 責任能力がない者が損害を与えた場面では、その者自身の不法行為責任の問題と、監督義務者の責任の問題を区別して整理する
    使用者責任・共同不法行為とは別の問題として整理する
場面で覚える
場面1
AはBとの売買契約に基づいて、BがAに対して代金支払義務を負っている。AはBに対して代金の支払いを求める立場にある。この場面では、契約による債権の行使が問題になる。
→ 債権（契約上の請求）
場面2
AはBとの売買契約に基づいて、BがAに対して商品引渡義務を負っている。AはBに対して商品の引渡しを求める立場にある。この場面でも、契約による債権の行使が問題になる。
→ 債権（契約上の請求）
場面3
AとBの間に契約関係はなかった。AがBの自転車を壊してしまい、Bに財産的損害が生じた。この場面では、契約によらない権利侵害を根拠とする損害賠償の問題が生じている。
→ 不法行為（財産侵害による損害賠償）
場面4
AとBの間に契約関係はなかった。Aの不注意によりBがけがをし、Bに身体的損害が生じた。この場面では、過失による身体侵害を根拠とする損害賠償の問題が生じている。
→ 不法行為（身体侵害による損害賠償）
場面5
AがBの名誉を毀損する行為をした。AとBの間に契約関係はなく、Bの法律上保護される利益が侵害されている。この場面では、名誉侵害を根拠とする損害賠償の問題が生じている。
→ 不法行為（法律上保護される利益の侵害による損害賠償）
場面6
X会社の従業員AがX会社の業務を執行する中で、第三者Bに損害を与えた。AにはAの不法行為責任があり、別にX会社が損害賠償責任を負う場面かどうかが問題になる。
→ 使用者責任（被用者の行為と事業執行性の確認が問題になる場面）
場面7
AとBが共同して行動し、その結果Cに損害が生じた。複数の加害者の行為が重なってCの損害が生じている場面であり、各加害者の責任が連帯して問題になる。
→ 共同不法行為（複数加害者の連帯責任が問題になる場面）
場面8
自己の行為の責任を弁識する能力が問題となる者Aが行為によりBに損害を与えた。Aの不法行為責任と、Aの監督義務者の責任を区別して整理する必要がある場面である。
→ 責任能力（責任を負う主体の問題として整理する場面）
よくある勘違い
  • 損害が発生したから必ず不法行為として整理するわけではない → 不法行為の根拠は故意または過失による権利または法律上保護される利益の侵害にある
  • 契約違反による損害賠償は、まず債務不履行側の問題として整理する → 不法行為として整理する前に、契約上の義務の不履行として位置づけられるかを確認する
  • 契約関係があるから不法行為責任が一律に成立しないとは整理しない → 契約関係がある場面でも、不法行為責任が競合して問題になる場合がある
  • 不法行為は、契約外の権利または法律上保護される利益の侵害として見る → 契約上の義務の不履行とは発生根拠が異なる
  • 故意と過失を同じ意味にしない → 故意は結果発生の認識、過失は注意義務の懈怠として区別して整理する
  • 権利侵害と損害発生を混同しない → 権利または利益の侵害が先にあり、その結果として損害が生じる関係として整理する
  • 使用者責任と共同不法行為を同じ制度として扱わない → 使用者責任は使用者・被用者関係を基礎とする場面、共同不法行為は複数加害者が関わる場面として区別して整理する
  • 不法行為を慰謝料（精神的損害の賠償）だけの制度として狭めない → 財産的損害の賠償も不法行為による損害賠償の対象として問題になる
1分復習
不法行為は、契約外の権利・利益侵害による損害賠償責任として見る。債務不履行とは根拠を分けて整理する。
  • 不法行為は、契約外の権利または法律上保護される利益の侵害として整理する
  • 故意または過失が問題になる（故意と過失は区別する）
  • 権利または法律上保護される利益の侵害を確認する
  • 損害の発生と加害行為との因果関係を確認する
  • 契約上の債務不履行とは根拠を分けて整理する
  • 使用者責任・共同不法行為・責任能力は別枠で整理する
ミニクイズ
問1

問2
次のうち、不法行為ではなく債務不履行として整理すべき場面はどれか。
問3
