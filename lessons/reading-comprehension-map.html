文章理解の全体地図

設問が何を求めているかを見抜くための基礎確認

一撃定義
POINT

文章理解は、文章の内容を暗記する問題ではなく、本文の構造と設問の要求を読み分ける問題である。

過去問では、要旨、内容一致、空欄補充、文章整序、接続関係、指示語などを見分けることが問われる。

まずイメージ
  • 要旨把握
    文章全体で筆者が一番言いたいことをつかむ
  • 内容一致
    本文に書かれていることと選択肢が合っているかを見る
  • 空欄補充
    前後の文脈から、空欄に入る語句や文を選ぶ
  • 文章整序
    文と文のつながりを見て、自然な順番に並べる
  • 接続関係
    しかし・つまり・たとえば・したがって、などの関係を見る
  • 指示語
    これ・それ・このような、などが何を指すかを確認する
  • 対比
    AではなくB、昔と今、一般論と筆者の主張などを見分ける
  • 具体例
    具体例が何を説明するために出ているかを見る
試験で問われるポイント
要旨把握
  • 最終段落や逆接後に筆者の主張が出やすい
    文章全体の方向を見る。細部の事実ではなく、筆者が繰り返し言いたいことを探す
内容一致
  • 本文にない言い過ぎ・すり替え・範囲拡大に注意する
    本文に書かれていないことを断定している選択肢は外す
空欄補充
  • 空欄の前後だけでなく、段落全体の流れを見る
    直前の一文だけで決めず、段落の話題の流れと接続語のサインを確認する
文章整序
  • 指示語・接続語・具体例・結論の順番を見る
    指示語が何を受けるかを手がかりに、前後のつながりを確認しながら並べる
接続関係
  • 逆接・理由・具体例・結論のサインを拾う
    「しかし」は前後の転換、「なぜなら」は理由、「たとえば」は具体例、「つまり」は結論のサイン
場面で覚える
場面1
設問が「本文全体の趣旨として最も適切なものはどれか」と聞いている。
→ 要旨把握（細部ではなく、文章全体で筆者が伝えたいことを探す）
場面2
選択肢が本文と合っているかどうかを問われている。
→ 内容一致（本文に書かれていないことを断定している選択肢は外す）
場面3
空欄に入る一文または語句を選ばせる問題が出た。
→ 空欄補充（直前だけでなく段落全体の流れと接続語のサインを確認する）
場面4
文を正しい順番に並べる問題が出た。
→ 文章整序（指示語・接続語を手がかりに前後のつながりを確認する）
場面5
「しかし」の後に筆者の主張が出てきた。
→ 逆接に注目（前の内容を受けながら、筆者の本音や転換が出てくる場面）
場面6
「このように」「それ」が何を受けるか迷った。
→ 指示語に注目（直前の文や段落に戻り、何を指しているかを確認する）
場面7
「たとえば」の後に事例が出てきた。
→ 具体例に注目（その例が何を説明するために出ているかを確認する）
場面8
AとBを比べている構造が見えた。
→ 対比に注目（昔と今、一般論と筆者の主張など、何と何を対比しているかを確認する）
よくある勘違い
  • 文章理解は知識量で解く問題ではない → 本文に書かれていることだけを根拠にする
  • 本文に書いていないもっともらしい選択肢は選ばない → 常識的に正しくても、本文に根拠がなければ選べない
  • 空欄補充は空欄の直前だけで決めない → 段落全体の流れと接続語のサインを確認する
  • 要旨問題では細部より文章全体の方向を見る → 部分的な記述の正確さより、筆者が全体で言いたいことを探す
  • 接続語を無視すると文章整序で崩れやすい → 「しかし」「つまり」「たとえば」は前後のつながりのサイン
1分復習
まず設問が何を求めているかを見る。それから本文を読む。
  • 全体の主張なら要旨把握
  • 本文と選択肢の照合なら内容一致
  • 前後の流れなら空欄補充
  • 文の順番なら文章整序
  • 逆接・理由・具体例なら接続関係
  • これ・それなら指示語
  • AとBの違いなら対比
  • 例が出たら何を説明しているかを見る
ミニクイズ
問1
設問が「本文全体の趣旨として最も適切なものはどれか」と聞いている。このときまず見るべきものはどれか？
問2
選択肢に、本文には書かれていない強い断定が含まれている。このとき注意すべきものはどれか？
問3
「しかし」の後に筆者の主張が出てきた。この接続語が示す関係としてまず見るべきものはどれか？
