行政法

行政立法の全体地図

「行政がルールを作れば全部同じ」という処理を解消するための基礎確認

一撃定義
POINT

行政立法とは、行政機関が一般的・抽象的なルールを定める行政活動として整理する。

行政立法の中でも、国民の権利義務に関わる外部的ルールとして問題になる法規命令と、行政内部の基準・事務処理などに関わる行政規則を区別する。取消訴訟で争えるかどうかは、行政立法か否かだけで決まるのではなく、処分性として別に確認する。

まずイメージ

行政が関わるルール・文書・活動は多様である。形式だけで制度を決めつけない。

  • 行政立法 ← このカードの中心
    行政機関が一般的・抽象的なルールを定める行政活動。個別具体的な事件・対象への法的効果を直接生じさせる行政行為とは区別する
  • 法規命令
    国民の権利義務に関わる外部的ルールとして問題になる命令。委任命令（法律の委任に基づき法律内容を補充する命令）と執行命令（法律執行に必要な細目的・手続的事項を定める命令）に分かれる
  • 行政規則
    行政内部の基準・事務処理・組織運営などに関わる内部的ルール。行政内部のルールとして整理する。ただし、行政運用を通じて外部に影響が生じる場面があることは否定しない
  • 行政行為
    個別具体的な事件・対象について、一方的に権利義務などの法的効果を生じさせる行政活動。行政立法（一般的・抽象的なルール形成）とは段階が違う（詳細は行政行為カードへ）
  • 通達
    上級行政機関が下級行政機関に対して示す内部的な指示・基準として整理する。国民を直接拘束する法規範として即断しない
  • 告示
    行政機関が一定事項を公示する形式として使われる。内容によって法規性・外部効果・処分性が問題になりうるため、形式名だけで結論を出さない
  • 条例・規則
    地方公共団体のルール形式。条例は地方公共団体の議会が制定する法形式。地方公共団体の長などが定める規則とは区別する。詳細は地方自治法カードへ
  • 行政指導
    相手方の任意の協力を求める行政活動。一般的・抽象的なルール形成である行政立法とは区別する
よくある勘違い
  • 行政がルールを作れば全部行政立法、ではない → 行政の活動形式は多様であり、個別具体的な法的効果を生じさせる行政行為など、行政立法以外の形式がある
  • 行政立法と行政行為は同じ、ではない → 行政立法は一般的・抽象的なルール形成、行政行為は個別具体的な事件・対象への法的効果であり、段階が異なる
  • 法規命令と行政規則は同じ、ではない → 法規命令は国民の権利義務に関わる外部的ルールとして問題になり、行政規則は行政内部の基準・事務処理などに関わる内部的ルールとして整理する
  • 行政規則は常に国民に一切関係ない、ではない → 行政規則は行政内部のルールだが、行政運用を通じて外部への影響が問題になる場面がありうる
  • 通達は当然に国民を直接拘束する、ではない → 通達は上級行政機関から下級行政機関への内部的指示・基準として整理する
  • 告示は常に行政立法、ではない → 告示は形式であり、内容によって法規性・外部効果・処分性が問題になりうる。形式名だけで結論を出さない
  • 行政立法だから取消訴訟で争えない、と即断しない → 取消訴訟で争えるかは処分性として別に確認する
  • 法律の委任があれば何でも命令で定められる、ではない → 委任命令は委任の範囲を超えて定めることができず、委任の範囲が問題になりうる
場面で覚える
場面1
行政機関が、広く一般に適用されるルールを定める。
→ 行政立法が問題になりうる。個別具体的な事件・対象について法的効果を生じさせる行政行為とは区別する
場面2
法律の委任を受けて、行政機関が法律内容を補充する命令を定める。
→ 委任命令が問題になりうる。委任の範囲を超えていないかを確認する。委任の範囲を超えた命令は適法性の問題が生じうる
場面3
行政機関が、法律の実施に必要な細目的・手続的事項を定める。
→ 執行命令が問題になりうる。法律の内容を勝手に変えるものではなく、実施上の細目を定めるものとして整理する
場面4
上級行政機関が下級行政機関へ運用基準を示す。
→ 通達・行政規則が問題になりうる。国民を直接拘束する法規範として即断しない。行政内部の指示・基準として整理する
場面5
行政機関が告示という形式で一定事項を公示する。
→ 形式名だけで結論を出さず、内容に応じて法規性・外部効果・処分性を確認する
場面6
行政の一般的ルールを取消訴訟で争えるかが問題になる。
→ 行政立法かどうかだけで終わらせず、処分性を別に確認する（詳細は処分性カードへ）
1分復習
「行政がルールを定めた場面」を見たら、制度の見分け方を確認する。
  • 一般的・抽象的なルール形成か → 行政立法の問題（個別具体的な法的効果を生じさせる行政行為とは区別する）
  • 個別具体的な事件・対象への法的効果か → 行政行為の問題（行政立法とは段階が違う）
  • 国民の権利義務に関わる外部的ルールか → 法規命令として問題になりうる
  • 行政内部の基準・事務処理か → 行政規則として整理する（行政運用を通じた外部への影響は別途確認）
  • 通達・告示を形式名だけで処理していないか → 内容に応じて法規性・外部効果・処分性を確認する
  • 取消訴訟で争えるかは処分性として別に確認する → 行政立法だから争えない、とは即断しない
  • 任意の協力を求めているか → 行政指導の問題（行政立法とは区別する）
ミニクイズ
問1
行政立法と行政行為の区別として最も適切なものはどれか。
問2
法規命令と行政規則の区別として最も安全な説明はどれか。
問3
告示や通達を見たときの態度として最も適切なものはどれか。
参考：発展確認・関連ページ
発展確認：法規命令と行政規則
  • 法規命令
    国民の権利義務に関わる外部的ルールとして問題になる命令。委任命令（法律の委任に基づく）と執行命令（法律執行に必要な細目的・手続的事項）に分かれる
  • 行政規則
    行政内部の基準・事務処理・組織運営などに関わる内部的ルール。訓令・通達・内規などが典型例として挙げられることがある。行政運用を通じて外部に影響が及ぶ場面はありうる（要確認）
発展確認：委任命令と執行命令
  • 委任命令
    法律の委任に基づいて、法律の内容を補充する命令として整理する。委任の範囲を超えて定めることができず、委任の範囲が問題になりうる
  • 執行命令
    法律の実施に必要な細目的・手続的な事項を定める命令として整理する。法律の内容を変えるものではなく、実施上の細目を定めるものとして整理する
発展確認：通達の位置づけ
  • 通達の内部的性質
    通達は、上級行政機関が下級行政機関に対して示す内部的な指示・基準として整理する。国民を直接拘束する法規範として即断しない
  • 外部への影響
    通達に従った行政運用が外部に影響を及ぼす場面はありうる。ただし、通達そのものが直接の法規範として国民を拘束するとは整理しない（要確認）
発展確認：告示は形式だけでなく内容を見ること
  • 告示の多様性
    告示は、行政機関が一定事項を公示する形式として使われる。内容によって、行政立法として機能するものから、一般的な情報提供に近いものまで多様な場合がある
  • 法規性・処分性の確認
    告示という形式名だけで法規性・外部効果・処分性を断定しない。内容に応じて確認する（要確認）
発展確認：行政立法と処分性
  • 行政立法と処分性の関係
    行政立法に見えるものでも、取消訴訟で争えるかどうかは処分性として別に確認する。行政立法だから常に処分性がない、とは整理しない（詳細は処分性カードへ）
発展確認：条例・規則は地方自治法カードへ

    地方公共団体の議会が制定する法形式として整理する。地方公共団体の長などが定める規則とは区別する。詳細は地方自治法カードへ
