損失補償の全体地図

国家賠償法1条・2条や民法不法行為と混同しないための入口整理

冒頭結論
POINT

損失補償は、「違法だから賠償せよ」という制度ではありません。

適法な行政活動であっても、特定の者に財産上の特別の犠牲が集中しているなら、その損失を補うことが問題になります。

まずは、違法行為の責任追及なのか、適法な行政活動による財産上の特別の犠牲なのかを入口で分けます。

入口判定
  • 違法な公権力行使による損害賠償か
    公務員の職務行為が違法で、それによって損害が生じた場面なら、国家賠償法1条方向を疑う
  • 公の営造物の設置管理の瑕疵か
    道路・公園などの公の営造物の設置または管理に問題があり、損害が生じた場面なら、国家賠償法2条方向を疑う
  • 適法な行政活動による財産上の特別の犠牲か
    行政活動自体は適法だが、特定の者に財産上の負担が集中している場面なら、損失補償方向を疑う
  • 単なる一般的負担か
    社会全体に広くかかる規制や負担であれば、直ちに損失補償とは読まない
  • 私人間の不法行為か
    民間人同士の事故や契約外の損害なら、まず民法上の不法行為方向を疑う
比較表
制度：国家賠償法1条
何を問題にするか：公権力行使に当たる公務員の違法な職務行為による損害賠償。
入口の合図：公務員・職務行為・違法・損害。間違えやすい相手：損失補償、民法上の不法行為、国家賠償法2条。
制度：国家賠償法2条
何を問題にするか：道路・公園など、公の営造物の設置または管理の瑕疵による損害賠償。
入口の合図：公の営造物・設置管理・瑕疵・損害。間違えやすい相手：国家賠償法1条、損失補償。
制度：損失補償
何を問題にするか：適法な行政活動により、特定の者に財産上の特別の犠牲が生じる場合の補償。
入口の合図：適法・行政活動・特定の者・財産上の特別の犠牲。間違えやすい相手：国家賠償法1条、国家賠償法2条、一般的負担。
制度：民法上の不法行為
何を問題にするか：私人間などで、違法な加害行為によって損害が生じた場合の損害賠償。
入口の合図：民間人同士・契約外の損害・加害行為。間違えやすい相手：国家賠償法1条。
制度：行政上の強制
何を問題にするか：行政上の義務履行を確保するための手段や、緊急時の実力行使。
入口の合図：義務を履行させる・実力で状態を実現する。間違えやすい相手：行政罰、損失補償。
制度：行政罰
何を問題にするか：行政上の義務違反などに対する制裁。
入口の合図：過去の義務違反・制裁・罰。間違えやすい相手：行政上の強制、損失補償。
ミニ事例
例1：公務員の違法な職務行為
公務員の違法な職務行為によって損害を受けた。
→ 国家賠償法1条方向
例2：公の営造物の設置管理の問題
道路や公園など公の営造物の設置管理に問題があり損害を受けた。
→ 国家賠償法2条方向
例3：適法な行政活動による財産上の特別の犠牲
行政活動自体は適法だが、特定の者に財産上の特別の犠牲が集中している。
→ 損失補償方向
例4：民間人同士の事故
民間人同士の事故や契約外の損害が問題になっている。
→ 民法上の不法行為方向
試験ポイント
  • 違法な公権力行使なら、国家賠償法1条方向を疑う。
  • 公の営造物の設置管理の瑕疵なら、国家賠償法2条方向を疑う。
  • 適法な行政活動による財産上の特別の犠牲なら、損失補償方向を疑う。
  • 私人間の違法な加害なら、民法上の不法行為方向を疑う。
  • 行政が不利益を与えたというだけで、直ちに損失補償と読まない。
ひっかけ注意
  • 損失補償を国家賠償と混同しない。
  • 損失補償を違法行為の責任追及として書かない。
  • 国家賠償法1条と2条を混同しない。
  • 公の営造物の話を損失補償に流さない。
  • すべての規制や負担に当然に補償が必要と書かない。
  • 行政罰や行政上の強制と混同しない。
  • 条文番号や判例名を推測で追加しない。
