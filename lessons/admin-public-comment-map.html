行政法

意見公募手続の全体地図

行政手続法クラスタで、個別処分とルール作成前の手続を取り違えないための入口確認

冒頭結論
POINT

意見公募手続は、個別事件の処分手続ではなく、命令等という一般的なルールや基準を作る前に、案を示して意見を集める手続である。

個別の申請への応答でも、個別の不利益処分でも、行政指導でも、届出でもない。行政が「ルールを作る前」に広く一般から意見を求めているかを見る。

入口判定
  • 行政が一般的なルールや基準を作ろうとしているか
    命令、審査基準、処分基準、行政指導指針など、行政手続法上の命令等として問題になる一般的なルール・基準づくりかを確認する。
  • その前に案や関連資料を示して意見を求めているか
    行政機関が命令等を定めようとする段階で、案や関連資料を公示し、広く一般の意見を求めているなら意見公募手続を疑う。
  • 個別の申請・不利益処分・行政指導・届出ではないか
    許可申請への諾否、特定相手への営業停止、任意協力の働きかけ、私人から行政庁への通知とは入口が違う。
  • 例外や適用除外を忘れていないか
    命令等を定める場面すべてで常に同じ形の手続が必要、と断定しない。例外・適用除外が問題になることがある。
比較表
意見公募手続
誰が動くか：行政機関
何をするか：命令等を定める前に、案や関連資料を公示し、広く一般から意見を求める。
相手方の位置づけ：個別の相手方ではなく、意見を提出できる一般の人。間違えやすい相手：申請に対する処分・不利益処分・行政指導・届出
申請に対する処分
誰が動くか：私人・事業者など
何をするか：許可、認可など、自己に利益を付与する処分を求める。
相手方の位置づけ：申請者。行政庁が許可・不許可で応答する。間違えやすい相手：意見公募手続・届出
不利益処分
誰が動くか：行政庁
何をするか：特定の相手方に、一方的に義務を課し、または権利利益を制限する。
相手方の位置づけ：処分の名あて人。間違えやすい相手：意見公募手続・行政指導
行政指導
誰が動くか：行政機関
何をするか：特定の相手に、行政目的のため任意協力を求める。
相手方の位置づけ：協力を求められる特定の相手。間違えやすい相手：不利益処分・意見公募手続
届出
誰が動くか：私人・事業者など
何をするか：法令上の通知を行政庁へ出す。
相手方の位置づけ：通知をする者。行政庁に許可を求める入口ではない。間違えやすい相手：申請に対する処分・意見公募手続
ミニ事例
例1：基準案を公示する
行政機関が新しい審査基準や処分基準を定める前に、案を公示して一般から意見を募集した。
→ 一般的なルール・基準づくりの前に意見を求める場面なので、意見公募手続として読む。
例2：営業許可を申請する
事業者が営業許可を申請し、行政庁が許可・不許可を判断した。
→ 私人の申請への応答なので、申請に対する処分であり、意見公募手続ではない。
例3：営業停止を命じる
行政庁が特定業者に営業停止を命じた。
→ 特定の相手方に不利益を与える入口なので、不利益処分として読み、意見公募手続とは分ける。
試験ポイント
  • 「意見を聞く」「公示する」「案を示す」「基準を作る」に注目する
    ただし、「意見を聞く」という言葉だけで行政指導や聴聞と混同しない。
  • 個別処分か、一般的なルール・基準づくりかを見る
    申請者・処分の名あて人という個別の相手が中心なら、まず申請に対する処分や不利益処分を疑う。
  • 意見提出の効果を広げすぎない
    提出された意見は考慮対象になるが、必ず採用されるわけではなく、意見提出者の同意がなければ命令等を定められない制度でもない。
  • 結果公示や考慮結果の説明も制度の一部として押さえる
    入口教材では、意見募集だけで終わるのではなく、結果公示や提出意見を考慮した結果の説明に関する制度がある、と簡潔に押さえる。
ひっかけ注意
  • 意見公募手続は、個別の申請者を救済する手続ではない。
  • 意見を出しても必ず採用されるわけではない。
  • 意見提出者の同意が必要になる制度ではない。
  • 命令等を定める場面すべてに例外なく同じ手続が必要、と断定しない。
  • 聴聞、弁明、行政指導、届出と混ぜない。
ミニクイズ
問1
行政機関が、今後使う処分基準の案を公示し、関連資料を示して広く一般から意見を求めている。まずどの制度として読むか。
問2
事業者が営業許可を申請し、行政庁が不許可にした。この場面はまずどの入口で扱うか。
問3
意見公募手続で意見を提出した人の意見は、必ず採用されなければならないか。

一次資料で確認する観点
  • 命令等の範囲
    命令、審査基準、処分基準、行政指導指針などが行政手続法上どのように整理されるかを確認する。
  • 意見公募手続の基本構造
    命令等を定めようとする段階で、案や関連資料を示して意見を求める手続として確認する。
  • 提出意見の扱いと結果公示
    提出意見を考慮する制度、結果公示や考慮結果の説明に関する制度を確認する。ただし、採用義務や個別同意に広げすぎない。
  • 例外・適用除外
    命令等を定める場面すべてに常に同じ手続が必要とは限らない点を確認する。
