憲法

憲法の全体地図

過去問で何を聞かれているかを見抜くための基礎確認

一撃定義
POINT

憲法は、国家権力を制限し、国民の権利を保障し、国会・内閣・裁判所など統治機構の基本を定める最高法規である。

過去問では、まず人権の問題か、統治機構の問題か、違憲審査の問題かを見分ける。

まずイメージ
  • 基本的人権
    国民の自由や平等を保障するルール
  • 幸福追求権
    憲法13条を中心に、新しい人権や個人の尊重と関わる場面
  • 法の下の平等
    不合理な差別的取扱いがないかを見る場面
  • 精神的自由
    思想・良心の自由、信教の自由、表現の自由など
  • 経済的自由
    職業選択の自由、財産権など
  • 人身の自由
    身体拘束や刑事手続に関わる自由
  • 社会権
    生存権、教育を受ける権利、労働基本権など
  • 参政権
    選挙権など、政治参加に関わる権利
  • 国会
    唯一の立法機関として法律や予算などに関わる
  • 内閣
    行政権の主体として国政を執行する機関
  • 裁判所
    司法権を担い、違憲審査権を持つ機関
  • 違憲審査
    法律や行政活動が憲法に違反しないかを判断する場面
試験で問われるポイント
人権総論
  • 誰のどの権利が、どのように制約されているかを見る
    権利の種類と制約の根拠・態様を分けて整理する
精神的自由
  • 表現の自由などは重要度が高く、制約の合憲性が問われやすい
    表現・思想・信教などへの制限は厳しく審査される場面がある
経済的自由
  • 政策的規制との関係で、精神的自由より広い規制が認められやすい場面がある
    職業の許可・資格・営業規制が問われる場面で整理する
平等
  • 区別に合理性があるかを見る
    すべての区別が禁止されるわけではなく、合理的な根拠がない区別が問題になる
社会権
  • 国にどこまで具体的な義務があるかが問題になりやすい
    生存権（憲法25条）はプログラム規定論などが問われる場面がある
国会・内閣・裁判所
  • どの機関の権限かを見分ける
    立法・行政・司法のどの機能に関わるかを整理してから答える
違憲審査
  • 裁判所が具体的事件を前提に憲法適合性を判断する場面として整理する
    抽象的に法律の合憲性を審査する制度ではなく、具体的な事件を前提とする点を確認する
場面で覚える
場面1
国民の表現活動が制限された。
→ 精神的自由・表現の自由
場面2
職業・営業への規制が問題になった。
→ 経済的自由
場面3
同じ立場なのに異なる扱いを受けた。
→ 法の下の平等
場面4
生活保障が問題になった。
→ 社会権・生存権
場面5
選挙に関するルールが問題になった。
→ 参政権
場面6
法律を作る機関が問われている。
→ 国会
場面7
行政権の主体が問われている。
→ 内閣
場面8
法律が憲法に違反するかが問われている。
→ 違憲審査
よくある勘違い
  • 人権問題と統治機構問題を混同しない → まず誰の権利が問題か、機関の権限が問題かを見分ける
  • 自由権と社会権を混同しない → 自由権は国家の不介入、社会権は国家の積極的な給付・関与が問題になる
  • 精神的自由と経済的自由では、規制の見方が違う場面がある → 規制の種類と目的を確認する
  • 平等はすべての区別が禁止されるわけではない → 合理的な根拠がない区別が問題になる
  • 違憲審査は抽象的に法律を審査する制度として単純化しない → 具体的事件を前提とする点を確認する
  • 国会・内閣・裁判所の権限を混同しない → 立法・行政・司法のどの機能かを先に整理する
1分復習
人権か統治機構か、どの自由かを最初に見分ける。
  • 自由が制限されたら人権問題
  • 表現・信教・思想なら精神的自由
  • 職業・財産なら経済的自由
  • 差別的取扱いなら平等
  • 生活保障なら社会権
  • 選挙なら参政権
  • 法律を作るなら国会
  • 行政を担うなら内閣
  • 裁判・違憲審査なら裁判所
  • 憲法違反かどうかを見るなら違憲審査
ミニクイズ
問1
ある自治体が、特定の内容の街頭演説を広く制限する条例を作った。この場面でまず見るべきものはどれか。
問2
ある法律が、同じような立場の人を合理的理由なく異なる扱いにしている疑いがある。この場面でまず見るべきものはどれか。
問3
裁判所が、具体的な事件の中で法律が憲法に反しないかを判断する。この場面でまず見るべきものはどれか。
