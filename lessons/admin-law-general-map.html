行政法

行政法総論の全体地図

過去問で何を聞かれているかを見抜くための基礎確認

一撃定義
POINT

行政法総論は、行政が国民に対してどのように権限を使うか、その基本ルールを整理する分野である。

過去問では、行政の行為がどのタイプか、行政にどこまで裁量があるか、どの手段が許されるかを見分けることが問われる。

まずイメージ
  • 行政行為
    行政庁が一方的に国民の権利義務に影響を与える行為
  • 行政裁量
    行政庁に判断の幅がある場面
  • 行政指導
    強制ではなく、協力を求める行政活動
  • 行政契約
    行政主体が契約形式で相手方と関係を作る場面
  • 行政計画
    行政が将来の方針や土地利用などを計画する場面
  • 行政強制
    行政目的を実現するために強制手段を使う場面。義務履行を確保する行政上の強制執行（代執行・直接強制・執行罰・強制徴収）と、義務違反を前提にしない即時強制に分かれる
  • 行政調査
    行政目的のために情報を集める場面
  • 行政罰
    行政上の義務違反に対して制裁を科す場面
試験で問われるポイント
行政行為
  • 処分性や取消訴訟とつながる
    行政行為に当たるかを確認するとともに、取消訴訟では抗告訴訟の対象となる処分等に当たるかを別途確認する必要がある
行政裁量
  • 裁量の逸脱・濫用が問題になる
    裁量があるからといって自由に決めてよいわけではない。制度趣旨・処分の性質・専門性を踏まえた判断が求められ、考慮すべき事情を十分に考慮しないこと（考慮不尽）や、考慮すべきでない事情を考慮すること（他事考慮）などがある場合は、裁量の逸脱・濫用として違法が問題になりうる
行政指導
  • 任意か、事実上の強制になっていないかが問題になる
    まず、法的義務を直接発生させるものか、任意の協力を求めるものかを分ける。名称が「指導」でも、行政指導に従わなかったことのみを理由として不利益な取扱いをすることは禁止される。事実上の強制になっていないかも問題になりうる
行政強制
  • 行政上の強制執行と即時強制を区別して考える
    行政上の強制執行（代執行・直接強制・執行罰・強制徴収）は義務履行の確保を目的とし、制度ごとに法律上の根拠・要件・手続が必要。行政代執行では代替的作為義務・法律の根拠・補充性・公益上の支障などの要件が問われる。即時強制は義務違反への制裁や義務履行確保手段とは異なり、義務違反を前提にしない。行政罰は過去の義務違反等への制裁であって、義務内容を直接実現する制度ではない
行政調査
  • 任意調査か強制調査か、限界が問題になる
    任意調査と強制調査を区別し、強制調査には個別の法律上の根拠が必要
行政罰
  • 行政刑罰と秩序罰の違いが問題になる
    行政罰は過去の義務違反等への制裁であり、義務内容を直接実現する制度ではない（行政強制と区別）。行政刑罰は刑法上の刑罰、秩序罰は過料などの制裁
場面で覚える
場面1
行政庁が一方的に事業者の許可を取り消した。
→ 行政行為（一方的に権利義務に影響を与える行為として、処分性の問題とつながる）
場面2
行政庁が専門的な知識と経験に基づき、許可を出すかどうかを判断している。
→ 行政裁量（判断の幅があるが、逸脱・濫用は違法になりうる）
場面3
行政庁が業者に設備の改善を求めているが、法的義務として命じたわけではない。
→ 行政指導（強制ではない任意の協力要請）
場面4
行政庁が民間事業者と契約を結んで公共サービスを提供させている。
→ 行政契約（処分ではなく契約形式による行政活動）
場面5
行政上の義務を履行しない者に代わって、行政が自ら作業を実施した。
→ 行政強制・代執行（義務不履行を前提とする行政上の強制執行の一種）
場面6
行政庁が事業者に対して帳簿の提出を求めた。
→ 行政調査（任意か強制かによって根拠・限界が異なる）
場面7
行政上の届出義務に違反した者に過料が科された。
→ 行政罰・秩序罰（刑罰ではなく過料による制裁）
場面8
市が策定した土地利用の基本方針が公表された。
→ 行政計画（将来の方針を定めるもの。処分性は原則として問題になりにくい場面）
よくある勘違い
  • 行政指導は命令ではないが、事実上の強制になれば問題になる → 名称ではなく実態で判断する
  • 裁量があるからといって、何をしてもよいわけではない → 逸脱・濫用は違法になりうる
  • 行政強制と行政罰は目的が違う → 行政上の強制執行は義務履行の確保が目的、行政罰は過去の義務違反等への制裁であって義務内容を直接実現する手段ではない
  • 行政強制の中でも、即時強制は義務違反を前提にしない → 行政上の強制執行（代執行・直接強制・執行罰・強制徴収）と混同しない
  • 行政調査はすべて強制とは限らない → 任意調査と強制調査は区別して考える
  • 行政行為は取消訴訟の入口とつながる → まず行政行為かどうかを確認する
1分復習
行政の行為のタイプを見分けることが、論点特定の第一歩。
  • 行政が一方的に決めるなら行政行為
  • 判断の幅が問題なら行政裁量
  • 法的義務を直接発生させるものでなく、任意の協力を求めるものなら行政指導
  • 契約形式なら行政契約
  • 将来方針なら行政計画
  • 義務実現の強制手段または即時強制なら行政強制（強制執行〔代執行・直接強制・執行罰・強制徴収〕は義務履行の確保、即時強制は義務違反を前提にしない）
  • 情報収集なら行政調査
  • 義務違反への制裁なら行政罰
ミニクイズ
問1
行政庁が事業者の営業許可を一方的に取り消した。この行為の性質としてまず見るべきものはどれか？
問2
行政庁が事業者に改善を求めたが、法的義務として命じたわけではない。この場面でまず見るべきものはどれか？
問3
行政上の義務を履行しない者に対し、行政が義務実現のために強制手段を使う場面でまず見るべきものはどれか？
