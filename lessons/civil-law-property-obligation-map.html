物権と債権の全体地図

過去問演習前に物権と債権の場面をざっくり切り分ける

一撃定義
POINT

物権は、物に対して直接に及ぶ権利として整理する。物を所有する、占有する、担保に入れるといった場面は、物を中心に権利関係を整理する物権の問題として位置づける。

債権は、特定の人に対して一定の給付を求める権利として整理する。代金を払ってほしい、物を引き渡してほしい、損害を賠償してほしいといった場面は、人と人の間の請求関係として整理する債権の問題として位置づける。

物権と債権は、どちらも財産に関わる権利だが、向かう先が違う。問題文を読んだとき、「物に向かう話」か「特定の人への請求の話」かを先に切り分ける方向で整理する。

まずイメージ
  • 物権
    物に対して直接に及ぶ権利。所有権・占有権・抵当権・留置権などが物権として分類される。物権は物を中心に権利関係を整理する場面に位置づく
  • 債権
    特定の人に対して一定の給付を求める権利。契約・債務不履行・保証・債権譲渡・弁済・相殺は債権として整理される場面に位置づく
  • 所有権
    物を全面的に使用・収益・処分する権能を持つ物権。物権の中でも最も基本的な権利として整理する
  • 占有権
    物を事実上支配している状態に基づく権利。所有権とは区別して整理する
  • 抵当権
    不動産などを担保として設定する物権。債権の担保として設定されるが、権利の分類としては物権側に位置づく
  • 留置権
    他人の物を適法に占有する者が、その物に関して生じた債権の弁済を受けるまで物を留置することで間接的に弁済を促す物権。同時履行の抗弁権とは区別して整理する
  • 債権者
    特定の人に対して給付を求める権利を持つ者。債権関係の一方の当事者
  • 債務者
    債権者に対して給付の義務を負う者。債権関係のもう一方の当事者
  • 給付
    債務者が債権者に対して行うべき行為の内容。金銭の支払い・物の引渡し・行為の実施などが給付の内容として問題になる
  • 契約
    当事者の意思表示の合致によって成立する法律行為。契約に基づく権利義務は債権として整理される
  • 債務不履行
    債務者が債務の内容に従った給付をしない場面の総称。履行遅滞・履行不能などに分類され、債権側の問題として整理する
試験で問われるポイント
物権では、誰がどの物に対してどのような権利を持つかを見る
  • 物権の問題は、どの物に対してどのような権利が及んでいるかを先に確認する方向で整理する
    所有権・占有権・抵当権・留置権などは、物に対して直接に及ぶ権利として物権側に位置づく
債権では、誰が誰に何の給付を求めているかを見る
  • 債権の問題は、誰が誰に対してどのような給付を求めているかを先に確認する方向で整理する
    契約・債務不履行・保証・債権譲渡・弁済・相殺は、特定の人に対する請求関係として債権側に位置づく
物権側の入口として整理するもの
  • 所有権・占有権・抵当権・留置権は物権側の入口として位置づける
    担保目的で設定される抵当権も、権利の分類としては物権側として整理する。債権の担保として設定される点と、権利の性質が物権である点を混同しない
債権側の入口として整理するもの
  • 契約・債務不履行・保証・債権譲渡・弁済・相殺は債権側の入口として位置づける
    これらはいずれも、特定の当事者間の請求関係として整理される場面に位置づく
留置権と同時履行の抗弁権を混ぜない
  • 留置権は物権として物を留置することで間接的に弁済を促す場面に位置づき、同時履行の抗弁権は双務契約の当事者間で相手の請求に対して自己の履行を拒絶できる場面に位置づく
    留置権は物権、同時履行の抗弁権は双務契約の当事者間の債権的な抗弁として区別して整理する
物権変動と債権譲渡を混ぜない
  • 物権変動は、物に対する権利の変動（所有権の移転・抵当権の設定など）が問題になる場面に位置づく。債権譲渡は、債権者が自分の持つ債権を別の人に移転する場面に位置づく
    どちらも権利の移転が問題になるが、物権変動は物を中心とする権利の変動として、債権譲渡は人に対する請求権の移転として区別して整理する
場面で覚える
場面1
AはBから土地を購入し、その土地の所有権を持っている。Aはその土地を自由に使用・収益・処分する立場にある。この場面では、物に対して直接に及ぶ権利が問題になる。
→ 物権（所有権）
場面2
AがBに土地を売った。Bへの所有権移転が問題になる場面で、登記を誰が先に備えたかが争点となった。この場面では、物に対する権利の変動と対抗要件が問題になる。
→ 物権変動・対抗要件（物権側の問題）
場面3
AはBから融資を受けるにあたり、Bのために自分の土地に抵当権を設定した。Aがローンを返済しない場合、Bはその土地について抵当権を行使する立場にある。
→ 物権（抵当権）
場面4
AはBとの売買契約に基づいて、Bに対して代金の支払いを請求している。Aは特定のBに対して金銭の給付を求める立場にある。
→ 債権（売買代金請求権）
場面5
BはAから商品を買った。BはAに対して商品の引渡しを求める立場にある。この場面では、Aに対する特定の給付の請求関係が問題になる。
→ 債権（引渡請求権）
場面6
AはBとの請負契約に基づいて、Bに対して建物の完成・引渡しを求めている。契約の内容に従ってBが給付を行うことが問題になる場面である。
→ 債権（請負契約に基づく履行請求）
場面7
AはBの時計を修理した。修理代金の支払いを受けるまで、AはBの時計を適法に占有している。Aがその時計の返還を求められた場面で、修理代金の支払いがあるまで留置できるかが問題になる。
→ 物権（留置権）
場面8
AはBとの双務契約に基づいて給付する義務がある。BがAに履行を求めてきた場面で、AはBがまだ自分への給付をしていないことを理由に、自己の履行を拒絶しようとした。
→ 債権的な抗弁（同時履行の抗弁権）
よくある勘違い
  • 物が出てきたら物権の問題、とは限らない → 契約の目的物として物が登場する場面でも、当事者間の請求関係が問題の中心なら債権側の問題として整理する
  • 契約の目的が物の引渡しであっても、引渡しを求める権利は特定の相手への請求として債権側に位置づく → 物の取引と物権の問題を混同しない
  • 物権は、性質として物に対して直接に及ぶ点を先に押さえる → 「誰に対しても同じように主張できるかどうか」は物権の性質の一側面として整理するが、問題の切り分けの第一歩は権利の向きで行う
  • 債権は金銭の支払いだけに限らない → 物の引渡し・行為の実施・不作為など、様々な内容の給付を求める権利として整理する
  • 留置権と同時履行の抗弁権を同じ制度として扱わない → 留置権は物権として物を留置する場面、同時履行の抗弁権は双務契約の当事者間で履行の拒絶が問題になる場面として区別する
  • 物権変動と債権譲渡を同じ対抗要件の話としてまとめない → 物権変動では登記や引渡しが対抗要件として問題になり、債権譲渡では通知や承諾が対抗要件として問題になる点で区別する
1分復習
物権は物に対して直接に及ぶ権利。債権は特定の人に給付を求める権利。権利の向きで切り分ける。
  • 物権の場面では、誰がどの物に対してどのような権利を持つかを先に確認する
  • 債権の場面では、誰が誰に対してどのような給付を求めているかを先に確認する
  • 所有権・占有権・抵当権・留置権は物権側の入口として整理する
  • 契約・債務不履行・保証・債権譲渡・弁済・相殺は債権側の入口として整理する
  • 物が出るかどうかではなく、権利の向きで物権と債権を切り分ける
  • 留置権と同時履行の抗弁権、物権変動と債権譲渡は混同しない
